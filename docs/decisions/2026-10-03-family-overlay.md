# 浮层族判据

## Status

Decided for Popover（2026-10-03，按逐值裁决修订）；其余重写目标为 Proposed。依据 [design.md](../../design.md)、[基础层](2026-10-03-foundation.md)、[组件分层](component-layering.md)。当前本族有 Popover 与保留实现 Tooltip；表列其余成员是待重写目标，不表示已导出。

## 一、这一族处理什么真实问题

一个人要做一件事，而这件事**需要暂时离开当前工作面，做完再回来**。

不是「弹出一个框」，是：确认一个不可逆的决定、在一个次要对象上做修改、查看一条补充信息、执行一个不属于当前主线的命令。

**核心问题**：如何让「暂时」与「回来」都成立——**浮起期间原工作面还在，关闭之后位置与焦点都回得去**。

两个失效模式都同等严重：浮层关不掉（困住用户）、关掉后回不去（丢失位置）。

## 二、参与的与不参与的方法

| 方法 | 参与 | 在这一族的后果 |
|---|---|---|
| 展开有据 | **主导** | 深入必须有理由；**返回必须存在且可预期** |
| 相成相制 | **参与** | 浮层与其触发者、与遮罩、与底层内容的关系必须成立 |
| 名实相符 | **参与** | 浮层类型由**它阻断什么**决定，不由它从哪边滑出决定 |
| 随境取度 | **参与（承载）** | 同一意图窄屏可换承载方式，但**阻断性、返回方式、语义不变** |
| 进退相承 | **参与** | 打开中可关闭、退出中可重开；焦点归位；不因动画阻塞 |
| 布白有用 | 不参与 | 浮层不决定页面的空间分配 |

## 三、由关系强制出的六个决定

### 决定 1：浮层类型由**阻断什么**决定，不由外观决定

这是本族最容易搞错的地方，也是 `sheet` / `drawer` 两个名字并存的根源。

| 类型 | 阻断什么 | 何时必须用 | 何时不成立 |
|---|---|---|---|
| **Modal**（`Dialog` / `AlertDialog`） | **阻断整个工作面** | 决定必须在使用其他内容前完成 | 用户不需要停下手上的事 → 用面板/就地 |
| **Non-modal**（`Popover` / `HoverCard` / `Tooltip`） | **不阻断** | 补充信息或局部操作 | 关键后果只存在于其中 → 违反 NG7 |
| **Edge panel**（`Drawer`） | 阻断或半阻断，**依内容而定** | 内容需要纵向空间、或需保留底层上下文 | 内容很短 → 用 Popover |

**推出**：`sheet` 与 `drawer` 是同一关系的两个名字，**保留 `drawer`**——它说明动作（抽出），`sheet` 只说明形状。

**「从哪边滑出」不是类型差异**，是同一类型的方向参数。

### 决定 2：**返回必须存在**，且必须在关闭之前就已确定

展开有据要求返回存在。因此：

- 浮层必须有一个**可预期的关闭方式**（Esc、点击外部、显式关闭）
- **由浮层自身关闭时，焦点回到触发者**；触发者已不存在时，回到有意义的上级
- **用户主动移开焦点时不抢回。** Tab 到浮层外的控件、点击背景中另一个可聚焦元素，是用户在导航，不是关闭浮层——此时保留用户的新落点。非阻断浮层尤其如此（决定 1）：抢回焦点会与「不阻断」直接冲突
- **不可逆动作不得用浮层关闭来表达「取消」**（design.md 原文：关闭窗口不能被称为撤销）

**禁止**：把「关闭」当作「已取消」。关闭与取消是两个不同的事实。

**归位规则的准确范围**（此前表述不精确，2026-10-03 由 P1 探针暴露并裁决）：

| 关闭路径 | 焦点落点 |
|---|---|
| Esc | 触发者 |
| 显式关闭控件 | 触发者 |
| 触发者已从 DOM 移除 | 有意义的上级（由调用方给） |
| **Tab 移出浮层** | **用户到达的元素**（不抢回） |
| **点击背景中另一个可聚焦控件** | **该控件**（不抢回） |

「焦点必须回到触发者」只覆盖前两行。把它读成无条件规则会与决定 1 的「不阻断」冲突。

### 决定 3：**动画所有权在 `motion.css`**

基础层 §12 的所有权选择：Popover / Tooltip 组件提供结构、原语测得的触发点原点与 data-slot，入退由 motion.css 接管，不声明第二套入场参数。当前起止 scale 0.98 / opacity 0、进入 140ms / 退出 100ms 均为**预设**，不得写成关系唯一决定。Popover 与 Tooltip 的 z-50 也是**继承预设**。

### Popover 当前的焦点与命中

Popover 固定 modal=false，不困住底层工作面；非阻断**不等于面板不会获得焦点**。独立审查实测 Enter 打开后 Popup 匹配 focus-visible，见[逐值裁决第六节](2026-10-03-value-adjudication.md)。当前面板已有 1px 边框，聚焦时 `focus-visible:border-ring` **只变色、不加粗**，不新增内描边或外围圈。此处描述实际行为，不把「面板是否应作为焦点落点」的未定评价写成它不能聚焦。

裸 Trigger / Close 当前有透明占位边框与 2px 自盒内线；Button 组合使用相应按钮档的焦点机制，须核对没有重复信号。touch-target 在粗指针下**自建定位上下文**，命中层至少库内 44px，不再依赖调用方手写 relative；这避免 static 宿主把命中层解析到视口。2px 与 44px 是**选择**，不冒充 WCAG AA 强制数值；强制颜色由 styles.css 统一回退，完整组合矩阵仍为 UNVERIFIED，见基础层 §15。

当前 Popover 面板读 rounded-overlay（12px）、surface-raised、容器 border 与 shadow-raised，内容滚动层读 `--qy-panel-padding-sm`（16px）。圆角、阴影和 padding 是**选择或预设**；必要识别机制要存在，但描边不是所有浮层的必选机制。Tooltip 的局部阴影与伪元素高光仍是保留实现预设，不把本族写成已全部按共享角色重写。

### 决定 4：**阻断性必须被正确声明**

阻断性决定三件事：焦点是否被困、底层是否可滚动、屏幕阅读器是否只读浮层。

**禁止**：声明的阻断性与实际键盘、滚动及底层可操作行为不一致。浮起外观本身不等于阻断，Popover 当前明确为非阻断。

**禁止**：`aria-modal` 与实际的焦点困住不一致。

### 决定 5：**关键后果不得只存在于会消失的浮层里**

NG7。Tooltip 与 HoverCard 是会消失的，因此它们**不得承载唯一的关键后果**。

**推出**：`Tooltip` 的用途是**补充**已有的可见信息（例如图标的文字说明），不是**替代**它。

### 决定 6：浮层内的动作遵循动作族判据

浮层本身不改变业务状态。危险后果必须可见、在场且与按钮可关联；ButtonProtection 或已有非空说明的 aria-describedby 均可，不因动作位于浮层就强制重复包装（动作族决定 3、基础层 §18）。关键后果不能只靠会消失的面板保留；应用须在合理的持续落点提供依据。

## 四、本族的单元构成

| 分组 | 成员 | 阻断性 | 承载 |
|---|---|---|---|
| **阻断式决定** | `Dialog`、`AlertDialog` | 完全阻断 | 需要在继续前完成的决定 |
| **确认契约** | `ConfirmAction`（新增 Pattern） | 依落点 | 危险动作与其保护的共同结构 |
| **边缘面板** | `Drawer` | 依内容 | 需要纵向空间或保留上下文的操作 |
| **非阻断补充** | `Popover`、`HoverCard`、`Tooltip` | 不阻断 | 补充信息、局部操作 |
| **命令浮层** | `Menu`、`ContextMenu` | 临时阻断 | 命令选择 |
| **导航浮层** | `NavigationMenu` | 不阻断 | 站点级导航 |

**`command` 已删**（分层文档）：命令面板是 `Menu` + `Input` 的组合情境，是 Pattern，不是组件。

## 五、逐组件定位与关键取舍

| 组件 | 定位 | 关键取舍 |
|---|---|---|
| `Dialog` | 阻断式工作面 | **不提供尺寸变体**：最大宽度由内容与视口决定 |
| `AlertDialog` | 阻断式，仅用于需明确决策 | 与 `Dialog` 的差别是**意图**（必须回应），不是外观 |
| `Drawer` | 边缘面板 | 吸收 `sheet`；方向是参数不是类型 |
| `Popover` | 与触发者绑定的非阻断浮层 | 不承担唯一关键后果；面板实际可获得焦点，聚焦边框只变色 |
| `Tooltip` | 补充已有信息的短文本 | **不得承载唯一后果**（NG7）；不作为唯一标签来源 |
| `HoverCard` | 悬停展开的富内容预览 | 必须有键盘等价路径（悬停不是唯一入口） |
| `Menu` | 命令选择 | 选项是命令不是值；值是 `Select` |
| `ContextMenu` | 上下文命令 | 右键是增强入口，**不得是唯一入口** |
| `NavigationMenu` | 站点级导航浮层 | 导航是到达，不是命令 |
| `ConfirmAction` | 危险动作 + 保护的结构 | 必须针对**当前对象、版本与变更内容**，不是「确定吗」 |

## 六、这一族最容易做错的六件事

| # | 错误 | 违反 | 判据 |
|---|---|---|---|
| 1 | Esc 关不掉，或焦点被困住无法离开 | 展开有据 | 键盘能否只用 Esc 与 Tab 走完全程 |
| 2 | Esc/显式关闭后无法返回，或主动移开后被抢回 | 展开有据 | 自身关闭检查触发者；Tab/点击背景检查用户新落点 |
| 3 | 视觉是浮层但 `aria-modal` 不一致 | 名实相符 | 读屏与键盘用户是否遇到与视觉不同的行为 |
| 4 | 关键后果只在 Tooltip 里 | NG7 / 展开有据 | 提示消失后能否确认该后果 |
| 5 | 用浮层关闭表达「已取消」 | 进退相承 | 关闭与取消是否被当作同一事实 |
| 6 | 组件自己写入场动画 | 基础层 §12 | 同一浮层是否存在第二个动效来源 |

## 七、与基础层的关系

消费 §4（圆角：独立浮层身份）、§5（必要识别，描边为可选机制）、§6（表面层级：临时浮起）、§9（状态归属：open 是基础状态，打开原因与后果归应用）、§12（动效所有权与继承预设）、§15（面板聚焦只变色、命中自建定位与系统回退）、§18（后果可见且可关联）。所有编号指向[基础层](2026-10-03-foundation.md)。

**本族不新建数值。** 需要时回基础层补。

## Alternatives

**未保留 `sheet`。** 它与 `drawer` 是同一关系（侧向浮层）的两个名字。两个名字对应一个对象会迫使用户记忆差异，违反名实相符。

**未把「方向」做成类型。** 左右上下的滑出方向是同一阻断关系的位置参数，不是四种不同语义。做成类型会诱导为每个方向写一套行为。

**未让 `Dialog` 提供尺寸变体。** 宽度应由内容需求与视口决定，不应是调用点的选择。提供尺寸变体会让「这个对话框多宽」成为一个需要判断的设计决策，而它不该是。

**未把 `Tooltip` 当作标签的唯一来源。** 会消失的提示不能承载唯一信息。

**未保留 `command` 组件。** 命令面板是组合情境，固化会锁死组合方式（如 `⌘K` 的搜索来源、分组、快捷键）。

**未把 `AlertDialog` 与 `Dialog` 合并。** 二者结构相同但**意图**不同：一个是「必须回应的决定」，一个是「暂时离开工作面」。合并会让「这个对话框是否必须回应」失去表达。

## Consequences

- 当前 Popover 面板实际获得焦点，不能删除其只变色的信号或用非阻断身份否认这个事实。
- 其余浮层已归档，本文记录重写目标，不沿用旧文件行数或组件页数量描述当前实现。
- Tooltip 仍有待重写预设；完整强制颜色组合与面板焦点落点的任务适合性分别验证，不从一次审查外推全部 PASS。
- ConfirmAction 为拟议 Pattern，实际 danger Button 已有两种合法后果关联路径，由 B 的新实现证据验收。
