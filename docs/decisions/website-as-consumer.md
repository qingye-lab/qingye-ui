# 官网作为组件库的第一方消费端

当前裁决：2026-10-03 重写任务，执行收尾跨至 2026-10-04。取代本文件早期的 88 模块、业务任务模拟和移动外壳安排；历史裁决见对应日期的计划与执行记录。

## 任务与边界

官网帮助人识别组件、打开真实示例、查当前 API，并把同源设计指南带入项目。当前目标为已重写的 83 个组件，目录数量与示例来自 `content/*/meta.ts` 和当前 registry，不另维护计数或示例库存。

- 首页是介绍项目作用的落地页，不是目录（用户 2026-10-08）。同日经多轮否决（目录、左右对撑、居中窄栏、硬拉宽、放大的图谱、标注画布），用户最终放开约束：「可以左右布局……我不限制你了……你设计需要使用我的项目理念」，并以 Linear 为精致度标尺。
- 2026-10-08 深度评审后，用户要求重新设计首页，改善设计与交互。现行结构为：产品名与技术定位；总纲及真实设计摘录组合（搜索、选择、密度、复制）；实际按钮尺寸与 DOM 几何；五级中性墨阶；安装 / AI 接入。交互控件复用库，摘录只属于当前示例，不模拟业务请求。详细表面与状态契约见 `apps/docs/.impeccable/surfaces/apps-docs-src-pages-home-tsx.md`。
- `/docs/components/:slug` 与 `/components/:slug` 共用组件内容身份；playground 裸页消费同一 registry 和 demo ID。预览、源码、API 与键盘信息保留各自用途。
- `/examples` 是一个完整的多页工作区示例（概览、集合、集合详情、设置、帮助），只用本库公开组件组合，随 `src/examples/` 路由。用户 2026-10 裁决：`/examples` 不受“不模拟业务场景”约束，必须是真实页面；数据是本地假数据，没有真实请求或服务。未知路径、未知工作区页面与未知设置分组都进入站点统一的 not-found 状态；跳转保留 URL 语言前缀。
- `/docs/patterns` 是当前 Pattern 公共结构目录。已删除业务模式的详情路由进入 not-found，不从归档恢复旧消费者。`generate-fixtures.mjs` 保持构建调用入口但不再生成无人消费的假业务资源。
- 所有交互控件复用本库公开组合；页面结构、表单分组和原生链接保留 HTML 语义。链接外观可用 `buttonVariants`。NativeSelect 的原生 option/optgroup 是其必要结构，并非一套另造的基础控件。
- 当前范围是桌面网站，Header 直接呈现导航；不为旧 Sheet 恢复移动菜单，也不恢复 Skeleton、Disclosure、Frame、Command 等禁用模块。

## 语义与状态

搜索由当前公开的 inline Combobox 与 Dialog 组成。结果来自当前指南与组件，caller 排序并提供目的地；无匹配不能发明结果。选择结果后把页面标题/主区域返回给 Dialog 的 `finalFocus`，由原语实际聚焦，避免在关闭回调中提前 focus 造成重入；取消归还原触发位置。

草稿和已应用条件分别保存；应用后才改变结果，取消回到已应用条件。Tabs 保留隐藏面板的草稿。复制成功由 Clipboard Promise 确认，拒绝后呈现公共 CopyButton 错误反馈。加载和渲染失败按对应局部说明，重试不丢弃文档邻接内容；未知、空与不适用分别使用当前 Empty 状态。

侧栏选中项在当前原生 ScrollArea 容器内滚动到可见处，使用真实 `data-slot="scroll-area"`，不依赖已删除的 Viewport 部件。

## 信息架构（2026-10-08）

用户反复指出：各页导航不一样且位置会变；文档页版式不统一；首页、示例与其他页的页头和宽度在切换时会变；理念、法度若放进文档，页头就不需要它们。取舍结果：

**一个壳。** 所有页面（首页、文档、组件、示例）同一个页头：吸顶、一条底线、页面背景色、同一宽度。宽度是 `--site-width` = 66 材（侧栏 12 + 间隔 2 + 正文 40 + 间隔 2 + 目录 10，正好是文档框架的总宽），两侧最小留白 2 材，`.site-frame` 居中；`html` 设 `scrollbar-gutter: stable`，有无滚动条的页面宽度相同。页头、首页、文档框架、示例画布都用 `.site-frame`，不再各写版心与内边距。

**一棵导航树。** 页头只有文档、组件、示例三个入口（库的 `NavigationMenu`），当前页点亮它所属的一处（`navScope`）。理念与法度在文档里，不进页头。侧栏是库的 `Sidebar`（`components/docs-nav.tsx`），在每个文档页内容与位置都相同；`DocsLayout` 只有一个路由父级，切页不重挂载。顺序即阅读顺序，上一页/下一页沿同一顺序：

| 组 | 页面 | 排序理由 |
|---|---|---|
| 开始 | 介绍 → 安装 → AI 使用 | 第一次接入 |
| 理念与法度 | 设计理念 → 基础判断 → 设计令牌 | 为什么，怎样判断，每个值从哪来 |
| 指南 | 主题 → 动效 → 国际化 → 无障碍 | 在项目里落地，改动由大到小 |
| 组件 | 总览 → 组件组合 → 十个分类（折叠） | 参考；当前页所在分类展开，其余按读者的折叠保持 |

动效在指南：它是怎样配置 MotionProvider 的说明，台账的「动」一节另有取值。

**一种字体。** 全站只用库的 `--qy-font-sans`（系统黑体：苹方 / 微软雅黑 / 思源黑体）与系统等宽；层级靠字号、字重与墨色，由库的字阶（display / title / chapter / heading）给出。曾用系统宋体做页题与章节标题、网页字体 Geist Mono 做代码，2026-10-08 撤销，理由：（一）用户 2026-10-07 已裁决「全项目一套系统字体」，并撤回过宋体正文；（二）design.md「材有美」：默认系统字体，外加拉丁字面使同一行出现两套 x 高度，正是被列为不应做的事；（三）理念正文与 design.md 都写明不取仿古字体——宋体与「取其法，不取其形」相悖；（四）宋体是印刷字，只在 macOS 有可靠的屏幕字面（苹方才是），Windows 回退到中易宋体，小字号锯齿明显，同一页在不同平台是两种样子，违背合宜为度；（五）不下载任何字体文件。若要品牌字体，走品牌层覆写 `--qy-font-sans`，不在页面里另指定。

**一套文章版式，所有页相同。** 页题 display 档、章节 title 档、小节 chapter 档，正文 reading 档、行长 34 字、中文两端对齐并严格避头尾；段间一材，小节两材，章节三材。这些写在 `prose.tsx` 与 `index.css`，页面不覆盖。理念页的出处改为正文上标链接加文末「来源简注」，边注与 `EssayFrame` 已撤销。

**首页**是同一壳与同一版式下的一篇介绍：总纲三行（40/48，唯一大于文档字阶的文字）与三句出处同行；三章（从使用出发、从关系形成整体、以材为祖）的标题与正文直接取自设计理念正文，每章右栏一个 1:1 的真实组件（同一按钮的五个状态、五级墨阶、五等按钮及其实测读数）；末了是开始使用。墨阶与五等按钮共用一套五列，两章的列上下对齐；五等按钮并置在同一条地线上，不用开关切换（2026-10-08 首页复审：此前右栏三章疏密不一，状态三行与单个按钮只占右栏四分之一）。左栏正文与右栏组件各在一条竖轴上，总纲的出处也落在右轴。首页没有卡片、没有示例应用、没有自己的版心与字体。此前的「设计摘录」交互面板（HomeCollection）已删除。

## 双语与同源指南

页面 chrome、指南正文、加载/错误恢复及非示例组件资料选择路由语言；具体作者 demo 可保留原示例内容。组件页显式传 locale 到公共 metadata/decision 接口，缺译事实由接口按字段保留，不用通用英语覆盖作者判断。

根 `design.md` 是设计指南唯一源。AI 页面消费 `designEntryFor(locale)`，同源抽取指南、AGENTS/design 接入片段与任务提示；中文 `/design.md` 契约保持，英文入口为 `/design.en.md` 与对应 AI 资源。哲学英文源为 `public-content/philosophy.en.md`，用 canonical 中文源 SHA256 绑定翻译；方法标题生成稳定 `method-1..6`，不修改中文正文、不执行 Markdown HTML。
