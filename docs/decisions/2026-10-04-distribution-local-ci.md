# 分发、本地 CI 与 Studio 消费迁移

当前源码按 `design.md` 重写后，分发的验收对象是实际安装版的公共组件与主题入口。版本准备为 **1.0.0 未发布候选**：控件 API、Card 默认视觉、原生表单组合、Table/Chart 数据入口及 modal Portal 契约均有破坏性变化。此处不创建 tag、不推送、不发布；工具包 API 没有变化，保持其版本，Studio 为私有消费工具，不顺便升版本。

## 已观察的真实断点

四个安装夹具仍需保留：Tailwind 与预编译 CSS 各有 Button 子路径小消费和显式 Table/Chart peers 的完整消费。旧完整夹具引用已不存在的 InputGroupText/InputGroupButton/ChartContainer、旧 DataTable 参数、Tree 扩展参数及 outline/ghost；刷新、加载名称被用来描述仅翻转布尔状态的假任务，不能继续作为结果证据。

旧 `--patterns` 浏览器入口仍访问已删除的业务任务页并依赖权限假资料投影。网站现有简单组合及组件演示才是当前真实消费对象。旧 foundation helpers 亦有旧 demo 标识、危险动作故事名称和 390px 矩阵。仅改 CLI 文案不能证明这些检查恢复。

Studio 的真实项目会话、nonce、主题导入/导出/读取/应用、冲突与异步响应归属继续由现有工具逻辑承担。只迁移公共组件调用和预览内容：表单草稿、显式输入错误、选择范围与 iframe 内 Portal 是真实预览事实；删除模拟保存的故事和自动推断结果。

## 关系与边界

- 浏览器范围为桌面：1100px 普通宽度、1600px 宽桌面，浅深串行。既有 2px 几何门禁、200% 文字与文字间距、语义名称、错误/未知事实、AST 规则以及浏览器进程清理不因迁移被弱化。
- 完整安装夹具以应用受控输入提供数值，Chart 与可见数值表同源；DataTable 消费调用方 TanStack table，不造请求或假刷新。Tabs 分离焦点移动与显式激活；Tree 移除焦点项验证恢复；原生 FormData 验证真实字段值及取消提交。
- InputGroup 附件保持静态语义，点击不替输入抢焦点；内部动作显式 Button `type="button"`。不继续要求旧附件自动聚焦行为。
- 公开中文与英文指南同时分发，`design.en.md` 与 `design.md` 并列，生成仍由主代理统一执行。
- 本代理只做源码、定点类型及脚本语法/纯逻辑回归；构建、打包、安装夹具与浏览器运行由主代理执行。未运行的状态必须为 NOT_RUN，不把脚本准备当运行成功。
