# 基础层：法度、关系与当前取值

## Status

Applied（2026-10-03 初版；2026-10-07 按表达九法重写）。设计依据是根 [design.md](../../design.md) 的总纲、器用六法与表达九法；实现规则见 [STANDARDS.md](../../STANDARDS.md)。值写在 `packages/ui/tokens/*.css`，本文说明每个值从哪里来。

初版把基础层写成逐值分类的审计记录，后续打磨又不断追加段落，出现了互相矛盾的描述（只读的外观、Badge 是否描边、禁用是否降透明度）。2026-10-07 重写时只保留当前事实；被取代的裁决记在文末「沿革」，不再散落正文。

## 来源分类

《礼记·月令》：「物勒工名，以考其诚。」每个值必须能指出它的来源：

| 来源 | 含义 | 修改方式 |
|---|---|---|
| **锚点** | 人选定的自由值，基础层只有少数几个 | 改锚点，派生值随之改变 |
| **派生** | 由锚点与一条写明的关系得出 | 改关系，而不是改结果 |
| **约束** | 关系给出下限或区间，取值在其中 | 说明取值与界限的距离 |
| **裁决** | 用户的明确决定，附日期 | 用户另行裁决 |
| **选择** | 几种关系都成立，择一并写明理由 | 改理由，而不是只改数 |
| **预设** | 暂时找不到关系的值 | 逐步收敛；不得写成派生 |

px 换算以根字号 16px 为基准。源码接线不等于浏览器验收；未实测的组合记为 `UNVERIFIED`，未运行的检查记为 `NOT_RUN`。

## 1. 材与分

《营造法式》：「凡构屋之制，皆以材为祖。」

| 量 | 值 | 来源 |
|---|---|---|
| 材 `--qy-cai` | 1.25rem（20px）：14px 正文的行高 | **锚点**。人读的是字，几何从正文的一行出发 |
| 分 `--qy-fen` | 材 ÷ 5 = 4px | **锚点**（除数 5 是选择）。全部几何的单位 |
| 半分 | 2px | **派生**。只用于贴身细部：轨道内缩、标记在行内的外加 |

**分格检验**：每个几何值都应能写成材与分的关系。行高全部是分的整数倍，不同文字档的行并排时基线能对齐，上下堆叠的行落在同一张 4px 格上。

## 2. 等：控件外部尺寸

| 等 | 外高 = 材 + n 分 | 横向留白 = (外高 − 分) / 2 | 圆角 = round(外高 × 5/16) | 图标 |
|---|---|---|---|---|
| `xs` | 24px（n = 1） | 10px | 8px | 14px |
| `sm` | 28px（n = 2） | 12px | 9px | 14px |
| `md` | 32px（n = 3） | 14px | 10px | 16px |
| `lg` | 36px（n = 4） | 16px | 11px | 18px |
| `xl` | 40px（n = 5） | 18px | 13px | 20px |

- **外高**：**派生**，材 + n 分。每升一等加一分。
- **窄屏**：**派生**，升一等（+1 分），窄屏的 xs 与桌面的 sm 同高；`sm:` 断点回到桌面。窄屏与粗指针是两个条件，粗指针另由触摸目标保证。
- **横向留白**：**派生**，= 纵向余量 + 2 分（纵向余量按一材的文字行计算）：文字两侧总比上下多一个组内间隔，读来是一行而不是一块。有 1px 边框时扣 1px，使文字起点与无边框形态一致。xl 原为 16px 预设，按关系收敛为 18px。
- **图标**：**派生**，= 该等字号 + 2px 取偶数：与汉字字面等高，并能在偶数外高中整像素居中。lg、xl 原为 16、18px，按关系收敛为 18、20px。
- **图标形态的留白**：**派生**，= (外高 − 图标) / 2。

**谁有权选等（裁决 2026-10-05）**：等是命令类的能力。Button 及其派生（Toggle、ToggleGroup、SegmentedControl、菜单项、CopyButton、ToolbarButton）保留五等，按钮名称随等变化，因为名称是按钮本身的一部分。

**填值控件只有一等**（裁决 2026-10-05）：Input、Textarea、Select、NativeSelect、Combobox、Autocomplete、NumberField、日期三件、TagInput、OtpField、InputGroup 不提供 `size`，只读角色层 `--qy-fill-height` / `-padding` / `-icon` / `-radius`，默认指向 md 等，紧凑密度降为 sm 等。值的文字始终是 md 文字档。依据是表达九法的**屋有大小，人无大小**：输入的值是内容，不随框变大。

**md 按钮读填值角色层**（组合验收 2026-10-05）：md 是最常与输入同行的一等，二者的关系是同高（经营位置：同行同气），所以 md 按钮的外高、圆角、留白随密度一起变；文字仍是 md 档。xs、sm、lg、xl 是位置的显式选择，不随密度。

**标记**（勾选、单选、滑块抓手）：边长 = 材 − 分 = 16px，**派生**。标记坐在标签那一行（一材）里，外加 `--qy-marker-inset` =（材 − 标记）/ 2，使标记连同空白正好占一行，多行标签时对齐第一行。与同一行里 md 图标同大。窄屏升一等到一材。密度不改标记，因为它跟随文字。原 20px 标记占满整行，并排时与上下行相碰，2026-10-07 收敛。

**开关**不是标记，是一条供一个点滑动的槽（应物象形：方以载事）：高一材、长两材 `--qy-switch-size`，**派生**。抓手与槽等距内缩，内缩量 = 焦点细线 + 焦点内线，给槽内焦点线留位；抓手圆角按同心换算。

**触摸目标** `--qy-touch-target` 44px：**选择**。粗指针下由 `touch-target` 扩展命中区，不随等与密度变化，不是 WCAG AA 的统一下限（2.5.8 基础要求 24×24px）。

## 3. 疏密：间距

邓石如：「疏处可以走马，密处不使透风，常计白以当黑。」间距是分组的第一手段，三级逐级拉开。

| 级 | 入口 | 值（默认 / 紧凑） | 来源 |
|---|---|---|---|
| 控件内 | `--qy-control-content-gap` | 6px | **派生**：1.5 分，比组内小一级，图标与名称读作一体 |
| 组内 | `--qy-field-gap`、`--qy-action-gap` | 8px | **派生**：2 分。名称、控件、说明之间；相邻动作之间 |
| 组间 | `--qy-field-group-gap`、`--qy-panel-gap` | 20 / 16px | **派生**：一个「疏密之材」，即空出一行正文 |
| 节间 | `--qy-section-gap` | 40 / 32px | **派生**：两个疏密之材 |

「疏密之材」`--qy-space-module` 默认就是材；紧凑密度把它换成 4 分，文字的材不变。

| 入口 | 值（默认 / 紧凑） | 关系 |
|---|---|---|
| `--qy-panel-padding` | 24 / 20px；≤767px 为 16px | 组间 + 1 分：面板里的内容先彼此成组，再与边框成组 |
| `--qy-panel-padding-sm` | 16 / 12px | 组间 − 1 分：Popover、Alert 通常只装一组内容 |
| `--qy-row-default` | 48 / 44px | 一个填值控件 + 上下各一个组内间隔 |
| `--qy-level-indent` | 12px | **预设** 3 分：明显小于行高，又大到一眼数得出级数；密度不改层级深度 |
| `--qy-page-gutter` | clamp(16px, 1.4vw, 28px) | **预设**，页面级 |

依赖疏密之材或填值高度的派生值声明在 `:root, [data-density]` 上：自定义属性里的 `var()` 在声明处求值后才继承，只在 `:root` 声明时，局部 `data-density` 改了锚点，派生值仍是根上的旧值。

**疏密检验**：去掉所有线与底色，分组仍然读得出来；同一关系在全库只有一个间距值。2026-10-07 之前组间（字段组 20px）与节间（20px）同值，节与节之间读不出比组更疏，已收敛。

## 4. 圆角：应物象形

**方以载事**：可操作、可编辑的范围方整，转角有缓。**圆以标点**：只有点与身份用圆（状态点、头像、单选标记、滑块抓手）。

| 入口 | 值 | 来源 |
|---|---|---|
| `--qy-radius-xs` … `-xl` | 8 / 9 / 10 / 11 / 13px | **派生 + 裁决**：r = round(外高 × 5/16)（`round(…, 1px)` 取整，故 36→11、40→13 而非 11.25、12.5），不设上限（用户裁决 2026-10-07：公共圆角更圆滑）。比例而非常数，大小控件读来同一种圆 |
| `--qy-radius-control`（`--qy-radius`、`-md`） | 10px | **派生**：md 外高 32 × 5/16 |
| `--qy-overlay-inset` | 4px | **派生**：1 分 |
| `--qy-radius-overlay` | 14px | **派生**：控件圆角 + 浮层内缩，使浮层里的行项与控件同角、且内外同心 |
| `--qy-radius-overlay-item` | 10px | **派生**：浮层圆角 − 内缩 |
| `--qy-radius-panel` | 16px | **选择**：面板是大面，取 4 分；同一比例落到面板会过方 |
| `--qy-radius-marker` | 5px | **派生**：round(标记边长 × 5/16) |
| `--qy-radius-item` | 8px（= `--qy-radius-xs`） | **选择**：行项与最小控件同角 |
| `--qy-radius-track` / `--qy-radius-slider-track` | 3px / 1px | **派生**：round(轨道高 × 5/16)，读数轨道 8、滑块轨道 4。轨道是载事的槽，转角有缓而不成胶囊；此前借用标记圆角（5px），超过轨道高的一半被裁成半圆 |

**同心**：只有同一轮廓等距内缩时，才有 r内 = max(0, r外 − inset)。负值退化为直角。独立子对象（Card 里的按钮）保持自己的角色，不随外层换算。轨道内的候选、开关抓手、浮层行项、编辑边界内的附属动作（外圆角 − 1px 边框）都按同心换算。

## 5. 线：骨法用笔

| 规则 | 来源 |
|---|---|
| 线只在面无法划出范围时出现。填充已划出范围就不再描边；底色与承载面相同时由线承担边界 | **裁决**（「和背景色一致时才保留边框」）；由骨法用笔推出 |
| 线宽统一 1px；强调靠墨色加深，不加粗 | **裁决**（「不做加粗，只做加黑」）；由骨法用笔推出 |
| 一个范围只用一种边界机制，线、底色与阴影不叠加 | **派生**（NG11） |
| 焦点是唯一的例外宽度，见 §15 | **约束**：焦点必须一瞥可见 |

| 部位 | 机制 |
|---|---|
| Button `solid` | 填充，无线 |
| Button `bordered` | 纸色底 + 淡墨线：按钮是命令，不用表示「可编辑」的重墨线；识别由焦墨文字或图标承担 |
| Button `quiet` | 无底无线，文字与图标识别入口 |
| Input 等填值控件 | 共同编辑边界：重墨线 |
| Card、Popover、浮层 | 清墨容器线 + 承载面 |
| 并列候选的轨道 | 纸色底 + 清墨线；候选项无线无底 |
| Badge | 无底无边，只是一段有墨色或状态色的字：标记是信息不是动作，不需要范围 |

## 6. 面与浮起：绘事后素

| 入口 | 用途 |
|---|---|
| `--qy-background` | 页面底纸：纸上一层清染 |
| `--qy-surface` | 面板：纸本色 |
| `--qy-surface-raised` | 临时浮起：浮层、Tooltip、Toast |
| `--qy-surface-inset` | 内嵌承载面、悬停：清染 |
| `--qy-surface-active` | 按下：淡染 |
| `--qy-surface-subtle` | 不透明的清染：头像回退、Kbd |
| `--qy-neutral-soft` | 墨的柔底：清染（4%）、透明叠合；中性 Alert。放在任何纸上都比所在的纸深一级。彩色柔底取 8%，墨取 4%：同浓度时黑墨比明亮色相暗得多，取染的浓度两者才读来同重 |
| `--qy-groove-surface` | 读数的凹槽（进度、计量、滑块轨道）：不透明的淡墨，是读数的一半，必须在任何承载面上可见 |
| `--qy-overlay` | 阻断遮罩：影，不是墨，**预设** |

**阴影只表达真实的浮起**：浮层盖在内容之上（`shadow-raised`），对话框阻断工作面（`shadow-overlay`）。同一平面上的东西不加阴影：Card 默认无阴影；分段控件与切换组的选中项、滑块抓手在 2026-10-07 去掉了阴影，因为填充已经划出范围（NG11、NG12）。阴影参数为**预设**。

**正常状态不铺灰底**（裁决 2026-10-05）：灰是一级墨，必须有它要说明的事实。

**临时浮起的统一画法**（NG3）：所有浮层取 `rounded-overlay` + 清墨容器线 + `surface-raised` + `shadow-raised`。浮层与触发器间隔 1 分，避免两道边框贴成一条粗线（**预设**）。列表项最小高度取同等控件外高，水平留白 = 同等带框控件留白 − 浮层内缩，候选文字与触发器文字同一起点（**派生**）。选中是事实，用尾部对勾；高亮是位置，用底色；二者可同时存在。

**编辑边界内的附属动作**：清除、展开、显示密码、日历入口放在值的编辑边界之内，无独立边框，铺满边框内高度，圆角为外圆角 − 1px（`src/input-adjunct.ts`）。

**并列候选的轨道**：同一个名字命名、方向键作为一个单位操作的候选集合，是同一个控件的几段。轨道外高 = 同等控件外高，候选高 = 外高 − 2 × 内缩 − 2px 边框，内缩半分，候选圆角按同心换算（`src/track.ts`）。消费者：SegmentedControl、ToggleGroup。单独的 Toggle 不受此约束。

**导航线**（2026-10-07，用户评「导航最丑陋」后重画）：标签页与导航菜单是「在几个目的地之间走动」，分段控件是「选一个值」，名实不同，画法也不同——此前把 Tabs 画进轨道是名实不符。目的地下面一道清墨基线；当前项把基线上自己那一段加深为焦墨（状态只加深已有的线）；未到达的目的地浓墨，悬停与当前焦墨；当前项不改字重，免得整排跳动；目的地之间一个组间距（`src/nav-line.ts`）。
**侧栏**：铺底纸色；当前项是一张纸（纸本色），比四周更亮；悬停清墨；条目带图标位，图标随文字墨色；收起是右上角的图标按钮。收起时悬停出现的名称立即出现（不用提示框的默认延迟）：它不是辅助说明，是被收起的名字本身。

**染随面积**（2026-10-07）：同一浓度的染，铺满一整行与染在一个小条目上读来轻重不同——面积越大，染越淡。小条目的当前项用淡染（12%）；表格里的当前行用清染（4%）。

**正文不立页面标题**（2026-10-08，用户裁决）：位置由面包屑与侧栏说明，正文里再写「概览」「设置」是重复；页面级的操作（时间范围、新建）放进顶栏或工具条末端。对象页的名称不是页面标题，是对象本身，保留。设置的分组是侧栏里的二级导航，一组一个地址，正文只放这一组；卡片标题只在说出导航没说的东西时才写。设置列表：名称在左、开关在右，行线贯通。

**按钮的外层包裹**：外层只在出现结果文字（等待、失败等）时才是一个盒；平时 `display: contents`，按钮本身就是布局项——调用方写在按钮上的外边距、对齐、不收缩直接生效。此前它恒为一个行内盒，`ms-auto`、`shrink-0` 落在看不见的一层上而失效。

**图标**（2026-10-08，用户要求更美观的开源图标）：Tabler Icons（MIT）。全部是线性描边，24 格网、圆头圆角，与「以线立形」一致。描边沿用 2/24，渲染在 14–20px 图标上是 1.17–1.67px，与正文笔画同一轻重区间；唯一例外是步骤标记里 12px 的对勾（2.5，渲染 1.25px），否则不足 1px 读不清。规则写在 `styles.css` 一处。

**示例应用暴露的四处修正**（2026-10-07，搭建 `/examples/workspace` 时发现）：
- 抽屉贴着视口一边：贴边那一侧没有圆角也没有线——它是从边上拉出来的，不是浮在空中的卡（应物象形）。
- 状态点的名字跟随所在那一行的字号与字重（与 Badge 同一规则）；此前固定为 13px 中等字重，放进表格整列偏重。
- 危险确认的触发按钮用描边加同一色调，实心危险色只留给对话框里最后确认的那一下（君位：一个流程一个最重点）；触发按钮同时关联快照里的后果，读屏在按下之前即可听到。
- 侧栏内容区是网格，被拉高时不得把多余高度分给各组（`content-start`），组间始终一个组间距。

**批量动作条**：一行说完——已选几项、是哪些（浓墨，单行截断），右边是动作；选中时就地替换工具条，同一行、同一高度，列表不跳。范围名与各对象版本是执行前核对的事实，交给读屏与快照，不铺在界面上（NG8）。工作台的过滤即输即滤，不设草稿与「应用」：过滤廉价且可逆，草稿与应用只用于代价高或不可逆的条件。
**面包屑**：成排的上级由位置表明可去，平时浓墨、无下划线，悬停加深并出现下划线；分隔为重墨小箭头，只作装饰；当前页焦墨。

**成对与成列的数据（比较表，2026-10-07 重画）**：数据集合是独立对象，铺一张纸（纸本色 + 清墨线 + 面板圆角，`TableContainer`）；表名在纸内第一行。表头与合计行用清染底划出范围，不再画重墨线（NG11）；行与行之间一道清墨线。单元格左右各半个组间距，列与列之间正好一个组间距；首尾单元格留面板内缘。正文一行 = 一个控件 + 上下各一个组内间隔（48），表头与合计行 = 一材 + 上下各一个组内间隔（36）。列标题 13px 浓墨中等字重；可排序的列名与其他列名同墨，只有正在排序的那一列是当前状态，转焦墨（一行表头不出现两种墨来区分「能不能排序」，能力由悬停与箭头说明）。行标题靠位置识别，不加字重。数字列右对齐、等宽数字，排序箭头放在文字前。标记列由内容定宽（`w-px`），留白与文字列同一条规则（原 `--qy-table-cell-tight` 已删除）。名称与值的列表由列表定列（`max-content minmax(0,1fr)`），条目 `subgrid`。`marker`、`numeric` 是列元数据，库不猜列名。

**浮层里的条目**（2026-10-07 收拢）：候选项（Select、Combobox、Autocomplete）与菜单项是同一种关系——浮层纸上的一行可选之物，圆角、高亮、禁用同一来源（`src/overlay-item.ts`）。二者只差一处：候选项是值，行高跟随填值角色层、随密度降档；菜单项是命令，行高跟随按钮尺寸档。候选项上下留白 = (填值外高 − 行高) / 2，一行时正好一个填值控件高，折行时留白不变。此前 Select 的候选项读固定的 md 尺寸，紧凑密度下不降档，与另两者不一致。

**列表为空时**（随境取度）：候选列表、树这类「一列可选之物」为空时，那句话坐在第一项的位置上——同一起点、同一行高、同一字号，浓墨；浮层里不放整块 Empty，空列表也不保留内缩。整块区域（图表、数据表、页面的一节）为空时才用 `Empty` 的三态（空、未知、不适用）。

**树的层级**（2026-10-07）：下一级从上一级内容列的起点开始，缩进 = 展开列宽 + 动作间隔（32），于是子项的展开钮落在父项名称（可勾选时为父项标记）之下，每一级各成一列；`--qy-level-indent`（12）只用于没有展开列的纯文字层级（阅读目录）。可勾选的树：值只含叶子 id，分支的勾选、半选是派生显示，不写回值（不重复计数）；禁用叶子不被级联改动；勾选与单选不在同一棵树上并用——一行只有一个点击目标、一个空格动作。勾选标记读 Checkbox 的标记角色 token，居中由所在行的 items-center 给出。

**侧栏**（2026-10-07 重画）：收起是同一张底面变窄成图标栏，不是换成另一样东西。栏宽 = 填值外高 + 两侧浮层内缩，图标在同一列；组名收起时只对读屏保留，组间靠疏密分开，不加线。名称由悬停提示给出。二级导航：展开时内嵌，子项文字与父项文字同一条竖线，一道清墨引导线从父项图标中线垂下；收起时子级在浮层里打开（目的地是链接，用 Popover，不用 Menu 的命令语义）。当前位置在子级时，父项只加深文字，不加新形状。当前项的画法随承载面：侧栏铺在比纸深一级的底上，当前项回到纸色；浮层本身是纸色，当前项用淡染——同一个「当前」，按所在的面取对比。

**长文阅读**（Prose，2026-10-07）：长文是一个独立对象，铺一张纸（纸本色 + 清墨线 + 面板圆角），与 Card 同一机制。版心 38em（阅读字号下 38 个汉字，落在每行 35–40 字之间，**预设**），纸宽 = 版心 + 两侧面板内缘。正文与界面同一套字体（用户裁决 2026-10-07：项目字体统一，`--qy-font-sans` 一个来源；曾短暂改为宋体正文，已撤回），16/28，汉字不收紧字距。段、列表、引用、代码块、表格之间一个组间距；h1/h2 前两材、h3/h4 前一材；总标题后一个组间距，其余标题后一个组内间隔——层级越高离正文越远，不倒置。长文自有标题阶梯（2026-10-08，用户评「比例与字号失调」后设）：篇 28/36、节 22/32、小节 18/28、h4 为正文加字重，每级约 1.25 倍（**预设**）；界面的 title/chapter 只差 1.2 倍、heading 与正文同大，借来做长文层级读不出来。与目录并排时，目录与文章作为一组居中，中间一个节间距。段首不缩进，分组交给段间距。引用用一道重墨竖线（没有底色，线是唯一的边界）。行内代码、代码块、表格、键位与库内同名组件同一画法；Markdown 的列对齐（`align`）盖过表头默认对齐。

**阅读目录**（Toc，2026-10-07）：与标签页、导航菜单同是「在目的地之间走动」，导航线转到左边——一道清墨竖线贯穿列表，当前项把自己那段加深为焦墨，文字浓墨、当前与悬停焦墨，不改字重（`src/nav-line.ts` 纵向变体）。13px，条目 = 一材 + 上下各一分（28），与 chapter 标题的行盒等高；与长文并排时下移「边线 + 面板内缘」，第一项与文章标题同一条行中线。`aria-current="location"`：指向本页内的位置，不是另一页。库只管画法与当前项；标题 id、滚动容器、吸顶偏移归调用方，滚动联动是可选的 hook。

**路径的线**（Steps、Timeline，2026-10-07 收拢）：一点一线是同一种关系（`src/thread.ts`）。标记坐在第一行（一材行盒）的中线上；线从本项标记下缘起、到下一项标记上缘止，两端各留一分。标记尺寸 m 由组件给出，内缩 t = (材 − m)/2，线的上端 = (材 + m)/2 + 分，下端 = 分 − t。此前时间线只量到下一项的行盒顶部，没扣小圆点的内缩，线上方留 4px、下方留 10px。

### G9：承载面与合成

调用方必须知道实际绘制的承载面。库不自动识别父背景，也不自动补边框；项目局部变量的协议未定，记为 `UNVERIFIED`。半透明颜色按真实叠层合成：每个 sRGB 通道 = alpha × 前景 +（1 − alpha）× 底色。图片、渐变与未知祖先背景需运行时取证。

## 7. 墨与彩：墨分五色

张彦远：「运墨而五色具。」层级由一条有限的墨阶承担；墨阶外不另造灰。

| 级 | 浓度 | 角色 | 来源 |
|---|---|---|---|
| 焦 | 88% | 正文与标题、实心填充、焦点线 | **选择**：比纯黑柔，正文对纸约 16:1 |
| 浓 | 66% | 辅助文字 | **约束**：在最深的叠层（清染面上再叠淡染）上仍保持 4.5:1 的最淡一级，浅深两色下限约 65% |
| 重 | 50% | 必要的控件边界：填值控件、未选标记 | **裁决**（2026-10-03：与输入框同强度 50%），对白纸约 3.95:1 |
| 淡 | 24% | 读数的凹槽；命令的边界（bordered 按钮） | **选择**：再浅在白纸上看不见，再深则空轨道像已填满；填充对凹槽约 6.5:1。bordered 按钮由重降淡见沿革 2026-10-09 |
| 清 | 8% | 容器线；彩色的柔底 | **选择** |
| 清染 | 4% | 内嵌面、页面底纸 | **派生**：同级线的一半——同样的墨，一层面看上去与一道细线一样淡 |
| 淡染 | 12% | 按下 | **派生**：淡的一半 |

- **字与实心**与纸调和成不透明色：它们的对比不能随下面的叠层漂移。**线与染**保持透明：叠在任何纸上，读出来是同一级墨。
- 浅色主题的墨是黑、纸是白；深色主题的墨是白、纸是深灰（纸的三级明度为**预设**）。阶的比例两边相同。2026-10-07 起深色输入线由 44% 收敛到与浅色同为 50%。
- **随类赋彩**：彩色只表达危险、警示、成功、信息与数据系列（NG10）。状态色的色值为**预设**（2026-10-09：危险色由 Tailwind 红 500/700 改为与中性灰在 sRGB 里调和（红 70–75%）——原色彩度近 sRGB 上限，一页中性墨里唯一的高彩度读来刺眼；色相不动、彩度降下来，对比仍按真实合成校验；警示、成功、信息尚未同改）；柔底取该色的清墨浓度（8%）；墨的柔底取清染（4%，`--qy-neutral-soft`），使二者读来同重。
- **数据系列**：**文字是墨，数据是色**（2026-10-07 修订，原「单系列用焦墨」被用户指出满屏黑柱）：图里的字、轴、网格用墨阶；数据即使只有一个系列也取第一色——焦墨是正文最重的一级，一根焦墨实柱面积远大于文字，会压过图名与读数（君位、染随面积）。多个系列按 `--qy-chart-1…5` 顺序取色，相邻两色可分辨，不表示好坏。只有行内迷你趋势线仍用墨：它坐在文字行里，从属于旁边的读数。堆叠面积是大面，填充取颜料与纸调和的淡色（28%，不透明），每带上沿一道足色线交代边界；热力图取第一色一种色相，由淡到足色。五色取中国画的矿植物颜料：花青、赭石、石绿、藤黄、胭脂（2026-10-07，用户评原 Tailwind 紫粉「丑陋」后改）——沉于墨、不艳，与墨阶同一气质；色值不是凭眼取的：经 dataviz `validate_palette.js` 校验，浅色对白纸与底纸、深色对深纸，明度带、色度下限、相邻色盲 ΔE ≥ 9、正常视觉 ΔE ≥ 16、对承载面 ≥ 3:1 全部通过，前三色两两通过（散点最多三系列）。次序是色盲安全的机制，不随意调换。
- **图的纸**：图与比较表同是数据集合，同一画法——纸本色、清墨线、面板圆角与内缘（`chartFrameClassName`）。看得见的轴名只有量的名字（单位）；类别轴名（日期、来源）与刻度重复，只留给读屏与数据表表头。
- **图的标题栏**（2026-10-07，Chart、ScatterChart、Heatmap 共用 `ChartHeader` / `useChartData`）：图名在左；图例与「查看数据」在右，同一条行中线；图名所在的行恒为一个小号控件高，折行时第一行的中线不动。环形图的图例在环下——它是一个整体的几部分，名称挨着环读。「查看数据」展开时像被按下，等价数据表展开在图下。
- **趋势的两种形**：行内趋势（`Sparkline` 默认）高一材、浓墨线，从属于旁边的读数；独立成块的趋势（`appearance="area"`，指标卡）是数据，取第一色的线加与纸调和的淡面，未给宽度时铺满所在的块。
- **图的任务**（2026-10-07 扩展）：图形由任务定，不由好看定。折线/面积读随时间的量；堆叠面积与堆叠柱读构成——部分互斥、加总为整体，所以不透明、彼此相切；堆叠柱是窄条，用足色、只隔 2px 纸色；堆叠面积是大面，用与纸调和的淡色带加足色上沿（半透明的淡面叠在一起会混色，读不出边界）；横向条形读排行与长类别名；环形只拆**一个**整体（一行数据、二到五个部分），多个整体的构成比较交给堆叠柱；散点读两个量的关系；热力图读两个类别维度上的分布。
- **轴**：柱与面积从零长出来；散点不从零起，但刻度取 1、2、2.5、5 乘 10 的幂，约四五格，量全为非负时下限不低于零。轴名跟着轴走（横向条形的纵轴是类别）。堆叠时轴读的是加总，轴宽按加总估。
- **热力图**：量没有类别，只用一种色相（第一色），由与纸调和的 12% 到足色。格子相邻，读的是浓淡之差，精确值由读数与数据表承担，所以下限不必取到对纸 3:1。未知的格不进色阶，用清墨斜纹。
- **朱只一点**：默认主题没有品牌强调色，强调就是焦墨。品牌在 `html[data-brand]` 上覆写 `--qy-primary`，用法如一方印，少而明确。
- **灰度检验**：转成灰度后层级与状态仍可读；状态不只靠色相表达（结合名称、文字、图标与 ARIA）。

## 8. 文字

字号是**预设**，行高是**派生**（分的整数倍）。相邻内容档至少差约 1.2 倍；两档字号相差无几时，层级交给墨色与字重，不再加一档字号。每档自带 size / leading / tracking / weight 四项。

|---|---|---|---|
| `display-xl` | 64/80 | 600 | 落地页单独成段的大字（首页总纲），全站至多一处；行高 20 分 = 4 材（2026-10-09 用户要求总纲用更大字号且字号须为全站公共档） |
| `display-lg` / `display` | 40/48、32/40 | 600 | 页面标题 |
| `title` | 24/32 | 600 | 区块标题 |
| `chapter` | 20/28 | 600 | 小节（原 22px，与 title 读不出差别，收敛） |
| `heading` | 16/24 | 600 | 有界对象的标题 |
| `body` / `body-strong` | 14/20（一材） | 400 / 500 | 正文 |
| `reading` / `prose` | 16/28 | 400 | 长文、富文本（原 15px） |
| `support` / `label` | 13/20 | 400 / 500 | 说明与字段名；说明不得大于 label（**约束**） |
| `caption` | 12/20 | 400 | 最小的说明，仍占一材，与正文行对齐 |

控件文字档（按钮名称随等变化）：xs 12/16、sm 13/20、md 14/20、lg 16/24、xl 18/28；窄屏各自放大 1–2px（**预设**）。填值控件的值固定读 md 档。控件文字 400，Button 另以 500 表达命令名称；值与选项是内容，全部 500 会让整片中文发粗（强调是稀缺资源）。

**正文是文档的默认文字**（**派生**，以材为祖）：`styles.css` 在 `body` 上设正文四元组（14/20），没有指定文字档的内容、以及跟随所在文字的标记都从这一行继承。此前 `body` 只设字体，默认落回浏览器的 16px，标记因此比正文还大。

**行内标记的几何**（**派生**，行气、材有美）：Badge 只是文字，几何就是所在那一行。Kbd 键帽外高 4 分 = 12px 字 + 上下各 1px + 1px 清墨线，只用线一种机制，不加底色（NG11）。em 换算会落到边和线上的值一律按整像素取整（`round()`）。

**字体**（**选择**，材有美）：系统字体栈（`ui-sans-serif` → 苹方 / 微软雅黑 / Noto CJK）。中英同行时系统字体的拉丁与中文字面成对设计；另加拉丁字体会让同一行出现两套 x 高度与灰度。项目可在品牌层覆写。字距为**预设**；`utilities.css` 用 `:lang(zh/ja/ko)` 将中日韩字距设为 normal。

评审用真实标点、混排、长标签与字体回退，不只查类名。

## 9. 状态

### 归属

| 事实 | 归属与表达 |
|---|---|
| 指针、焦点、按下、展开、临时选择 | 控件与无障碍原语 |
| 选中、无效、当前项 | 控件可自持，也可受控 |
| 等待、进行中、结果未知、失败、部分成功 | 应用决定事实，界面分别表达 |
| 权限、审批、版本、持久化 | 应用 |

Button 的 `state = idle | waiting | in-progress | unknown | failed` 是**接口选择**；boolean loading 也能满足归属关系。成功由应用在对象处表达，控件不以动画或超时宣布结果。Toast 的 loading 默认 30000ms 后转为 unknown（**预设**），保留原对象内容，不等同失败。

### 动作与状态分属两个元素

按钮只承载动作（名称 + 一个状态图标），宽度不随状态改变；结果由按钮旁的状态文字表达，它不是控件，二者以 `aria-describedby` 关联。等待、进行中用中性文字；结果未知用警示色（未知不等于失败，主入口是核实）；明确失败用危险色。按钮本身不随状态染色：整个按钮变红会把「读取结果」变成「危险动作」。

### 只读与禁用

| 事实 | 含义 | 外观 |
|---|---|---|
| 只读 | 不能在这里编辑，内容仍要阅读、选取、复制 | 纸色承载面 + 清墨线，值保持焦墨；旁边给「只读」说明 |
| 禁用 | 当前不可操作 | 清染承载面 + 清墨线 + 浓墨文字；**不降整块不透明度** |

**推导（骨法用笔）**：重墨线说的是「这里可以编辑」。只读与禁用都不可编辑，线降为清墨；二者的区别落在面与字上——只读的内容仍是要读的正文，所以纸色、焦墨；禁用是当前不可操作，所以清染、浓墨。禁用不降整块不透明度，因为禁用字段的内容常常仍需要被读到。同一规则适用于全部填值控件（Input、Textarea、InputGroup、Select、NativeSelect、NumberField、OtpField、TagInput、Combobox、Autocomplete、日期三件），由 `src/fill-state.ts` 共享。不得用 `:read-only` 选择器表达只读：原生 `:read-only` 也匹配禁用的输入。Button、Toggle 等命令类的禁用仍用 `opacity-64`（**预设**），真实禁用另由原生、ARIA 与事件约束承担。

### 值以名称出现

Select 的触发器只有拿到「值 → 名称」的表（`items`）才知道怎么称呼当前值；缺少时会显示原始值。开发环境对「有值但没有 items」给出警告，生产环境不提示也不改写。

### 标记是信息，不是动作

Badge 是正文里的一段字（用户裁决 2026-10-07：不要底色，直接显示文字颜色）：没有底、边与留白，基线、字号、行高都跟随所在那一行。neutral 用浓墨；emphasis 用焦墨加中等字重；`tone`（info / success / warning / danger）由调用方声明，用该状态的文字色加中等字重。它与 StatusDot 分工：StatusDot 是「彩色圆点 + 墨色名称」，表达对象的状态。

### 不定进度与确定进度同形

两者都是实心条；确定态的宽度就是进度，不定态是一段移动的窄带（轨道的 1/5，**预设**），差别只在位置是否可知。动效归 `motion.css`（1.5s），减少动态效果时停在中点成为静止的一段。RTL 下反向。进度、计量、占比是同一种读数轨道，共用 `--qy-readout-track-size`（两分，**预设**）。

## 10. 强调与君位

功能作用与视觉强调分别判断，size、variant、tone 不代理权限。

| 表达 | 承担什么 | 不自动意味着什么 |
|---|---|---|
| `solid` | 填充承担范围与强调 | 主动作、已授权、更安全 |
| `bordered` | 与承载面同底色时由线承担范围 | 固定的第二级 |
| `quiet` | 内容识别入口 | 不重要 |
| `tone="danger"` | 危险后果语义 | 已获授权 |

**一个视图只有一个君**：君的地位先由位置与留白确立，再由尺寸与墨色加强。异常时停止可以成为君，阅读时正文可以成为君。

## 11. 交互反馈

| 部位 | 表达 | 来源 |
|---|---|---|
| solid 悬停、按下 | 填充色与纸调和，纸占一级清墨（`--qy-primary-hover`、`--qy-danger-fill-hover`） | **派生**：淡一级，仍在墨阶上；原「90% 透明度」在墨阶外另造一级灰，已收敛 |
| 悬停（bordered、quiet、未选中的候选、列表高亮） | 清墨 8% | **派生**：比静止的内嵌面（清染 4%）深一级；悬停是要被看见的反馈（用户 2026-10-07：悬停可视效果不好） |
| 按下；当前位置（导航当前页、侧栏当前项、树的选中行） | 淡染 12% | **派生**：再深一级。当前位置是持续的事实，比瞬时的悬停深，悬停当前项时不变 |
| `qy-pressable` 按下 | scale 0.97；键盘与减少动态效果下不执行 | **预设** |
| 粗指针命中 | `touch-target` 扩展到 44px | **选择** |

反馈不改变布局；pressed 不能宣布保存完成。

## 12. 动：气韵生动

动效说明真实变化，可中断，业务完成不依赖动画；同一类变化用同一节拍。时长与曲线均为**预设**。

| 入口 | 值 | 角色 |
|---|---|---|
| `--qy-duration-instant` | 0ms | 程序性即时变化 |
| `--qy-duration-press` | 100ms | 按压；浮层退出 |
| `--qy-duration-fast` | 140ms | 快速反馈；浮层进入 |
| `--qy-duration-feedback` | 180ms | 原位进入 |
| `--qy-duration-base` | 220ms | 展开、滑动 |
| `--qy-duration-slow` | 320ms | 较大范围变化；当前无消费 |
| `--qy-duration-drawer` | 450ms | 抽屉 |
| `--qy-ease-out` / `-in-out` / `-drawer` / `-spring` | 见 `components.css` | `-spring` 当前无消费 |
| `--qy-stagger` | 40ms | 内容错峰 |

Popover、Tooltip、HoverCard 的入退由 `motion.css` 拥有，起止 `scale(0.98)` 与 `opacity(0)` 为**预设**。MotionProvider 记录键盘与指针方式：键盘下即时切换；减少动态效果时删除位移与缩放，直接手势仍反映实际移动。Toast 与 FieldError 仍有局部动效，数值为**预设**。

## 13. 密度与三轴

| 轴 | 写入方 | 改变什么 |
|---|---|---|
| 品牌 | 项目写 `html[data-brand]` | 视觉身份，例如强调色与字体 |
| 明暗 | ThemeProvider 写 `.light` / `.dark`；属性模式写 `data-theme` | 墨与纸互换 |
| 密度 | 容器写 `data-density` | 紧凑 = 降一等：填值控件降为 sm 等，疏密之材从一材换成 4 分 |

紧凑不改文字、标记与触摸目标（屋有大小，人无大小）。窄屏媒体查询只管视口几何（页边距、面板内缘），与密度不共享会冲突的 token。三轴改变外观，不改变权限、保存策略或操作范围。Popover Portal 的局部密度、方向与语言须通过容器保留。

## 14. 方向与语言

优先逻辑方向；箭头定位等有物理方向理由的保留。截断、换行、平衡是按位置的**选择**，不存在「单行必截断」的禁令；必要后果不能因截断或提示消失而丢失。内置文案走 `useUILocale()`，新增同时补中文与英文。

## 15. 焦点与命中

用户的要求是「**控件外面不出现任何一圈**」，由骨法用笔推出：焦点只让已有的线加深。

### 标准要求与项目决定

- **约束，AA 2.4.7**：键盘焦点须可见，未规定统一像素宽度。[W3C：Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)
- **约束，AA 1.4.11**：识别控件或其状态所必需的非文本信息与相邻颜色至少 3:1。[W3C：Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
- **AAA 2.4.13**：面积判据，不是 AA 的 2px 宽度下限；本库不据此宣称 AAA。[W3C：Focus Appearance](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html)

### 部位与取值

| 部位 | 焦点表达 | 来源 |
|---|---|---|
| 有边框的部位（Input、bordered Button、可聚焦 Card、Popover 面板、未选标记） | 边框由静止的墨（填值控件为重、bordered 按钮为淡）加深为焦墨（`--qy-ring`），宽度仍 1px | **裁决**；骨法用笔 |
| 无效的 Input | 边框改为危险文字色，宽度不变 | **选择** |
| 实心填充（solid、选中的候选、勾选标记） | 填充内侧 2px 反色线 `--qy-focus-ring-width` | **约束**：没有线可加深；它是全库唯一的 2px 线 |
| quiet 入口 | 自身盒内 1px `--qy-focus-quiet-width` | **选择** |
| Input 附属按钮、裸 Popover 入口 | 自身盒内 2px | **选择** |
| 外围新增焦点圈 | 不允许 | **裁决**（NG9） |

强制颜色模式下 box-shadow 被系统移除，`styles.css` 用 `outline` 恢复，宽度与内缩读局部 `--qy-focus-ring-width`，颜色交给系统，`!important` 用于覆盖 utilities 层的 `outline-none`。完整强制颜色矩阵为 `UNVERIFIED`。

检查用真实 `Tab` 触发 focus-visible，等过渡至少 500ms 再读计算值：聚焦前后宽高不变，信号可见，无外扩。

`--qy-touch-target` 44px 是库内选择；[WCAG 2.2 AA 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) 基础要求为 24×24px。`touch-target` 在粗指针下自建定位上下文，命中层宽高各为 `max(100%, 44px)` 并居中；须实测不被裁切、不覆盖相邻目标或视口。

## 16. 对比底线

| 对象 | 约束 |
|---|---|
| 普通大小文字，包括辅助文字 | ≥ 4.5:1 |
| 大文本（约 ≥ 18.67px 粗体 / ≥ 24px） | ≥ 3:1 |
| 必要的控件边界、图形信息与焦点状态 | 与相邻颜色 ≥ 3:1 |

半透明层按真实合成测量，浅深分别测。`test/contrast-check.test.ts` 按墨阶解析全部库内角色组合（2026-10-07：浅深各 190 组 PASS）；源码里依赖运行时继承的 490 处上下文仍为 `UNVERIFIED`，需浏览器取证。

## 17. 内容容量

空、零、未知与不适用是不同事实，各自使用可识别的表达。截断或换行是按位置的选择；真实宽度、语言、图标、附属操作与 200% 放大共同决定容量。Button 允许标签换行，Input 让实际文本占剩余宽度。

## 18. 组合契约

| 关系 | 契约 |
|---|---|
| 相邻 | 读已有关系间隔（§3），组件不凭各自偏好增加外间距 |
| 同行 | 同高、同基线（经营位置）：md 按钮与填值控件同高；轨道外高 = 同等控件外高；标记在行内居中 |
| 嵌套 | 仅同一轮廓等距内缩才用同心换算（§4） |
| 分组 | 先用间距；围合由独立身份与删去检验决定（NG4、NG11） |
| 继承 | 密度、明暗、方向、语言按实际祖先继承；Portal 单独确认容器 |
| 一致 | 同一关系在同一产品面只有一种画法（NG3） |

### 危险后果：ButtonProtection 与外部说明

`tone="danger"` 满足任一即可：（1）位于 `ButtonProtection` 内，它接受非空 consequence，渲染可见后果并关联到按钮；（2）按钮的 `aria-describedby` 指向页面中存在且文本非空的元素。两者都不满足时开发环境抛错、生产不抛。存在非空文本不自动证明说明可见或针对当前对象，调用方仍须保证。确认步骤按风险决定，ButtonProtection 不判断权限、不发请求、不强制二次弹窗。

### 浮层所属与开启顺序

`FloatingLayerScope active` 只接收真实 modal 开启事实；`useFloatingLayer(role)` 返回样式，供公开 Positioner、Backdrop 或 Viewport 合并。层序整数（通知 5、文档候选 10、modal 30、步长 10、面偏移 1、所属候选偏移 2）为**预设**；所属候选高于父面、新开 modal 遮住旧面候选、通知低于候选是**约束**。仅客户端真实开启推进 serial；取消或受控拒绝不推进。

## 19. 对齐：经营位置与行气

谢赫「经营位置」，书法「行气」：一行之内字字相承，行与行之间气脉贯通。对齐不是逐个微调，而是让所有东西落在少数几条由材与分决定的线上。用户要求（2026-10-07）：对齐理念必须仔细打磨。

### 纵向：一行之内

| 规则 | 来源 |
|---|---|
| **按行居中，不按拉丁基线。** 同一行的元素各自在等高的行盒里居中对齐 | **派生**：中文字面居中于字身，拉丁基线对齐会让 12px 与 14px 两种字号错开小数像素，误差逐行累积（2026-10-07 实测：基线对齐的行出现 23.5px、22.75px 的高度） |
| 文字行高一律是材或分的整数倍 | **派生**（§1 分格） |
| 控件与文字同行时，文字行在控件外高里居中，偏移 = (材 + n 分 − 材) / 2 = n 分 / 2 | **派生**：五等的 n 分分别为 4、8、12、16、20px，偏移 2、4、6、8、10px，全部是整数 |
| 同一行的控件同高：md 按钮、填值控件、并列候选的轨道都读 `--qy-fill-height` | **派生**（§2、§6） |
| 图标在文字行内居中：(行高 − 图标) / 2，图标取偶数 | **派生**（§2） |
| 标记（勾选、单选）在标签行内居中，多行标签时对齐第一行 | **派生**（§2 `--qy-marker-inset`） |
| 名称列与内容列：名称放在与内容第一行等高的行盒里居中；内容是一整块（表格、图表、列表）时从顶部开始 | **派生**：名称说的是内容的第一行 |

### 横向：一列之内

| 规则 | 来源 |
|---|---|
| **一列只有一条左缘。** 有边或有底的控件，以外缘对齐这条线；没有边也没有底的入口（展开入口、行内链接、标签文字），以文字对齐这条线 | **派生**：读者看到的是有形的边；没有形的入口，看到的是字 |
| 不用按钮的留白做缩进：quiet 按钮放在一列开头时，会让文字比上下内容多缩进一个留白 | **约束**：列首的无形入口不用 quiet 按钮，改用不带留白的入口（如展开入口）或负外边距抵消 |
| 同一编辑边界内，附件与值之间是控件内间隔，只有贴边的一侧保留填值留白 | **派生**（§3、§6） |
| 数字列右对齐并用等宽数字 | **派生**：数位对齐才能比较大小 |

### 状态叠加

| 规则 | 来源 |
|---|---|
| **悬停是当前状态自己的悬停。** 选中的实心填充悬停时淡一级（`--qy-primary-hover`），不退回未选中的清墨底 | **派生**（§9 状态可以同时存在）。2026-10-07 实测：日历选中日、分段控件选中段悬停后变成浅灰底上的白字 |
| 未选中的悬停样式只在未选中时出现，不靠类名的先后去覆盖 | **约束**：tailwind-merge 保留后写的同组类，条件选择器之间由样式表先后决定，二者都不可靠 |

### 检查

逐页用脚本实测：有边或有底的元素没有半像素；同一行控件同高、同顶；行高都在 4px 格上；字号都在文字档里。截图只用于发现变化，结论以实测数值为准。
