# 基础层：法度、关系与当前取值

## Status

Applied（2026-10-03 初版；2026-10-07 按表达九法重写）。设计依据是根 [design.md](../../design.md) 的总纲、器用六法与表达九法；实现规则见 [STANDARDS.md](../../STANDARDS.md)。值写在 `packages/ui/tokens/*.css`，本文说明每个值从哪里来。

初版把基础层写成逐值分类的审计记录，后续打磨又不断追加段落，出现了互相矛盾的描述（只读的外观、Badge 是否描边、禁用是否降透明度）。2026-10-07 重写时只保留当前事实；被取代的裁决记在文末「沿革」，不再散落正文。

## 来源分类

《礼记·月令》：「物勒工名，以考其诚。」每个值必须能指出它的来源：

| 来源 | 含义 | 修改方式 |
|---|---|---|
| **锚点** | 人选定的自由值，基础层只有少数几个 | 改锚点，派生值随之改变 |
| **派生** | 由锚点与一条写明的关系得出 | 改关系，而不是改结果 |
| **约束** | 关系给出下限或区间，取值在其中 | 说明取值与界限的距离 |
| **裁决** | 用户的明确决定，附日期 | 用户另行裁决 |
| **选择** | 几种关系都成立，择一并写明理由 | 改理由，而不是只改数 |
| **预设** | 暂时找不到关系的值 | 逐步收敛；不得写成派生 |

px 换算以根字号 16px 为基准。源码接线不等于浏览器验收；未实测的组合记为 `UNVERIFIED`，未运行的检查记为 `NOT_RUN`。

## 1. 材与分

《营造法式》：「凡构屋之制，皆以材为祖。」

| 量 | 值 | 来源 |
|---|---|---|
| 材 `--qy-cai` | 1.25rem（20px）：14px 正文的行高 | **锚点**。人读的是字，几何从正文的一行出发 |
| 分 `--qy-fen` | 材 ÷ 5 = 4px | **锚点**（除数 5 是选择）。全部几何的单位 |
| 半分 | 2px | **派生**。只用于贴身细部：轨道内缩、标记在行内的外加 |

**分格检验**：每个几何值都应能写成材与分的关系。行高全部是分的整数倍，不同文字档的行并排时基线能对齐，上下堆叠的行落在同一张 4px 格上。

## 2. 等：控件外部尺寸

| 等 | 外高 = 材 + n 分 | 横向留白 = (外高 − 分) / 2 | 圆角 = round(外高 × 5/16) | 图标 |
|---|---|---|---|---|
| `xs` | 24px（n = 1） | 10px | 8px | 14px |
| `sm` | 28px（n = 2） | 12px | 9px | 14px |
| `md` | 32px（n = 3） | 14px | 10px | 16px |
| `lg` | 36px（n = 4） | 16px | 11px | 18px |
| `xl` | 40px（n = 5） | 18px | 13px | 20px |

- **外高**：**派生**，材 + n 分。每升一等加一分。
- **窄屏**：**派生**，升一等（+1 分），窄屏的 xs 与桌面的 sm 同高；`sm:` 断点回到桌面。窄屏与粗指针是两个条件，粗指针另由触摸目标保证。
- **横向留白**：**派生**，= 纵向余量 + 2 分（纵向余量按一材的文字行计算）：文字两侧总比上下多一个组内间隔，读来是一行而不是一块。有 1px 边框时扣 1px，使文字起点与无边框形态一致。xl 原为 16px 预设，按关系收敛为 18px。
- **图标**：**派生**，= 该等字号 + 2px 取偶数：与汉字字面等高，并能在偶数外高中整像素居中。lg、xl 原为 16、18px，按关系收敛为 18、20px。
- **图标形态的留白**：**派生**，= (外高 − 图标) / 2。

**谁有权选等（裁决 2026-10-05）**：等是命令类的能力。Button 及其派生（Toggle、ToggleGroup、SegmentedControl、菜单项、CopyButton、ToolbarButton）保留五等，按钮名称随等变化，因为名称是按钮本身的一部分。

**填值控件只有一等**（裁决 2026-10-05）：Input、Textarea、Select、NativeSelect、Combobox、Autocomplete、NumberField、日期三件、TagInput、OtpField、InputGroup 不提供 `size`，只读角色层 `--qy-fill-height` / `-padding` / `-icon` / `-radius`，默认指向 md 等，紧凑密度降为 sm 等。值的文字始终是 md 文字档。依据是表达九法的**屋有大小，人无大小**：输入的值是内容，不随框变大。

**md 按钮读填值角色层**（组合验收 2026-10-05）：md 是最常与输入同行的一等，二者的关系是同高（经营位置：同行同气），所以 md 按钮的外高、圆角、留白随密度一起变；文字仍是 md 档。xs、sm、lg、xl 是位置的显式选择，不随密度。

**标记**（勾选、单选、滑块抓手）：边长 = 材 − 分 = 16px，**派生**。标记坐在标签那一行（一材）里，外加 `--qy-marker-inset` =（材 − 标记）/ 2，使标记连同空白正好占一行，多行标签时对齐第一行。与同一行里 md 图标同大。窄屏升一等到一材。密度不改标记，因为它跟随文字。原 20px 标记占满整行，并排时与上下行相碰，2026-10-07 收敛。

**开关**不是标记，是一条供一个点滑动的槽（应物象形：方以载事）：高一材、长两材 `--qy-switch-size`，**派生**。抓手与槽等距内缩，内缩量 = 焦点细线 + 焦点内线，给槽内焦点线留位；抓手圆角按同心换算。

**触摸目标** `--qy-touch-target` 44px：**选择**。粗指针下由 `touch-target` 扩展命中区，不随等与密度变化，不是 WCAG AA 的统一下限（2.5.8 基础要求 24×24px）。

## 3. 疏密：间距

邓石如：「疏处可以走马，密处不使透风，常计白以当黑。」间距是分组的第一手段，三级逐级拉开。

| 级 | 入口 | 值（默认 / 紧凑） | 来源 |
|---|---|---|---|
| 控件内 | `--qy-control-content-gap` | 6px | **派生**：1.5 分，比组内小一级，图标与名称读作一体 |
| 组内 | `--qy-field-gap`、`--qy-action-gap` | 8px | **派生**：2 分。名称、控件、说明之间；相邻动作之间 |
| 组间 | `--qy-field-group-gap`、`--qy-panel-gap` | 20 / 16px | **派生**：一个「疏密之材」，即空出一行正文 |
| 节间 | `--qy-section-gap` | 40 / 32px | **派生**：两个疏密之材 |

「疏密之材」`--qy-space-module` 默认就是材；紧凑密度把它换成 4 分，文字的材不变。

| 入口 | 值（默认 / 紧凑） | 关系 |
|---|---|---|
| `--qy-panel-padding` | 24 / 20px；窄屏（< 40rem）为 16px | 组间 + 1 分：面板里的内容先彼此成组，再与边框成组 |
| `--qy-panel-padding-sm` | 16 / 12px | 组间 − 1 分：Popover、Alert 通常只装一组内容 |
| `--qy-hint-padding-inline` / `-block` | 12 / 8px（外缘到内容；不随密度） | 提示面（Tooltip、锚定通知的 tooltipStyle、数据图读数）：字与小控件同字号，行向取小控件外缘到字的距离；块向 = 读数行间 1 分 + 1 分。只有一行的 Tooltip 不读块向，高即小控件高。2026-10-13 |
| `--qy-row-default` | 48 / 44px | 一个填值控件 + 上下各一个组内间隔 |
| `--qy-level-indent` | 12px | **预设** 3 分：明显小于行高，又大到一眼数得出级数；密度不改层级深度 |
| `--qy-page-gutter` | clamp(16px, 1.4vw, 28px) | **预设**，页面级 |

依赖疏密之材或填值高度的派生值声明在 `:root, [data-density]` 上：自定义属性里的 `var()` 在声明处求值后才继承，只在 `:root` 声明时，局部 `data-density` 改了锚点，派生值仍是根上的旧值。

**疏密检验**：去掉所有线与底色，分组仍然读得出来；同一关系在全库只有一个间距值。2026-10-07 之前组间（字段组 20px）与节间（20px）同值，节与节之间读不出比组更疏，已收敛。

## 4. 圆角：应物象形

**方以载事**：可操作、可编辑的范围方整，转角有缓。**圆以标点**：只有点与身份用圆（状态点、头像、单选标记、滑块抓手）。

| 入口 | 值 | 来源 |
|---|---|---|
| `--qy-radius-ratio` | 5/16 | **预设**（用户裁决 2026-10-12：比例只写一处）：圆角与外高之比的唯一来源。没有更基本的关系推出 5/16，它来自 2026-10-07 的取向与观感；「比例而非常数」才是由关系得来的部分。此前字面 5 / 16 散在 `components.css` 七处，现在控件、标记、读数轨道、骨架条、OtpField 的格都读它，改它一处全库圆角一起变；浮层、面板与由它们内缩得到的圆角不读它 |
| `--qy-radius-xs` … `-xl` | 8 / 9 / 10 / 11 / 13px | **派生 + 裁决**：r = round(外高 × `--qy-radius-ratio`)（`round(…, 1px)` 取整，故 36→11、40→13 而非 11.25、12.5），不设上限（用户裁决 2026-10-07：公共圆角更圆滑）。比例而非常数，大小控件读来同一种圆 |
| `--qy-radius-control`（`--qy-radius`、`-md`） | 10px | **派生**：md 外高 32 × 5/16 |
| `--qy-overlay-inset` | 4px | **派生**：1 分 |
| `--qy-radius-overlay` | 14px | **派生**：控件圆角 + 浮层内缩，使浮层里的行项与控件同角、且内外同心 |
| `--qy-radius-overlay-item` | 10px | **派生**：浮层圆角 − 内缩 |
| `--qy-radius-panel` | 16px | **选择**：面板是大面，取 4 分；同一比例落到面板会过方 |
| `--qy-radius-marker` | 5px | **派生**：round(标记边长 × `--qy-radius-ratio`) |
| `--qy-radius-item` | 8px（= `--qy-radius-xs`） | **选择**：行项与最小控件同角 |
| `--qy-radius-track` / `--qy-radius-slider-track` | 3px / 1px | **派生**：round(轨道高 × `--qy-radius-ratio`)，读数轨道 8、滑块轨道 4。轨道是载事的槽，转角有缓而不成胶囊；此前借用标记圆角（5px），超过轨道高的一半被裁成半圆 |

**同心**：只有同一轮廓等距内缩时，才有 r内 = max(0, r外 − inset)。负值退化为直角。独立子对象（Card 里的按钮）保持自己的角色，不随外层换算。轨道内的候选、开关抓手、浮层行项、编辑边界内的附属动作（外圆角 − 1px 边框）都按同心换算。

## 5. 线：骨法用笔

| 规则 | 来源 |
|---|---|
| 线只在面无法划出范围时出现。填充已划出范围就不再描边；底色与承载面相同时由线承担边界 | **裁决**（「和背景色一致时才保留边框」）；由骨法用笔推出 |
| 线宽统一 1px；强调靠墨色加深，不加粗 | **裁决**（「不做加粗，只做加黑」）；由骨法用笔推出。值在 `--qy-line-width`，裸写的 `border*` / `divide-*` 读它（见「系统角色令牌」） |
| 一个范围只用一种边界机制，线、底色与阴影不叠加 | **派生**（NG11） |
| 焦点是唯一的例外宽度，见 §15 | **约束**：焦点必须一瞥可见 |

| 部位 | 机制 |
|---|---|
| Button `solid` | 填充，无线 |
| Button `bordered` | 纸色底 + 淡墨线：按钮是命令，不用表示「可编辑」的重墨线；识别由焦墨文字或图标承担 |
| Button `quiet` | 无底无线，文字与图标识别入口 |
| Input 等填值控件 | 共同编辑边界：重墨线 |
| Card、Popover、浮层 | 清墨容器线 + 承载面 |
| 并列候选的轨道 | 纸色底 + 清墨线；候选项无线无底 |
| Badge | 无底无边，只是一段有墨色或状态色的字：标记是信息不是动作，不需要范围 |

## 6. 面与浮起：绘事后素

| 入口 | 用途 |
|---|---|
| `--qy-background` | 页面底纸：纸上一层清染 |
| `--qy-surface` | 面板：纸本色 |
| `--qy-surface-raised` | 临时浮起：浮层、Tooltip、Toast |
| `--qy-surface-inset` | 内嵌承载面：清染（4%），静止 |
| `--qy-surface-hover` | 悬停与键盘高亮：清染（4%，用户裁决 2026-10-12，**预设**），透明叠合，在所坐的面上深一级 |
| `--qy-surface-selected` | 持续的选中 / 当前 / 展开：清染（4%，同上，**预设**），与悬停同一级，**悬停不深于选中**。全库唯一的「当前」面：`--qy-sidebar-current`、`--qy-track-selected` 只是它的别名，导航当前页、分页当前页、树与表格的选中行、日期区间、`aria-expanded` 的展开项都读它 |
| `--qy-surface-active` | 按下：清墨（8%，同上，**预设**），再深一级，只在按下的一瞬 |
| `--qy-surface-strong` | 静止的深一级墨面：清墨（8%）。小面积的占位条（`SkeletonLine`）与数据图的参照带。此前借用悬停面，悬停改为 4% 后名实不符，改读此角色，视觉不变；高对比偏好下钉在 8% |
| `--qy-surface-subtle` | 不透明的清染（当前没有库内消费者；头像回退改读 `--qy-neutral-soft`，Kbd 只用线） |
| `--qy-neutral-soft` | 墨的柔底：清染（4%）、透明叠合；中性 Alert。放在任何纸上都比所在的纸深一级。彩色柔底取 8%，墨取 4%：同浓度时黑墨比明亮色相暗得多，取染的浓度两者才读来同重 |
| `--qy-groove-surface` | 读数的凹槽（进度、计量、滑块轨道）：不透明的淡墨，是读数的一半，必须在任何承载面上可见 |
| `--qy-code-surface` | 代码块的面：取页面底纸本身（`var(--qy-background)`，用户裁决 2026-10-12：要比白纸深一点点，且取值须与背景有关系），不另写浓度 |
| `--qy-overlay` | 阻断遮罩：影，不是墨，**预设** |

**阴影只表达真实的浮起**：浮层盖在内容之上（`shadow-raised`），对话框阻断工作面（`shadow-overlay`）。通知（Toast）也盖在内容之上，读同一级 `shadow-raised`（用户裁决 2026-10-13；此前只有一道线，是全库唯一没有阴影的浮起面）。同一平面上的东西不加阴影：Card 默认无阴影；分段控件与切换组的选中项、滑块抓手在 2026-10-07 去掉了阴影，因为填充已经划出范围（NG11、NG12）。阴影参数为**预设**。

**反馈梯**（用户裁决 2026-10-30，取代 2026-10-12「悬停 = 选中」；更早取代过 4% / 8% / 12% 三级与「当前位置用淡染」）：静止 → 悬停（清染 4%）→ 选中 / 当前（清墨 8%）；按下也读清墨 8%，只在一瞬。三者都是同一种墨的透明叠合，各自相对「它所坐的那张面」深一级，与底色的关系由叠合给出，不写不透明色值。起因：悬停 = 选中时，指针停在哪一项，那一项就和当前项一模一样，读者分不清「我在哪」与「我要去哪」；悬停浅、当前深是主流导航与列表的共同做法（Primer、Fluent、Material 3、Linear）。关系：选中 = 悬停的两倍，与「按下 = 悬停的两倍」、实心填充「悬停让一级、按下让两级」同一比例；全部从墨原子 `--qy-ink-qing` 推出（清染 = 清 / 2），调这一个原子，线、悬停、选中与按下一并移动。浓度的起点（清 = 8%）仍是**预设**。规则：悬停是瞬时的预告，选中是持续的事实，预告不能压过事实，所以悬停不深于选中；**颜色不是唯一信号**（WCAG 1.4.1）：列表类的当前项（侧栏、分页、树）另加字重，分段控件与切换按钮由位置与轨道给出，表格行由选择框给出。静止的面读 `--qy-surface-inset` / `--qy-neutral-soft` / `--qy-surface-strong`，不借用状态面（名实相符）。静止面的悬停若只改底色会看不出，这样的部位必须另有悬停信号：填值控件悬停把边框从重墨加深到浓墨（`--qy-border-strong`，2026-10-30 起不再等于输入边界）；没有其他信号的部位悬停加深到按下面，并说明关系。

**当前用面还是用线**（2026-10-30 写定，此前散在各组件）：在一列同类的对象或去处中选出一个，用面（侧栏、分页、树、表格行、日历区间）；在同一区域内切换内容，或指向页内的一个位置，用线（Tabs、Toc）。同一个条目上不并用直线与圆角填充面（2026-10-12 裁决仍有效）。

**实心填充与危险柔底的按下**（用户裁决 2026-10-13）：与中性反馈梯同一关系——按下 = 悬停的两倍。实心填充悬停让出一级清墨给纸（`--qy-primary-hover`、`--qy-danger-fill-hover`），按下让出两级（`--qy-primary-active`、`--qy-danger-fill-active`）；危险的 bordered / quiet 按钮悬停读 `--qy-danger-soft`（一级），按下读 `--qy-danger-soft-active`（两级）。此前这几档按下与悬停同值，按下只剩 0.97 的缩放，减少动效与键盘操作时没有反馈。全部仍从 `--qy-ink-qing` 推出；份额（一级 / 两级）是**预设**。高对比偏好下这些份额钉在原值（8% / 16%）：随墨阶到 24% / 48% 时填充上的字不足 4.5:1（浅色实测：危险填充悬停 4.48:1、按下 2.67:1；悬停那一档此前就不足，只是没有被检查到）。`contrast-check` 现在检查悬停与按下两档填充上的字。

**浮层与触发器的间隔**（用户裁决 2026-10-13）：所有锚定在触发器上的浮层都离开触发器 1 分（`--qy-popup-offset`）。此前 Menu、Select、Combobox、Autocomplete 取 4px，Popover、Tooltip、HoverCard 取 Base UI 的默认 0，面板的边直接贴着触发器。令牌登记为 `<length>`（`@property`），`floating-layer.tsx` 的 `popupOffset()` 在每次定位时读它并交给定位器的 `sideOffset`；调用方显式传入 `sideOffset` 时以调用方为准。

**代码面**（2026-10-12）：取页面底纸本身，不另写浓度。代码块坐在卡片或面板（纸本色）上时比所坐之处深一级；坐在页面底纸上时与页面没有底色差，范围只由一条清墨容器线划出。同一后果的另一面：代码块标题栏里选中的段与侧栏当前项（都是选中面叠在底纸上）在浅深两主题里读出同一种颜色（浅色 235 灰，深色 32 灰，实测合成值）。

**正常状态不铺灰底**（裁决 2026-10-05）：灰是一级墨，必须有它要说明的事实。

**临时浮起的统一画法**（NG3）：所有浮层取 `rounded-overlay` + 清墨容器线 + `surface-raised` + `shadow-raised`（Tooltip 也有线，2026-10-30 补齐）。线与阴影并用**不是** NG11 的重复划界：线划出范围，阴影表达这一层盖在内容之上——二者说的是两件事；深色主题下阴影几乎看不见，能给出边缘的只有线。浮层与触发器间隔 1 分，避免两道边框贴成一条粗线（**预设**）。列表项最小高度取同等控件外高，水平留白 = 同等带框控件留白 − 浮层内缩，候选文字与触发器文字同一起点（**派生**）。选中是事实，用尾部对勾；高亮是位置，用底色；二者可同时存在。

**编辑边界内的附属动作**：清除、展开、显示密码、日历入口放在值的编辑边界之内，无独立边框，铺满边框内高度，圆角为外圆角 − 1px（`src/input-adjunct.ts`）。

**并列候选的轨道**：同一个名字命名、方向键作为一个单位操作的候选集合，是同一个控件的几段。轨道外高 = 同等控件外高，候选高 = 外高 − 2 × 内缩 − 2px 边框，内缩半分，候选圆角按同心换算（`src/track.ts`）。消费者：SegmentedControl、ToggleGroup。单独的 Toggle 不受此约束。

**导航线**（2026-10-07，用户评「导航最丑陋」后重画）：标签页与导航菜单是「在几个目的地之间走动」，分段控件是「选一个值」，名实不同，画法也不同——此前把 Tabs 画进轨道是名实不符。目的地下面一道清墨基线；当前项把基线上自己那一段加深为焦墨（状态只加深已有的线）；未到达的目的地浓墨，悬停与当前焦墨；当前项不改字重，免得整排跳动；目的地之间一个组间距（`src/nav-line.ts`）。
**侧栏**：铺底纸色；当前项是叠在这张底上的选中面（`--qy-surface-selected`，用户裁决 2026-10-12：选中色全库只有一种，且与底色有关系；取代此前「当前项是纸本色、侧栏近纸色时改为淡染」的角色画法），不随承载面改写，浮层子级也不再局部覆写；当前项只由这张面标出，**不画线**（用户裁决 2026-10-12：直的墨线与圆角的填充面不在同一个条目上并用；只用线如 Toc、Tabs 可以，只用圆角填充面如侧栏当前项也可以）；悬停浅一级（清染 4%），当前项是清墨 8% 并加字重（2026-10-30）；条目带图标位，图标随文字墨色；收起是右上角的图标按钮。收起时悬停出现的名称立即出现（不用提示框的默认延迟）：它不是辅助说明，是被收起的名字本身。

**染随面积**（2026-10-07；2026-10-12 反馈梯之后）：同一浓度的染，铺满一整行与染在一个小条目上读来轻重不同——面积越大，染越淡。2026-10-07 曾让小条目的当前项用淡染（12%）、表格当前行用清染（4%）；现在所有「当前」都是同一面（`--qy-surface-selected`，4%），不再按面积分两级（用户裁决 2026-10-12：选中面必须一致）。小面积的静止占位条仍按面积深一级，读 `--qy-surface-strong`（8%）。

**正文不立页面标题**（2026-10-08，用户裁决）：位置由面包屑与侧栏说明，正文里再写「概览」「设置」是重复；页面级的操作（时间范围、新建）放进顶栏或工具条末端。对象页的名称不是页面标题，是对象本身，保留。设置的分组是侧栏里的二级导航，一组一个地址，正文只放这一组；卡片标题只在说出导航没说的东西时才写。设置列表：名称在左、开关在右，行线贯通。

**按钮的外层包裹**：外层只在出现结果文字（等待、失败等）时才是一个盒；平时 `display: contents`，按钮本身就是布局项——调用方写在按钮上的外边距、对齐、不收缩直接生效。此前它恒为一个行内盒，`ms-auto`、`shrink-0` 落在看不见的一层上而失效。

**图标**（2026-10-08，用户要求更美观的开源图标）：Tabler Icons（MIT）。全部是线性描边，24 格网、圆头圆角，与「以线立形」一致。描边沿用 2/24，渲染在 14–20px 图标上是 1.17–1.67px，与正文笔画同一轻重区间；唯一例外是步骤标记里 12px 的对勾（2.5，渲染 1.25px），否则不足 1px 读不清。规则写在 `styles.css` 一处。

**示例应用暴露的四处修正**（2026-10-07，搭建 `/examples/workspace` 时发现）：
- 抽屉贴着视口一边：贴边那一侧没有圆角也没有线——它是从边上拉出来的，不是浮在空中的卡（应物象形）。
- 状态点的名字跟随所在那一行的字号与字重（与 Badge 同一规则）；此前固定为 13px 中等字重，放进表格整列偏重。
- 危险确认的触发按钮用描边加同一色调，实心危险色只留给对话框里最后确认的那一下（君位：一个流程一个最重点）。（2026-10-10 用户裁决后：触发按钮不再关联后果，后果是对话框的说明。）
- 侧栏内容区是网格，被拉高时不得把多余高度分给各组（`content-start`），组间始终一个组间距。

**批量动作条**：一行说完——已选几项、是哪些（浓墨，单行截断），右边是动作；选中时就地替换工具条，同一行、同一高度，列表不跳。范围名与各对象版本是执行前核对的事实，交给读屏与快照，不铺在界面上（NG8）。工作台的过滤即输即滤，不设草稿与「应用」：过滤廉价且可逆，草稿与应用只用于代价高或不可逆的条件。
**面包屑**：成排的上级由位置表明可去，平时浓墨、无下划线，悬停加深并出现下划线；分隔为重墨小箭头，只作装饰；当前页焦墨。

**成对与成列的数据（比较表，2026-10-07 重画）**：数据集合是独立对象，铺一张纸（纸本色 + 清墨线 + 面板圆角，`TableContainer`）；放进已有的一张纸（Card）时 `framed={false}`，不铺第二张（NG11，2026-10-10）；表名在纸内第一行。表头与合计行用清染底划出范围，不再画重墨线（NG11）；行与行之间一道清墨线。单元格左右各半个组间距，列与列之间正好一个组间距；首尾单元格留面板内缘。正文一行 = 一个控件 + 上下各一个组内间隔（48），表头与合计行 = 一材 + 上下各一个组内间隔（36）。列标题 13px 浓墨中等字重；可排序的列名与其他列名同墨，只有正在排序的那一列是当前状态，转焦墨（一行表头不出现两种墨来区分「能不能排序」，能力由悬停与箭头说明）。行标题靠位置识别，不加字重。数字列右对齐、等宽数字，排序箭头放在文字前。标记列由内容定宽（`w-px`），留白与文字列同一条规则（原 `--qy-table-cell-tight` 已删除）。名称与值的列表由列表定列（`max-content minmax(0,1fr)`），条目 `subgrid`。`marker`、`numeric` 是列元数据，库不猜列名。

**浮层里的条目**（2026-10-07 收拢）：候选项（Select、Combobox、Autocomplete）与菜单项是同一种关系——浮层纸上的一行可选之物，圆角、高亮、禁用同一来源（`src/overlay-item.ts`）。二者只差一处：候选项是值，行高跟随填值角色层、随密度降档；菜单项是命令，行高跟随按钮尺寸档。候选项上下留白 = (填值外高 − 行高) / 2，一行时正好一个填值控件高，折行时留白不变。此前 Select 的候选项读固定的 md 尺寸，紧凑密度下不降档，与另两者不一致。

**列表为空时**（随境取度）：候选列表、树这类「一列可选之物」为空时，那句话坐在第一项的位置上——同一起点、同一行高、同一字号，浓墨；浮层里不放整块 Empty，空列表也不保留内缩。整块区域（图表、数据表、页面的一节）为空时才用 `Empty` 的三态（空、未知、不适用）。

**树的层级**（2026-10-07）：下一级从上一级内容列的起点开始，缩进 = 展开列宽 + 动作间隔（32），于是子项的展开钮落在父项名称（可勾选时为父项标记）之下，每一级各成一列；`--qy-level-indent`（12）只用于没有展开列的纯文字层级（阅读目录）。可勾选的树：值只含叶子 id，分支的勾选、半选是派生显示，不写回值（不重复计数）；禁用叶子不被级联改动；勾选与单选不在同一棵树上并用——一行只有一个点击目标、一个空格动作。勾选标记读 Checkbox 的标记角色 token，居中由所在行的 items-center 给出。

**侧栏**（2026-10-07 重画）：收起是同一张底面变窄成图标栏，不是换成另一样东西。栏宽 = 填值外高 + 两侧浮层内缩，图标在同一列；组名收起时只对读屏保留，组间靠疏密分开，不加线。名称由悬停提示给出。二级导航：展开时内嵌，子项文字与父项文字同一条竖线，一道清墨引导线从父项图标中线垂下；收起时子级在浮层里打开（目的地是链接，用 Popover，不用 Menu 的命令语义）。当前位置在子级时，父项只加深文字，不加新形状。当前项是选中面，叠在所坐的面上（侧栏底或浮层的纸色）总比它深一级——同一个「当前」，对比由叠合给出，不再按承载面分两种画法（2026-10-12 取代此前的纸本色 / 淡染两种）。

**长文阅读**（Prose，2026-10-07；版面与标题阶梯 2026-10-12 按官网文档正文收回，外框 2026-10-30 改为默认关闭）：长文通常依附在页面或面板里，默认不画框；`framed` 时铺一张纸（纸本色 + 清墨线 + 面板圆角），与 Card 同一机制，与 TableContainer 的 `framed` 同义而默认相反。行宽 = 正文字号的 40 倍（一行 40 字，**预设**），段落、列表、引用止于此；版心 38 材，代码块、表格、图可以占满；纸宽 = 版心 + 两侧 2 材内缘（`--qy-prose-measure` / `-column` / `-inset`，`tokens/components.css`）。正文与界面同一套字体（用户裁决 2026-10-07：项目字体统一，`--qy-font-sans` 一个来源；曾短暂改为宋体正文，已撤回），16/28，汉字不收紧字距。间距四级（以 `prose.css` 文件头为准）：标题到它统领的正文一个组内间隔；段、列表、引用、代码块、表格之间一材；篇首到第一节、小节之前两材；节之前四材（**预设**，比小节高一级）——层级越高离正文越远，不倒置。标题阶梯借界面的三档（2026-10-12 用户裁决：长文以官网文档正文为准）：篇 = display 32/40、节 = title 24/32、小节 = chapter 20/28，h4 为正文加字重；三档是别名，改界面那一档长文跟着变，只改长文就覆写 `--qy-text-prose-h1…h3`。沿革：2026-10-08 曾自设 28/36、22/32、18/28，官网文档没有采用，两处正文不一致，已收回。与目录并排时，目录与文章作为一组居中，中间一个节间距。段首不缩进，分组交给段间距。引用用一道重墨竖线（没有底色，线是唯一的边界）。行内代码、代码块、表格、键位与库内同名组件同一画法；Markdown 的列对齐（`align`）盖过表头默认对齐。

**阅读目录**（Toc，2026-10-07）：与标签页、导航菜单同是「在目的地之间走动」，导航线转到左边——一道清墨竖线贯穿列表，当前项把自己那段加深为焦墨，文字浓墨、当前与悬停焦墨，不改字重（`src/nav-line.ts` 纵向变体）。13px，条目 = 一材 + 上下各一分（28），与 chapter 标题的行盒等高；与长文并排时下移「边线 + 面板内缘」，第一项与文章标题同一条行中线。`aria-current="location"`：指向本页内的位置，不是另一页。库只管画法与当前项；标题 id、滚动容器、吸顶偏移归调用方，滚动联动是可选的 hook。

**路径的线**（Steps、Timeline，2026-10-07 收拢）：一点一线是同一种关系（`src/thread.ts`）。标记坐在第一行（一材行盒）的中线上；线从本项标记下缘起、到下一项标记上缘止，两端各留一分。标记尺寸 m 由组件给出，内缩 t = (材 − m)/2，线的上端 = (材 + m)/2 + 分，下端 = 分 − t。此前时间线只量到下一项的行盒顶部，没扣小圆点的内缩，线上方留 4px、下方留 10px。

### G9：承载面与合成

调用方必须知道实际绘制的承载面。库不自动识别父背景，也不自动补边框；项目局部变量的协议未定，记为 `UNVERIFIED`。半透明颜色按真实叠层合成：每个 sRGB 通道 = alpha × 前景 +（1 − alpha）× 底色。图片、渐变与未知祖先背景需运行时取证。

## 7. 墨与彩：墨分五色

张彦远：「运墨而五色具。」层级由一条有限的墨阶承担；墨阶外不另造灰。

| 级 | 浓度 | 角色 | 来源 |
|---|---|---|---|
| 焦 | 88% | 正文与标题、实心填充、焦点线 | **选择**：比纯黑柔，正文对纸约 16:1 |
| 浓 | 66% | 辅助文字 | **约束**：在最深的叠层（纸上叠按下面）上仍保持 4.5:1 的最淡一级，浅深两色下限约 65% |
| 重 | 50% | 必要的控件边界：填值控件、未选标记 | **裁决**（2026-10-03：与输入框同强度 50%），对白纸约 3.95:1 |
| 淡 | 24% | 读数的凹槽；命令的边界（bordered 按钮） | **选择**：再浅在白纸上看不见，再深则空轨道像已填满；填充对凹槽约 6.5:1。bordered 按钮由重降淡见沿革 2026-10-09 |
| 清 | 8% | 容器线；彩色的柔底；按下面（`--qy-surface-active`）与静止的深一级墨面（`--qy-surface-strong`） | **选择**（按下的取值是 2026-10-12 的**预设**） |
| 清染 | 4% | 内嵌面、页面底纸；悬停面与选中面（叠在所坐的面上） | **派生**：同级线的一半——同样的墨，一层面看上去与一道细线一样淡。悬停 = 选中 = 清染是 2026-10-12 的**预设**（反馈梯，§6） |

- **字与实心**与纸调和成不透明色：它们的对比不能随下面的叠层漂移。**线与染**保持透明：叠在任何纸上，读出来是同一级墨。
- 浅色主题的墨是黑、纸是白；深色主题的墨是白、纸是深灰（纸的三级明度为**预设**）。阶的比例两边相同。2026-10-07 起深色输入线由 44% 收敛到与浅色同为 50%。
- **随类赋彩**：彩色只表达危险、警示、成功、信息与数据系列（NG10）。状态色的色值为**预设**（2026-10-09：危险色由 Tailwind 红 500/700 改为与中性灰在 sRGB 里调和（红 70–75%）——原色彩度近 sRGB 上限，一页中性墨里唯一的高彩度读来刺眼；色相不动、彩度降下来，对比仍按真实合成校验；警示、成功、信息尚未同改）；柔底取该色的清墨浓度（8%）；墨的柔底取清染（4%，`--qy-neutral-soft`），使二者读来同重。
- **数据系列**：**文字是墨，数据是色**（2026-10-07 修订，原「单系列用焦墨」被用户指出满屏黑柱）：图里的字、轴、网格用墨阶；数据即使只有一个系列也取第一色——焦墨是正文最重的一级，一根焦墨实柱面积远大于文字，会压过图名与读数（君位、染随面积）。多个系列按 `--qy-chart-1…5` 顺序取色，相邻两色可分辨，不表示好坏。只有行内迷你趋势线仍用墨：它坐在文字行里，从属于旁边的读数。堆叠面积是大面，填充取颜料与纸调和的淡色（28%，不透明），每带上沿一道足色线交代边界；热力图取第一色一种色相，由淡到足色。五色取中国画的矿植物颜料：花青、赭石、石绿、藤黄、胭脂（2026-10-07，用户评原 Tailwind 紫粉「丑陋」后改）——沉于墨、不艳，与墨阶同一气质；色值不是凭眼取的：经 dataviz `validate_palette.js` 校验，浅色对白纸与底纸、深色对深纸，明度带、色度下限、相邻色盲 ΔE ≥ 9、正常视觉 ΔE ≥ 16、对承载面 ≥ 3:1 全部通过，前三色两两通过（散点最多三系列）。次序是色盲安全的机制，不随意调换。
- **图的纸与命名**（2026-10-13）：`framed={false}` 时图不铺自己的纸（线、底、圆角与内缘），坐在承载面上，左右缘即承载面的内容缘（**派生**，§19 一列一条左缘；与 TableContainer 的 `framed` 同义）。图内标题是否显示只看有无外部名称（`aria-labelledby` / `aria-label`），与 `framed` 无关（**约束**：同一名字不说两遍）；无标题时图例与「查看数据」仍在图内、靠行尾，二者皆无时标题栏不渲染。`label` 仍必填，命名等价数据表。名称校验先判类型再判空，报错指出是哪一项（2026-10-13：消费项目传入 undefined 时曾抛 TypeError 崩页）。
- **图的纸**：图与比较表同是数据集合，同一画法——纸本色、清墨线、面板圆角与内缘（`chartFrameClassName`）。看得见的轴名只有量的名字（单位）；类别轴名（日期、来源）与刻度重复，只留给读屏与数据表表头。
- **图的标题栏**（2026-10-07，Chart、ScatterChart、Heatmap 共用 `ChartHeader` / `useChartData`）：图名在左；图例与「查看数据」在右，同一条行中线；图名所在的行恒为一个小号控件高，折行时第一行的中线不动。环形图的图例在环下——它是一个整体的几部分，名称挨着环读。「查看数据」展开时像被按下，等价数据表展开在图下。
- **趋势的两种形**：行内趋势（`Sparkline` 默认）高一材、浓墨线，从属于旁边的读数；独立成块的趋势（`appearance="area"`，指标卡）是数据，取第一色的线加与纸调和的淡面，未给宽度时铺满所在的块。
- **行内趋势的目标带与类别**（2026-10-12，`Sparkline` 的 `band` 与 `tone`）：目标带是参照，不是数据，用墨阶里的染，不用色相；填色取清墨（8%，透明，**预设**——清染 4% 在浅色纸上过淡，8% 在两种主题、两种形下都看得出又不压过线）。纵向范围取数据与目标带的并集（**派生**：带只按数据范围画会失真）。`tone` 由调用方声明，组件不因数值越出目标带自己变色（**约束**，随类赋彩）；摘要里的「高于 / 低于 / 在目标内」是组件算得出的事实，由文字承担，区间两端含在带内，转灰度仍读得出。
- **图的任务**（2026-10-07 扩展，2026-10-12 增补占比构成）：图形由任务定，不由好看定。折线/面积读随时间的量；堆叠面积与堆叠柱读构成——部分互斥、加总为整体，所以不透明、彼此相切；堆叠柱是窄条，用足色、只隔 2px 纸色；堆叠面积是大面，用与纸调和的淡色带加足色上沿（半透明的淡面叠在一起会混色，读不出边界）；横向条形读排行与长类别名；环形只拆**一个**整体（一行数据、二到五个部分），多个整体的构成比较交给堆叠柱；散点读两个量的关系；热力图读两个类别维度上的分布。
- **图的参照与主次**（2026-10-12，Chart 的 `references`、`series[].context`、`events`）：参照、背景系列与事件帮读者定位数据，自己不是数据，所以用墨不用色（NG10）。
  - 参照带取清墨（8%）的染，画在网格之上、数据之下，不描边（**选择**：读的是带与数据的相对位置，精确范围由图例、读数与数据表承担，不要求对纸 3:1；实测 1.19 / 1.25）。
  - 参照线 1px、浓墨（66%）、`4 3` 虚线（**预设**）：与网格的清墨实线、基线的淡墨实线、悬停游标的重墨实线分开，靠更深并且是虚线；对纸 7.23 / 8.03。
  - 背景系列（同一个量的「其余」若干条）：1px 淡墨（24%）实线，不画标记，不进悬停读数，图例合成一项（`contextLabel` 必填）；不占身份色 1–5，上限 12 条（**预设**）。试过重墨 50%：六七条叠成一团深灰，与主线争位。对纸 1.78 / 2.20，低于 3:1——它的数值全在数据表里，不承载唯一信息（**选择**，如实记录）。
  - 事件点：半径 3 的实心圆加一圈纸色，落在类别轴基线上；名称进悬停读数与数据表的一列（**预设**）。
  - 参照的名称必填，范围算入量轴（**约束**，名实相符）；有带时读数给出「高于 / 低于 / 在其内」，按第一个带算（**选择**）。
  - 环形不接受参照与事件；背景系列只用于折线（**约束**）。
- **图形里的状态类别色**（2026-10-12，`--qy-{danger,warning,success,info}-graphic`）：线与填充（Sparkline、Meter 指示、Proportion 与 Chart 的段、事件点、Heatmap 分档）读这一档，不读 `-foreground`；Badge、StatusDot、Alert 的字与点仍读 `-foreground`。同一类别同一色相，按承担的角色取不同明度（先例：危险的 `-foreground` 与 `-fill`）。起因是门禁：直接用文字色时，浅色危险与警示在绿色盲下 ΔE 只有 6.2，深色危险与成功 7.5。
  - **约束**（浏览器 computed 实测）：对纸、底纸、读数凹槽均 ≥ 3:1——Meter 指示压在凹槽（墨 24%）上，这把浅色图形色限制在相对亮度 ≤ 0.146、深色 ≥ 0.35，所以四色的明度窗口很窄；四色两两正常视觉 ΔE00 ≥ 16，红、绿、蓝三种色盲模拟（Machado 2009）下 ≥ 9，实测最小值浅 24.0 / 12.2 / 12.3 / 13.1，深 37.5 / 16.5 / 10.2 / 9.5；彩度不超过数据五色。余量最薄处：浅色警示对凹槽 3.07，深色危险对凹槽 3.06，深色成功与信息在蓝色盲下 9.5。
  - **灰度**：按 CSS 灰度（不只看 OKLab L）浅深次序同为 危险 < 信息 < 成功 < 警示。只有危险与其余三色明显分开；警示与成功、成功与信息的灰度差只有 12–15，靠 2px 纸色空隙、图例次序与名称兜底（如实记录，受上面的明度窗口所限）。
  - **预设**：各色的调和配方——在「原色阶 + 墨 / 中性」里枚举，取满足全部约束、离 `-foreground` 最近的一组；为此原色阶补了五个台阶。色盲模拟是算法近似，不是真人测试。
  - **代价**（如实记录）：浅色的危险图形色比 Badge 的危险文字色深，并排时看得出差别；信息、成功、警示的图形色与数据系列的花青、石绿、赭石相近，同一张图里不会混用（系列要么全部声明类别、要么都不声明），跨图并排时较近。
- **系列的状态类别**（2026-10-12，`series[].tone`）：类别由应用声明；一张图里非背景系列要么全部声明、要么都不声明，同一类别不出现两次（**约束**，NG3、NG10）。
- **阶梯**（2026-10-12，`series[].interpolation`）：`step` 表达值在两次变化之间保持不变（设定值、阈值、库存），只对折线与各种面积生效，其他形式传入抛错（**约束**）。取 step-after：记录是「从这一刻起变成这个值」，step-before 会把变化画到观测之前（**选择**）。不提供平滑曲线：曲线画出数据里没有的值（**约束**，名实相符）。堆叠与占比的面各带共用边界，须同一种插值（**派生**）。
- **占比构成**（2026-10-12，`bar-share`、`area-share`）：读的是构成怎样变，不是多少。每行各系列归一到该行之和，量轴固定 0–100%，轴名写「量名 + 占比」——轴名说的是轴上的量（**派生**，名实相符）。刻度 0 / 25 / 50 / 75 / 100：读占比靠「一半、四分之一」（**预设**）。画法沿用堆叠的法度（**派生**）。含未知或不适用值、或和为 0 的行整行不画：整体不可得，每个占比都会是假的；已知原值只在数据表里列出（**约束**）。负值抛错；量轴上没有数量，不接受参照（**约束**）。读数与数据表同时给原值与占比（**选择**）。
- **柱上标值**（2026-10-12，`valueLabels`）：只给单系列的柱与横向柱（**约束**：并排多系列每根都标数会挤成一片，堆叠与占比的段太窄）。标了值就不再画量轴刻度与网格，基线保留（**约束**，NG1：同一事实不说两遍）。文字用墨阶、`dense`、等宽数字、焦墨——它就是读数，比刻度的浓墨深一级（**选择**）。与柱端间距一分（**预设**）；纵柱顶部余量 = 间距 + 一行字高，横柱末端余量 = 间距 + 最宽标签的估算字宽（**派生**）。至多 12 行（**预设**）。`formatValue` 返回节点时只取字符串或数字结果，与热力图格名同一规则（**约束**）。
- **堆叠的合计**（2026-10-12）：堆叠与占比的读数末尾、数据表末列给出合计；含不可得值的行不合计——已知部分的和不是合计，读数记「—」，数据表写明缺项（**约束**，名实相符）。
- **环形图例**（2026-10-12）：每项为名称加「值（占比）」，写法与 Proportion 的图例一致；总量大于各部分之和时「其余」同样给出。读数列右对齐并用等宽数字（**派生**，§19）。
- **折线的标记疏密**（2026-10-12）：点距小于两个标记宽（16px）时只画每个系列的末点（**派生**：此时标记已互相叠住，画满等于一条粗线）。
- **轴**：只有折线可以指定量轴范围（`valueDomain`）：位置编码可以不从零起，长度与面积编码不行，其他图形传入即抛错（**派生**）；已知值或参照落在范围外时抛错，不裁切。柱与面积从零长出来；散点不从零起，但刻度取 1、2、2.5、5 乘 10 的幂，约四五格，量全为非负时下限不低于零。轴名跟着轴走（横向条形的纵轴是类别）。堆叠时轴读的是加总，轴宽按加总估。
- **热力图**：量没有类别，只用一种色相（第一色），由与纸调和的 12% 到足色。格子相邻，读的是浓淡之差，精确值由读数与数据表承担，所以下限不必取到对纸 3:1。未知的格不进色阶，用清墨斜纹。
- **热力图的分档**（2026-10-12，`levels`）：档由应用声明，2 到 5 档，组件不从数值猜好坏（**选择**）。给出分档时不再用连续色阶，格子取所在档的一块色，图例是各档的色块加档名；档名进入格子的可访问名称与读数。浓淡随档次递增，与有无 tone 无关，去掉色相仍读得出次序（**约束**，灰度检验、NG10）：无 tone 的档取墨，止于重墨 50%（焦墨满格会压过图名与读数）；有 tone 的档取该类别色与纸调和到足色。无 tone 的档只能排在有 tone 的档之前，否则亮度失序，违反时抛错。第 i 档的浓度 = 12% + (i / (n − 1))^1.35 × 范围（**预设**）：下端沿用连续色阶的下限；指数取自实测——等分时深色主题下警示与危险亮度持平，1.2 在图形类别色校正后浅色 n = 5 的「危险 → 警示」失序（−0.001），1.35 下浅深两色、n = 2…5、任意相邻类别组合单调。上限 5 档也是**预设**。n = 5 时相邻档相对亮度的最小差为浅 0.012、深 0.009，肉眼可辨度为 `UNVERIFIED`；按严重度排列（无 → 成功 → 警示 → 危险）时为浅 0.107、深 0.021。换品牌色或状态色后须重测。未知的格不属于任何一档，仍是斜纹。
- **热力图的语义与键盘**（2026-10-12）：整张图是只读的 grid，格是 gridcell，每格自带完整名称（行名、列名、值，有分档时加档名）；可见的行列标题不进可访问树，免得每格重读一遍（**选择**）。整张图一个 Tab 停靠点，方向键、Home / End、Ctrl + Home / End 移动，离开再回来落在上次所在的格，RTL 下左右对调，Esc 收起读数；行尾汇总也是一格（**约束**）。此前每格一个停靠点，一张 7 × 24 的图要按 168 次 Tab 才能越过。
- **朱只一点**：默认主题没有品牌强调色，强调就是焦墨。品牌在 `html[data-brand]` 上覆写 `--qy-primary`，用法如一方印，少而明确。
- **灰度检验**：转成灰度后层级与状态仍可读；状态不只靠色相表达（结合名称、文字、图标与 ARIA）。

**高对比偏好**（2026-10-12，`tokens/contrast.css`）：`(prefers-contrast: more) and (forced-colors: none)` 时墨阶整体上移一档——焦 88→100、浓 66→88、重 50→66、淡 24→50、清 8→24；悬停与选中随墨阶上移为 12%（= 清 / 2，与默认里清染 = 清 / 2 同一关系），按下为 24%，反馈梯仍逐级加深。只用媒体查询，不是第四个主题轴；改的是原子墨阶，读它的线、字、染与组件里的直接引用一并跟随（**选择**：一处声明）。声明与 semantic 同一组选择器，局部明暗根各自重算，`html[data-brand]` 的覆写不受影响（实测）。两处偏离「整体上移」：**重只升到浓**——填值控件获焦时线由重加深为焦墨是唯一焦点信号，重升到焦则获焦前后同色（**约束**，§15；获焦前后线的对比由 4.12 / 2.61 降为 2.91 / 2.14，下限 2:1 为**预设**）；**焦升到满值**——否则浓升到 88 后辅助文字与正文同色（代价：占位字与值的差缩为 88 对 100，如实记录）。**不动**：清染（底纸与 subtle 面由它调出，图系列色与状态色在其上要 ≥ 3:1）、读数凹槽（Meter 状态色在其上要 ≥ 3:1）、状态柔底（升到 24% 成厚重色块，状态由图标与文字承担）、静止的深一级墨面（Chart 参照带与骨架占位条的填色，`--qy-surface-strong`，钉在 8%）、全部数据编码色（各有色差门禁）。尺寸、圆角、线宽、间距不变。强制颜色开启时整块不成立。消费项目若覆写墨阶原子，须在自己的覆写里同样包一层该媒体查询。

| `metric-lg` | 32/40 | 600 | 概览里居首的读数，由 Stat `size="lg"` 的 StatValue 读。字号沿用 display 已有的 32，不新开字号（**预设**）；行高 10 分 = 2 材（**派生**）；与 metric 相差 1.33 倍，满足相邻档至少 1.2 倍；字距、字重与同字号的 display 同值（**预设**） |

控件文字档（按钮名称随等变化）：xs 12/16、sm 13/20、md 14/20、lg 16/24、xl 18/28；窄屏各自放大 1–2px（**预设**）。填值控件的值固定读 md 档。控件文字 400，Button 另以 500 表达命令名称；值与选项是内容，全部 500 会让整片中文发粗（强调是稀缺资源）。

**正文是文档的默认文字**（**派生**，以材为祖）：`styles.css` 在 `body` 上设正文四元组（14/20），没有指定文字档的内容、以及跟随所在文字的标记都从这一行继承。此前 `body` 只设字体，默认落回浏览器的 16px，标记因此比正文还大。

**行内标记的几何**（**派生**，行气、材有美）：Badge 只是文字，几何就是所在那一行。Kbd 键帽外高 4 分 = 12px 字 + 上下各 1px + 1px 清墨线，只用线一种机制，不加底色（NG11）。em 换算会落到边和线上的值一律按整像素取整（`round()`）。

**字体**（**选择**，材有美）：系统字体栈（`ui-sans-serif` → 苹方 / 微软雅黑 / Noto CJK）。中英同行时系统字体的拉丁与中文字面成对设计；另加拉丁字体会让同一行出现两套 x 高度与灰度。项目可在品牌层覆写。字距为**预设**；`utilities.css` 用 `:lang(zh/ja/ko)` 将中日韩字距设为 normal。

**读数的大小只落在读数上**（2026-10-12，屋有大小，人无大小）：Stat 的 `size` 只换读数本身的文字档，由它在页面上的位置选（**选择**）；标签、单位、说明、变化量的字号不随之变（**约束**）。不提供 36 与 28 两档：它们各要新开一档字号（**选择**）。

**标题换行均衡**（2026-10-12，**选择**）：标题档（display-xl、display-lg、display、title、chapter、heading）与 PageHeader、Empty 的标题加 `text-wrap: balance`（Baseline 2024-05），折行时各行长度相近、不留孤字；单一来源是 `typography.tsx` 的 `balancedSteps`。正文与说明不加：`pretty` 仍未被普遍支持，留作观察。不支持时回落为普通换行。

评审用真实标点、混排、长标签与字体回退，不只查类名。

## 9. 状态

### 归属

| 事实 | 归属与表达 |
|---|---|
| 指针、焦点、按下、展开、临时选择 | 控件与无障碍原语 |
| 选中、无效、当前项 | 控件可自持，也可受控 |
| 等待、进行中、结果未知、失败、部分成功 | 应用决定事实，界面分别表达 |
| 权限、审批、版本、持久化 | 应用 |

Button 只有忙碌一种状态：`loading`（用户裁决 2026-10-10「功能要纯粹」，取代此前的 `state = idle | waiting | in-progress | unknown | failed`）。事实由调用方持有，按钮不启动请求、不推断结束。成功、失败与结果未知由应用用提示组件在对象处表达，控件不以动画或超时宣布结果。Toast 同理不做推测（同日裁决）：只呈现应用给出的类型，此前「loading 30000ms 后转为 unknown」的期限与 `loadingTimeout` 已移除；需要期限时由应用计时并更新这一条。

### 动作与状态分属两个元素

按钮只承载动作；忙碌时名称留在原位，后面多一个转动的记号（图标形态由记号暂时替下自己的图形），焦点不动、重复触发被挡住。「进行中」只对读屏说（不可见的 live region，以 `aria-describedby` 关联），按钮旁不再有可见的状态文字。

结果是另一个元素，而且是另一个组件（2026-10-10 裁决）：就地说明用 Alert，短暂反馈用 Toast，字段错误用 FieldError，对象状态用 StatusDot。结果未知用警示色（未知不等于失败，主入口是核实），明确失败用危险色——这些颜色属于提示组件，按钮本身不随结果染色：整个按钮变红会把「读取结果」变成「危险动作」。

### 只读与禁用

| 事实 | 含义 | 外观 |
|---|---|---|
| 只读 | 不能在这里编辑，内容仍要阅读、选取、复制 | 纸色承载面 + 清墨线，值保持焦墨；旁边给「只读」说明 |
| 禁用 | 当前不可操作 | 清染承载面 + 清墨线 + 浓墨文字；**不降整块不透明度** |

**推导（骨法用笔）**：重墨线说的是「这里可以编辑」。只读与禁用都不可编辑，线降为清墨；二者的区别落在面与字上——只读的内容仍是要读的正文，所以纸色、焦墨；禁用是当前不可操作，所以清染、浓墨。禁用不降整块不透明度，因为禁用字段的内容常常仍需要被读到。同一规则适用于全部填值控件（Input、Textarea、InputGroup、Select、NativeSelect、NumberField、OtpField、TagInput、Combobox、Autocomplete、日期三件），由 `src/fill-state.ts` 共享。不得用 `:read-only` 选择器表达只读：原生 `:read-only` 也匹配禁用的输入。Button、Toggle 等命令类的禁用仍用 `opacity-64`（**预设**），真实禁用另由原生、ARIA 与事件约束承担。

**只读的 Select 不打开**（2026-10-12，**约束**）：Base UI 1.8 起只读的 Select 可以打开浏览候选。本库不随之改变：Select 的值已经以名称显示在触发器上，打开只会给出一排点不动的选项，读作「可以改」，与上面「只读是不能在这里编辑」相悖。实现上在 `onOpenChange` 里取消只读时的打开请求，调用方的 `onOpenChange` 收不到这次请求。

### 值以名称出现

Select 的触发器只有拿到「值 → 名称」的表（`items`）才知道怎么称呼当前值；缺少时会显示原始值。开发环境对「有值但没有 items」给出警告，生产环境不提示也不改写。

### 标记是信息，不是动作

Badge 是正文里的一段字（用户裁决 2026-10-07：不要底色，直接显示文字颜色）：没有底、边与留白，基线、字号、行高都跟随所在那一行。neutral 用浓墨；emphasis 用焦墨加中等字重；`tone`（info / success / warning / danger）由调用方声明，用该状态的文字色加中等字重。它与 StatusDot 分工：StatusDot 是「彩色圆点 + 墨色名称」，表达对象的状态。

### 不定进度与确定进度同形

两者都是实心条；确定态的宽度就是进度，不定态是一段移动的窄带（轨道的 1/5，**预设**），差别只在位置是否可知。动效归 `motion.css`（1.5s），减少动态效果时停在中点成为静止的一段。RTL 下反向。进度、计量、占比是同一种读数轨道，共用 `--qy-readout-track-size`（两分，**预设**）。

### 读数轨道的分格、类别与图例（2026-10-12）

- **分格**：量是离散的 n 级时，Progress 与 Meter 的 `segments={n}` 把轨道按 n 个等宽格分开（n 为 2 以上的整数）。值必须落在格的边界上，Progress 的值不能为 null；半格的填充与「离散」名实不符，所以抛错而不取整（**约束**）。容差 1e-6 格只吸收除法舍入（**选择**）。校验只有一份（`src/segments.ts`）。
- **格间空隙**取半分（2px），与 Proportion 相邻部分之间的空隙同值（**派生**）。空隙由 CSS 遮罩切出，是透明的：库不知道承载面的颜色（G9），画上去的「纸色」缝换一张底就露馅。每格周期为 (W + g) / n，格宽为周期减 g，n 格正好铺满 W；格与缝对称，RTL 不另写。
- **类别**：Meter 的 `tone` 由调用方声明，组件不从数值猜好坏；不给时用主色。色相之外必须由格数或文字承担同一事实（灰度检验）。Progress 不加 tone：进度没有好坏（**约束**）。读出名称的有序级别不用 Meter，见下条「级别标记」；不给 StatusDot 加 level（**选择**：一个组件只承担一件事）。
- **占比的类别**：Proportion 各部分的 `tone` 要么全部声明、要么全不声明；同一 tone 不得出现两次（两段同色无法区分），违反时抛错。声明后各段与图例色块取类别色，不再按 `--qy-chart-N`（**约束**）。
- **占比的图例**：`legend="hidden"` 只改图例的承载面（视觉隐藏），不改内容——图例是整条轨道的文字等价物，不能删（**约束**）。用在旁边已有读数承担同一组数的地方。
- **级别标记**（2026-10-13，`SeverityMark`）：有次序的级别是「n 级里的第几级」，读出的是级别的名称而不是数值，所以不是 Meter（测量，读屏读数）；级别之间有次序，所以也不是 StatusDot（无序的状态）——一个组件一件事（**约束**）。级别由填满的格数承担，`tone` 只是附带的类别，由调用方声明，组件不从级别猜好坏，不给时取焦墨（**约束**，随类赋彩、灰度检验）。名称 `label` 必填，库不内置任何级别用词（**约束**，名实相符）；`level` 为 1 到 `max` 的整数、`max` 为 2 到 5 的整数，越界或非整数抛错而不取整，没有级别时不放标记（**约束**）；上限 5 与 Heatmap 分档同值（**选择**）。格高取状态点边长 `--qy-status-dot-size`（8px），与 StatusDot 同行时同高、同一条行中线（**派生**）；格间取半分（**派生**，与读数轨道分格、Proportion 同值）；格宽一分（4px，**预设**：默认三格总宽 16px 与 md 图标同宽是结果，不是推导）；圆角 = 格宽 × `--qy-radius-cap-ratio`（**派生**；格是刻度，取方，不取圆点）。未填的格是一道重墨线（`border-input`），不是凹槽的淡墨：空格是读出级数的一半，淡墨对纸不到 3:1；实测对纸 4.00 / 5.18（浅 / 深），已填格对纸 ≥ 5.47 / 6.74（**选择**；底纸与内嵌面上未测，UNVERIFIED）。标记前有一个零宽字撑起所在那一行的行高，名称隐藏（`name="hidden"`）时仍占一行，与同行文字同一条中线（**派生**，§19 行气）。根是 `role="img"`，可访问名称即 `label`，格与可见名称不进可访问树，名称只读一遍（**约束**）。强制颜色下已填为 CanvasText 实心、未填为 ButtonBorder 线，类别色收成同一色，级别仍由格数承担（**派生**）。

## 10. 强调与君位

功能作用与视觉强调分别判断，size、variant、tone 不代理权限。

| 表达 | 承担什么 | 不自动意味着什么 |
|---|---|---|
| `solid` | 填充承担范围与强调 | 主动作、已授权、更安全 |
| `bordered` | 与承载面同底色时由线承担范围 | 固定的第二级 |
| `quiet` | 内容识别入口 | 不重要 |
| `tone="danger"` | 危险后果语义 | 已获授权 |

**一个视图只有一个君**：君的地位先由位置与留白确立，再由尺寸与墨色加强。异常时停止可以成为君，阅读时正文可以成为君。

**筛选与切换不是君**（2026-10-12，用户裁决）：分段控件、切换组、独立 Toggle 的选中态与分页的当前页不读 `--qy-primary`，品牌覆写主操作的填充时它们不随之变色、不与主按钮同重。品牌如一方印，只落在主操作上（§7 朱只一点）。

## 12. 动：气韵生动

动效说明真实变化，可中断，业务完成不依赖动画；同一类变化用同一节拍。时长与曲线均为**预设**。

| 入口 | 值 | 角色 |
|---|---|---|
| `--qy-duration-instant` | 0ms | 程序性即时变化 |
| `--qy-duration-press` | 100ms | 按压；浮层退出 |
| `--qy-duration-fast` | 140ms | 快速反馈；浮层进入 |
| `--qy-duration-feedback` | 180ms | 原位进入 |
| `--qy-duration-base` | 220ms | 展开、滑动 |
| `--qy-duration-drawer` | 450ms | 抽屉 |
| `--qy-ease-out` / `-in-out` / `-drawer` | 见 `components.css` | 进入与反馈 / 原位往返 / 抽屉 |
| `--qy-duration-wait` | 1500ms | 不定长等待的一个周期：进度条一程、进行中标记（Button、Toast）一圈。同一类变化共用一个节拍（2026-10-09 之前分别是 1.5s 与 Tailwind 的 1s）。**预设** |
| `--qy-stagger` | 40ms | 内容错峰 |

Popover、Tooltip、HoverCard 的入退由 `motion.css` 拥有，起止 `scale(0.98)` 与 `opacity(0)` 为**预设**。MotionProvider 记录键盘与指针方式：键盘下即时切换；减少动态效果时删除位移与缩放，直接手势仍反映实际移动。循环动效只有两处，都说「进行中、比例未知」：进度条的移动条与进行中标记的旋转（`.qy-spin`，无公开组件：等待必须有对象）；减少动态效果时两者都停下，条与弧仍在。骨架屏不循环（等待没有变化可说）。Toast 与 FieldError 仍有局部动效，数值为**预设**。`hiddenUntilFound`（Accordion、Collapsible，默认关）被页内查找命中时由原语直接展开，不播放过渡（**派生**：Base UI 在 `beforematch` 时取 0 时长）。

## 13. 密度与三轴

| 轴 | 写入方 | 改变什么 |
|---|---|---|
| 品牌 | 项目写 `html[data-brand]` | 视觉身份，例如强调色与字体 |
| 明暗 | ThemeProvider 写 `.light` / `.dark`；属性模式写 `data-theme` | 墨与纸互换 |
| 密度 | 容器写 `data-density` | 紧凑 = 降一等：填值控件降为 sm 等，疏密之材从一材换成 4 分 |

紧凑不改文字、标记与触摸目标（屋有大小，人无大小）。窄屏媒体查询只管视口几何（页边距、面板内缘），与密度不共享会冲突的 token。三轴改变外观，不改变权限、保存策略或操作范围。Popover Portal 的局部密度、方向与语言须通过容器保留。

## 14. 方向与语言

优先逻辑方向；箭头定位等有物理方向理由的保留。截断、换行、平衡是按位置的**选择**，不存在「单行必截断」的禁令；必要后果不能因截断或提示消失而丢失。内置文案走 `useUILocale()`，新增同时补中文与英文。

**书写方向（2026-10-12）**：`UILocaleProvider` 提供 `dir`（`"ltr" | "rtl"`）。省略时由 `locale.code` 推出：先问平台（`Intl.Locale` 的 `getTextInfo()`），平台没有答案时看文字子标签，再退回语言表 `ar he iw fa prs ur ps sd ug yi dv ckb ks syr`（出处 Unicode CLDR 的从右到左排布；表是最小子集，不求穷尽，**预设**）；不认识的代码为 ltr。Provider 把方向交给 Base UI 的 `DirectionProvider`，由 `useUIDirection()` 与 `useUILocale().dir` 读出；它不渲染包裹元素，也不改写 `<html dir>`——后者由应用设置并须与 Provider 一致，否则版式（CSS `direction`）与行为（方向键、滑块增减、子菜单与浮层出现侧）分离（**约束**，实测：只改 `<html dir>` 时 Slider、Tabs 的方向键仍按 ltr，子菜单打不开）。浮层出现侧用逻辑值（`inline-start` / `inline-end`）；Toast 视口位置、Drawer 的边是物理名，保留。跟随实际排版的方向键（Heatmap、Tree）读 computed `direction`。

**标签作用域（2026-10-12，约束）**：Field 只建立一个标签作用域，域内控件共享一个 id 与一个标签。一个值的多个候选项（`Radio`、`SegmentedControlItem`）在 Field 内各自开作用域（不渲染元素的 `Field.Item`），每项有自己的 id，名称来自项自己；整组的标签、描述与错误仍落在 radiogroup。已由 `FieldItem` 包住的项不再叠加。同一字段里第二个独立控件（例如滑块旁的精确输入）用 `FieldItem` 隔开，名称写在控件上。此前 SegmentedControl 每组三项共用一个 id，Slider 与旁边的 NumberField 共用一个 id。

## 15. 焦点与命中

用户的要求是「**控件外面不出现任何一圈**」，由骨法用笔推出：焦点只让已有的线加深。

### 标准要求与项目决定

- **约束，AA 2.4.7**：键盘焦点须可见，未规定统一像素宽度。[W3C：Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)
- **约束，AA 1.4.11**：识别控件或其状态所必需的非文本信息与相邻颜色至少 3:1。[W3C：Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
- **AAA 2.4.13**：面积判据，不是 AA 的 2px 宽度下限；本库不据此宣称 AAA。[W3C：Focus Appearance](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html)

### 部位与取值

| 部位 | 焦点表达 | 来源 |
|---|---|---|
| 有边框的部位（Input、bordered Button、可聚焦 Card、Popover 面板、未选标记） | 边框由静止的墨（填值控件为重、bordered 按钮为淡）加深为焦墨（`--qy-ring`），宽度仍 1px | **裁决**；骨法用笔 |
| 无效的 Input | 边框改为危险文字色，宽度不变 | **选择** |
| 实心填充（solid、勾选标记） | 填充内侧 2px 反色线 `--qy-focus-ring-width` | **约束**：没有线可加深；它是全库唯一的 2px 线 |
| 轨道内选中的候选 | 同 quiet：段内 1px 焦墨线（Toggle 系为边框变焦墨） | **派生**：选中段是选中面而非实底（2026-10-12），不需要反色线 |
| quiet 入口 | 自身盒内 1px `--qy-focus-quiet-width` | **选择** |
| 热力图的格（填充从纸色一路深到足色） | 格内一道 2px 焦墨线，再衬 1px 纸色线 | **预设**：单一线色在中间深浅处只有约 2.5:1；两线并用后任一深浅至少一条 ≥ 3:1（实测浅色 ≥ 4.07、深色 ≥ 3.69）。只为这张图的填充跨度而设，不是全库的焦点画法 |
| Input 附属按钮、裸 Popover 入口 | 自身盒内 2px | **选择** |
| 以已有边界的控件作 Popover 入口（`render={<Button />}`） | 由该控件负责焦点与边框，入口只补命中区 | **约束**（NG11：一处负责焦点）。2026-10-12 实测，无条件附加时 bordered 的静止边框被盖掉、获焦多一圈 2px，solid / quiet 变宽 2px |
| 可滚动的表格容器 | 只在内容真的溢出时可聚焦，并成为具名区域（名称依次取调用方、caption、表的 label） | **约束**（WCAG 2.1.1 键盘可滚动；放得下的表不该多一个 Tab 停靠点）。服务端与首帧按不可滚动（**选择**：无布局可测） |
| 外围新增焦点圈 | 不允许 | **裁决**（NG9） |

强制颜色模式下 box-shadow 被系统移除，`styles.css` 用 `outline` 恢复，宽度与内缩读局部 `--qy-focus-ring-width`，颜色交给系统，`!important` 用于覆盖 utilities 层的 `outline-none`。

**强制颜色（2026-10-12）**：浏览器把 `background-color`、`color`、`border-color` 换成系统色并移除 `box-shadow`，靠填充与阴影表达的范围会消失。`styles.css` 的 `@media (forced-colors: active)` 逐类补回：焦点用 `outline`（落在 Highlight 填充的选中项上改用 `HighlightText`）；选中与当前统一用 `Highlight` / `HighlightText` 并设 `forced-color-adjust: none`（否则 Chromium 给文字垫 Canvas 底板）；二态与取值（Checkbox、Radio、Switch、Slider、Progress、Meter）补一圈 `ButtonBorder` 线并以 `Highlight` 填充；禁用用 `GrayText`；占比、热力图、图例与状态点属数据编码，保留原色，名称与数值由文字和数据表承担。补线一律负偏移 `outline`，不改尺寸（NG9）。取证见 `docs/baseline/2026-10-12-forced-colors/README.md`，脚本 `scripts/forced-colors-audit.mjs`：Chromium 153 的 `forcedColors: 'active'` 模拟下，80 个部位 × 浅深 × {边界、状态、焦点} 修复前 135 PASS / 95 FAIL，修复后 230 PASS / 0 FAIL；普通模式 182 页零像素差异。**边界**：这是模拟，不是真实 Windows 对比主题，各主题的 Highlight / GrayText 配对未逐一实测；Steps、Accordion、Timeline、Avatar、Link、Breadcrumb、Drawer、Input 的无效与只读态、Menu 勾选项、Slider 只读抓手不在矩阵内，为 `UNVERIFIED`。

检查用真实 `Tab` 触发 focus-visible，等过渡至少 500ms 再读计算值：聚焦前后宽高不变，信号可见，无外扩。

`--qy-touch-target` 44px 是库内选择；[WCAG 2.2 AA 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) 基础要求为 24×24px。`touch-target` 在粗指针下自建定位上下文，命中层宽高各为 `max(100%, 44px)` 并居中；须实测不被裁切、不覆盖相邻目标或视口。

## 16. 对比底线

| 对象 | 约束 |
|---|---|
| 普通大小文字，包括辅助文字 | ≥ 4.5:1 |
| 大文本（约 ≥ 18.67px 粗体 / ≥ 24px） | ≥ 3:1 |
| 必要的控件边界、图形信息与焦点状态 | 与相邻颜色 ≥ 3:1 |

**轨道选中面的取舍**（2026-10-12，如实记录；选中面改为 4% 后按 `tokens/*.css` 合成重算）：选中面对轨道底实测 1.09:1（浅）/ 1.11:1（深），达不到 1.4.11 的 3:1（此前 12% 时为 1.32 / 1.43，更淡了）。选中状态由面的深浅与字的墨色差共同承担：选中字对面 15.16 / 12.16，未选字对底 7.26 / 8.08。**选择**：接受这一取舍，不为凑 3:1 加线或加深面；需要更强的选中时，项目改 `--qy-surface-selected`（全库一起变），面改成实心墨时再成对改 `--qy-track-selected-foreground`。

半透明层按真实合成测量，浅深分别测。`test/contrast-check.test.ts` 按墨阶解析全部库内角色组合（2026-10-07：浅深各 190 组 PASS）；源码里依赖运行时继承的 490 处上下文仍为 `UNVERIFIED`，需浏览器取证。

高对比偏好下底线仍成立：`contrast-check` 以偏好值复验全部库内角色组合，浏览器 computed 实测 54 项 PASS（`scripts/contrast-more-audit.mjs`）。浅 / 深：可编辑线对纸 4.00→7.23 / 5.21→8.05，bordered 按钮线 1.78→4.00 / 2.19→5.21，辅助文字 7.23→16.48 / 7.24→12.22；选中段字对面 12.49→11.42 / 9.40→7.55，仍远高于 4.5:1。容器线（清）升到约 1.8 / 2.2:1，仍不到 3:1，按 §6 不承担识别。**边界**：Chromium 对媒体特性的模拟，不是真实系统设置（NOT_RUN）。

## 17. 内容容量

空、零、未知与不适用是不同事实，各自使用可识别的表达。截断或换行是按位置的选择；真实宽度、语言、图标、附属操作与 200% 放大共同决定容量。Button 允许标签换行，Input 让实际文本占剩余宽度。

## 18. 组合契约

| 关系 | 契约 |
|---|---|
| 相邻 | 读已有关系间隔（§3），组件不凭各自偏好增加外间距 |
| 同行 | 同高、同基线（经营位置）：md 按钮与填值控件同高；轨道外高 = 同等控件外高；标记在行内居中 |
| 嵌套 | 仅同一轮廓等距内缩才用同心换算（§4） |
| 分组 | 先用间距；围合由独立身份与删去检验决定（NG4、NG11） |
| 继承 | 密度、明暗、方向、语言按实际祖先继承；Portal 单独确认容器 |
| 一致 | 同一关系在同一产品面只有一种画法（NG3） |

### 危险后果：归对话框，不归按钮

**用户裁决 2026-10-10（功能要纯粹）**：「button 不应该承载警告等作用，这种场景应该使用弹框」。此前的契约（danger Button 须位于 `ButtonProtection` 内或以 `aria-describedby` 关联非空后果，否则开发环境抛错）已撤销，`ButtonProtection` 移除。现在：

- Button 只触发动作；`tone="danger"` 只是色调，不校验、不包装、不关联后果。
- 需要用户知道后果再决定时，按钮是入口，打开 AlertDialog（或带已读快照的 ConfirmAction）；后果写在对话框的说明（AlertDialogDescription）里，在最后那一下之前可见，读屏随对话框读到。
- 起因是使用方反馈：表格行里的删除入口旁摆不下一段说明，而确认弹窗不被旧诊断承认。放宽诊断条件只是给按钮的兼职打补丁；根因是按钮兼了别的组件的事。

同一条裁决下的其它处置（2026-10-10）：TooltipTrigger 不再默认渲染无框按钮，`render` 必填——提示附在调用方给出的控件上；ConfirmAction 的后果从底部动作旁移到对话框说明，入口不再挂只给读屏的后果。

### 候选浮层的分组与状态（2026-10-12）

- Select、Combobox、Autocomplete 的组名画法只有一个来源 `src/overlay-group.ts`（**约束**，NG3；抽取前后逐像素一致）。组名的留白、上 2 下 1 的间距单位、辅助字号与墨色沿用此前的 SelectGroupLabel（**预设**）。分隔线与 MenuSeparator 同一画法，分组靠间距读得出时不用（**选择**）。
- 一件事实一个播报者：「没有结果」归 Empty，Status 说加载中与结果数，结果数为 0 时不出声（**选择**）。Status 默认只给读屏，加载中可用 `visible` 与 Empty 同位显示（**派生**：结果数看列表即知）。Status 是 polite live region，保持挂载只换内容（**约束**）。加载期间不同时显示 Empty，否则等待被说成「没有结果」（§9）。
- 命令面板不是组件：Dialog + 常开内联的 Autocomplete；选 Autocomplete 是因为命令是动作，没有要保存的已确认值。快捷键由应用绑定，库不监听全局按键（**约束**）。
- `focusFirstInvalid(form)` 只读 DOM 事实：`aria-invalid="true"` 或原生 `:invalid`（不用 `:user-invalid`：提交失败时用户可能未交互过）；落点是键盘本来能到的部件，跳过本库隐藏的原生副本（**派生**）。Form 不自动落焦点，默认行为不变（**选择**）。

### 输入族的事实与认证（2026-10-12）

- 认证类输入不得拦截粘贴与自动填充（**约束**，WCAG 3.3.8）。OtpField 默认去掉空白与连字符后再校验（验证码常分组送达）；分段固定 `dir="ltr"`（数字串没有书写方向）；真实输入透明覆盖在分段上接收指针，触屏不阻止默认，让系统的长按菜单属于真实输入（**选择**）。PasswordInput 开发期缺 `autoComplete` 时警告。
- 输入法合成期间不截断、不回写，合成结束再校验（**选择**：中途改回值会打断合成；真实输入法 UNVERIFIED）。
- TagInput 的 `required` 指至少一个已确认标签（名实相符）；表单提交时非空草稿按 Enter 的规则收下，收不下就拦住 submit 并就地说明（**选择**：看得见的草稿要么入表单，要么说出为什么不能）。到达 `max` 后草稿输入禁用，但画法同只读（纸色、焦墨，线为清墨）：已确认标签仍可移除、仍要读（**派生**，§9）。方向键按 computed `direction`（**约束**：跟随屏幕排版）。
- FileUpload 以 `webkitGetAsEntry()` 识别并拒绝文件夹；粘贴只在焦点位于组件内时生效，不监听 document；文档级拖放守卫归应用（**约束**）。只读时不摆「移除」，禁用时保留并失效（§9：只读不是「此刻不可用」）；选择入口的名称落第一列，第二列留给「只读」说明。
- 字数提示按字形计（`Intl.Segmenter`），只在跨档时播报固定文字（**选择**）；演示不设 `maxLength`，因原生上限按 UTF-16 码元计。

### 日期族（2026-10-12，详见 `2026-10-03-family-date.md`）

- **键入中间态不是值**（**约束**）：原生日期输入允许比组件更宽的键入（年份可到 6 位、分段只填一半），此时 `value` 为空串而 `validity.badInput` 为真；既不上报，也不清空已有值，失焦后回到已接受值。只有全部分段清空才是清除（逐段删空时浏览器不发事件，在失焦处判定）。此前键入第 5 位年份会清空整个字段。
- **边界同源**（**选择**）：`min` / `max` 一处声明，同时约束原生输入、日历禁用范围与可翻到的月份；与旧写法取交集，交集为空时开发期警告。
- **范围的草稿**（**选择**）：两个原生输入与弹层日历共用一份草稿；键入出完整、有序、在范围内的范围即请求变更，日历与预设的选择等「应用」。只填一端、反向、越界不提交，不静默交换端点（**约束**）；无效在焦点离开整个字段且弹层关闭后才判定（逐段键入时的暂态不算）。预设的函数值在打开时求值，当前预设用淡染面 + 焦墨字（与分页当前页同一画法）。
- **日历区域**（**派生**）：月名、星期名、数字由 `Intl.DateTimeFormat(code)` 产生，周起始日由 `Intl.Locale` 的 `getWeekInfo().firstDay` 推出，不引入 date-fns 区域包；zh-CN、en-US 显示不变，显式 `locale` 优先。星期名取 short，超过 4 个字符改取 narrow（**预设**：格宽固定）。方向依次取 `dir`、UILocale、祖先实际方向，从右向左时翻页箭头镜像。
- **禁用的祖先链**（**约束**）：填值控件观察自身与整条祖先链上每个 fieldset 的 `disabled`（`src/input-facts.ts`），外层 fieldset 运行时禁用也同步；`<legend>` 例外由 `:disabled` 判定承担。

### 浮层所属与开启顺序

`FloatingLayerScope active` 只接收真实 modal 开启事实；`useFloatingLayer(role)` 返回样式，供公开 Positioner、Backdrop 或 Viewport 合并。层序整数（通知 5、文档候选 10、modal 30、步长 10、面偏移 1、所属候选偏移 2）为**预设**；所属候选高于父面、新开 modal 遮住旧面候选、通知低于候选是**约束**。仅客户端真实开启推进 serial；取消或受控拒绝不推进。

## 19. 对齐：经营位置与行气

谢赫「经营位置」，书法「行气」：一行之内字字相承，行与行之间气脉贯通。对齐不是逐个微调，而是让所有东西落在少数几条由材与分决定的线上。用户要求（2026-10-07）：对齐理念必须仔细打磨。

### 纵向：一行之内

| 规则 | 来源 |
|---|---|
| **按行居中，不按拉丁基线。** 同一行的元素各自在等高的行盒里居中对齐 | **派生**：中文字面居中于字身，拉丁基线对齐会让 12px 与 14px 两种字号错开小数像素，误差逐行累积（2026-10-07 实测：基线对齐的行出现 23.5px、22.75px 的高度） |
| 文字行高一律是材或分的整数倍 | **派生**（§1 分格） |
| 控件与文字同行时，文字行在控件外高里居中，偏移 = (材 + n 分 − 材) / 2 = n 分 / 2 | **派生**：五等的 n 分分别为 4、8、12、16、20px，偏移 2、4、6、8、10px，全部是整数 |
| 同一行的控件同高：md 按钮、填值控件、并列候选的轨道都读 `--qy-fill-height` | **派生**（§2、§6） |
| 图标在文字行内居中：(行高 − 图标) / 2，图标取偶数 | **派生**（§2） |
| 标记（勾选、单选）在标签行内居中，多行标签时对齐第一行 | **派生**（§2 `--qy-marker-inset`） |
| 名称列与内容列：名称放在与内容第一行等高的行盒里居中；内容是一整块（表格、图表、列表）时从顶部开始 | **派生**：名称说的是内容的第一行 |

### 横向：一列之内

| 规则 | 来源 |
|---|---|
| **一列只有一条左缘。** 有边或有底的控件，以外缘对齐这条线；没有边也没有底的入口（展开入口、行内链接、标签文字），以文字对齐这条线 | **派生**：读者看到的是有形的边；没有形的入口，看到的是字 |
| 不用按钮的留白做缩进：quiet 按钮放在一列开头时，会让文字比上下内容多缩进一个留白 | **约束**：列首的无形入口不用 quiet 按钮，改用不带留白的入口（如展开入口）或负外边距抵消 |
| 同一编辑边界内，附件与值之间是控件内间隔，只有贴边的一侧保留填值留白 | **派生**（§3、§6） |

## 系统角色令牌（2026-10-12）

用户裁决：「选中色也应该是根据 token 生效，并且应该和背景色之类的有关系」「圆角之类基础的东西不应该每个组件单独配置」「所有组件都应该是这个原则」。审计发现若干基础角色只在组件里以字面量重复。本轮只定义令牌与 Tailwind 出口，**每个令牌的值等于组件今天写的值，计算值零变化**；组件改接另行分批。判据：只有「库的基础量纲」或「至少两个组件共享的角色」才进令牌；只在一个组件一个位置出现的值不设令牌，由组件就地标为**预设**。

| 令牌 | 值 | 来源 | 说明 |
|---|---|---|---|
| `--qy-fen-half` | 分 / 2 = 2px | **派生** | 半分。Tailwind 出口 `gap-fen-half`、`h-fen-half`、`min-w-fen-half` 等；`--qy-track-inset`、`--qy-segment-gap` 改读它 |
| `--qy-line-width` | 1px | **裁决**（线宽统一 1px，见 §5） | 裸写的 `border`、`border-x/y/s/e/t/b/l/r`、`divide-x/y` 经 `--default-border-width` 读它；间距键 `line` 另供 `-mb-line`、`size-line` 等间距类读它。**不能**跟随它：`border-2`/`border-4`、`w-px`/`h-px`、`inset-ring`、`decoration-1`、`calc()` 里的字面 1px——这些仍是字面量，须改写成裸 `border*` 或 `(--qy-line-width)` 形式 |
| `--spacing` ← `--qy-fen` | 0.25rem | **派生** | Tailwind 的间距单位绑到分。两者都是 rem（`0.25rem` 与 `calc(1.25rem / 5)`），任何根字号下逐值相同，因此 `p-1`、`gap-2` 的计算值不变 |
| `--qy-opacity-disabled` | 64% | **预设** | 禁用的透明度；出口 `opacity-disabled`。此前 `opacity-64` 散在十余处 |
| `--qy-surface-field` | 浅色 `--qy-surface`；深色 `--qy-surface-inset` | **选择** | 填值控件的静止面，出口 `bg-surface-field`。此前每处写 `bg-card dark:bg-surface-inset`，只认 `.dark`，不认 `data-theme`，也不认嵌套根；令牌随两种深色机制与高对比、强制色一起变 |
| `--qy-ink-decor` | 与 `--qy-border-input` 同式（重墨 `--qy-ink-zhong`） | **派生** | 把边界墨色当作文字或填充用时的角色（Breadcrumb 分隔字、Timeline 的点），出口 `text-ink-decor` / `bg-ink-decor`；不再借用边线令牌 |
| `--qy-radius-cap-ratio` | 1 / 4 | **预设** | 色块圆角 = 边长 × 1/4；`--qy-swatch-radius` 读它。与 `--qy-radius-ratio`（5/16）是两个比例，不合并 |
| `--qy-glyph-box`、`--qy-glyph-box-inset` | 4 分 = 16px；(材 − 字框) / 2 = 2px | **派生** | 装短标签的小方框；Kbd、Prose 的 kbd、CornerMark |
| `--qy-header-row` | 材 + 2 × 组内间隔 = 36px | **派生** | 表头行与合计行的行高；Table、Prose |
| `--qy-inline-code-size`、`--qy-underline-offset` | `round(0.875em, 1px)`、`round(0.25em, 1px)` | **预设** | 取此前各处字面量的共同值；em 在使用处求值。下划线粗细就是 `--qy-line-width` |
| `--qy-field-min-text` | 4em | **预设** | 可输入字段里文字区的下限（Select 触发器、Combobox、InputGroup） |
| `--qy-popup-offset` | 1 分 = 4px | **派生** | 浮层与触发器的间距。CSS 能读，Base UI 的 `sideOffset` 只收数字或 `(data) => number`，读不到 DOM；JS 侧须先量一个读取该令牌的元素（见契约文件）。各浮层今天的偏移 0 与 4 并存，**本轮不统一** |
| `--qy-scale-popup` 0.98、`--qy-scale-press` 0.97、`--qy-travel-rise` 4px | 同左 | **预设** | `motion.css` 的动势量；此前是该文件内的字面量。导航内容切换的 1.5rem 与窄屏对话框的 1rem 各只一处使用，留在 `motion.css` 的规则里作字面量（**预设**），不设令牌 |
| `--qy-focus-quiet-width` | `--qy-line-width` | **派生** | 强制色模式下安静焦点轮廓的宽度 |
| `--qy-button-bordered-border-danger`、`--qy-button-bordered-border-focus-danger` | 危险色按 `--qy-ink-dan` 混合；危险色本身 | **派生** | bordered 危险按钮的边与焦点边；此前写在 `button.tsx` 的任意值里 |
| `--qy-control-{xs,sm,md,lg,xl}-padding-bordered` | 内边距 − `--qy-line-width` | **派生** | 此前是字面 `- 1px`，现读线宽，值不变 |

## 2026-10-10 功能纯粹：本次梳理的处置

用户裁决「功能需要纯粹」之后，对兼任了别的组件本职的部分逐项处置。以下是事实记录，取值定位照旧如实标注。

| 组件 | 去掉的兼职 | 归属 | 依据 |
|---|---|---|---|
| Button | `state` 的 waiting / unknown / failed 与按钮旁的状态文字 | 保留忙碌（`loading`）；结果归 Alert / Toast / FieldError / StatusDot | 用户裁决：「保留忙碌没有问题，其他的有需要可以使用提示组件」 |
| Toast | `loadingTimeout` 与超期自动转 unknown | 期限与「何时算未知」归应用 | 用户裁决：「toast 不做推测」 |
| Input | 清空、搜索图标、Escape 清空、显示密码 | SearchInput、PasswordInput（由 InputGroup + Input + InputGroupButton 组合），普通字段的附属动作用 InputGroupButton | 用户要求参照最佳实践：主流库的基础输入框都不内置这两件事，另设组合件（**接口选择**，不是理念推导） |
| Chart / ScatterChart / Heatmap | 整图的 empty / unknown / not-applicable 状态 | 调用方在原位放 Empty；等价数据表是无障碍替代，保留 | 用户同意该处置 |
| SidebarLink | 无 | `count` 保留：数字的两种摆法取决于侧栏是否收起，只有侧栏自己知道，它是条目的内容而不是另一个组件的本职 | 用户交由本库判断（**判断**） |

同批的两处非纯粹性改动：

- **编辑边界内的图标形附属动作**宽度改为边界内高（外高 − 2px 边框）。此前取图标形按钮自己的外高再配 `aspect-square`，把 Combobox、Autocomplete 的边界撑到 34px，比 Input 高 2px（实测）；现在与 Input 同为 32px（紧凑 28px）。关系：附属动作在边框以内，见方的边长只能是内高。
- **SidebarLink 当前项**在面之外加一段焦墨线（**已于 2026-10-12 撤销**，见沿革；下面是当时的论证）。关系：纸本色与侧栏底的明度差很小，只靠面在深色与低视力下认不出当前位置；画法取导航线已有的「当前项把自己那一段加深为焦墨」，二级条目加深的是已有的引导线，一级条目画在条目起始边内侧。线宽 1px 与导航线相同；一级条目的线上下各让出一个条目圆角，这两个取值是**预设**。
