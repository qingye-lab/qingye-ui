# 数值、固定长度文本与字符串集合

2026-10-03，Decided。依据根 `design.md` 的名称与状态、变化与恢复、归属检验，`STANDARDS.md`、基础层与表单族/选择器族。从当前公共 Input / Button / Field 和安装版 Base UI 原语组合；未读取归档或上游组件实现。

## 语义与状态归属

- NumberField 是可为空的数值输入。编辑文本属于数值原语，`number | null` 属于调用方；空、负号和未完成的小数不强制变成零。直接编辑允许超出 min/max，提交保留浏览器约束；步进服从 min/max 与 step，默认不吸附。封装固定 `allowOutOfRange=true`，不提供静默纠正入口。格式化是显式 `format` 的选择，不代表保存。
- OtpField 是一个固定长度的文本字段，以一个真实 Input 注册 Field，分段只呈现文本与光标位置。前导零保留；填写长度不代表验证成功。分段点击定位原生光标；方向键、退格、删除、复制和替换遵循原生文本选择。长度由调用方提供，以 Unicode code point 计；超长插入整次拒绝并就地说明，不截断粘贴。调用方提供的超长值仍完整显示，不擅自改写。
- TagInput 是已确认字符串集合与待确认草稿。Enter 或添加按钮才确认；确认时去除两端空白，区分大小写，以精确字符串去重。这些是公开的选择，不是唯一推导。空值和重复项留住草稿并显示原因；受控集合未接受添加时不清草稿。IME 组字中的 Enter 不确认。空草稿下 Backspace 先聚焦最后一项，再用删除键移除；所有附属动作都是非提交按钮。表单只提交已确认项，重复同名表单键；草稿不混入集合。
- 本地编辑、光标和就地约束提示归库；值、校验事实、请求、刷新、失败、未知和持久化归应用。disabled 阻止编辑与动作且不提交；readonly 可聚焦、复制和提交，不可修改。Field 提供名称、说明与调用方错误，不另造校验或提交结果。

## 几何与表达

五档控件外高、同名文字档、窄屏 +4px、圆角、颜色、命中目标沿用基础层**预设/选择**；不把继承值写成关系推导。NumberField 的输入与步进共用一条边界；OTP 的每段等宽，宽度读取同档外高，粗指针读取触摸目标，这是本批的**结构选择**。TagInput 的确认项与草稿分行，用已有 field-gap/action-gap 表达关系。所有焦点信号只改变已有边界颜色或使用 Button 盒内信号，无外围圈；不增加颜色、z-index、动效或全局 token。

NumberField 导出原语命名空间和 root/group/input/increment/decrement 公共部件。OtpField 的 `render/ref/className/style` 属于真实文本输入，`controlClassName` 属于分段容器。TagInput 的 `render/ref` 属于根容器，`inputProps` 透传真实草稿 Input 的 render/ref/ARIA/事件。新内建文案同时补中英 locale。

本批只运行三个新增测试文件，检查编辑、前导零、分段定位、粘贴拒绝、受控拒绝、IME、禁用/只读、Field 与表单语义。统一生成、类型构建、浏览器几何、真实键盘焦点、触摸命中、对比度、真实 IME 与辅助技术由主任务另验，不能由源码或 jsdom 推成 PASS。
