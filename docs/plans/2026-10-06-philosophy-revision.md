# 理念修订稿：取法传统，补全「文」

状态：**草案，待用户审定**（2026-10-06）。审定后并入根 `design.md`，本文件转为修订记录。

## 0. 为什么修订

用户的出发点：**参考中国传统文化的经典内核与东方美学的亮点，创建一套 UI 组件。**

现行 `design.md` 在「质」上完整：语义、状态真实、归属、恢复、可访问，这些是骨架，全部保留。它的缺口在「文」：

- 六种方法几乎都在处理语义与关系，「表达」只有「视觉基调」六句判断，推不出任何值。基础层 41 处「推导」全是相对关系（同高、同心、相减），**没有一个绝对值是推出来的**，于是尺寸、色阶、间距只能逐个标「预设」，或被误写成推导。
- 传统只被用作方法的名字。真正能生成视觉决定的传统——营造的模数、书画的墨法与章法、园林的因借——没有进入理念。
- 用户已经作出的视觉裁决（只加黑不加粗、同底色才留边框、正常态不用灰底、墨色配色、值字号不随框变）散落在裁决记录里；子代理只读理念，做不出这些。

《论语·雍也》：「质胜文则野，文胜质则史。文质彬彬，然后君子。」此前的组件是「质胜文」：语义正确、外观粗糙。本次修订不削弱质，补上文。

## 1. 取法的规矩

传统进入本库只有一种方式：**取其法，不取其形。**

一条传统方法要进入理念，必须同时满足三条，缺一条就不收：

1. **有出处**：能指出原文或公认的手法，不借传统之名说通用道理。
2. **能生成**：能在界面上作出一个判断，或决定一类取值。
3. **能检验**：给出可观察的判据，不依赖「有东方感」之类的感受。

不取的东西见 §7：纹样、仿古字体、印章与书法图形作装饰、五行配色等。

## 2. 总纲

**器用为本，关系为法，合宜为度。** 三句保留，各补其根：

| 总纲 | 出处 | 在本库的含义 |
|---|---|---|
| 器用为本 | 《易·系辞》「形而下者谓之器」；《考工记》以「良」论器 | 组件是器，先成其用：语义、状态、可达。用不成立，形不讨论 |
| 关系为法 | 《老子》第二章「有无相生，难易相成，长短相形，高下相倾」 | 大小、轻重、疏密只在相互比较中成立。改一处的强调，先看能否减弱它周围的，而不是加强它自己 |
| 合宜为度 | 《考工记》「天有时，地有气，材有美，工有巧，合此四者，然后可以为良」；《园冶》「巧于因借，精在体宜」 | 好坏看是否合于情境（时）、环境（气）、媒介（材）、工艺（巧）四者，不看是否用尽 |

文与质是检验总纲的一对：**质**是器用与语义（§3），**文**是表达的法（§4）。两者分别判断，不互相代替；任何一侧缺失都不算完成。

## 3. 质：器用之法

这一部分是现行 `design.md` 的强项，方法内容不变，只补出处，并收紧彼此的分工。

| 方法 | 出处 | 决定什么 |
|---|---|---|
| 名实相符 | 《论语·子路》「名不正，则言不顺；言不顺，则事不成」 | 名称对应真实对象、动作与后果；等待、成功、失败、未知按真实事件表达 |
| 君臣佐使 | 《素问·至真要大论》「主病之谓君，佐君之谓臣，应臣之谓使」 | 一个界面内动作与信息的角色：主意图、支持、保护与修正、去向。**一个视图只有一个君** |
| 进退相承 | 《易·乾·文言》「知进退存亡而不失其正」 | 正常、等待、失败、取消与恢复围绕同一对象连续发生 |
| 展开有据 | 园林「移步换景」「欲扬先抑」 | 每一次展开都给出与这一步相称的内容；有直达入口与返回路径 |
| 少则得 | 《老子》第二十二章「少则得，多则惑」 | 能组合解决的不增加配置，能复用关系的不新增组件 |

原「相成相制」并入总纲「关系为法」；原「布白有用」「随境取度」归入文（§4.2）与度（§5），各只在一处定义。

## 4. 文：表达之法（新增）

### 4.1 以材为祖：模数

**出处**：《营造法式·大木作制度》「凡构屋之制，皆以材为祖。材有八等，度屋之大小，因而用之」；「凡屋宇之高深，名物之短长……皆以所用材之分，以为制度焉」。

**内核**：整座建筑只定一个基本量「材」，所有构件的尺寸都写成它的「分」。建筑等级变化时只换材的等级，构件之间的比例不变。

**界面上的法**：

- **材**：界面最基本的量是**正文的一行**：正文字号及其行高。人读的是字，所有围绕文字的几何都从这一行出发。
- **分**：材的整除单位，用于全部几何：控件高、留白、间距、圆角、标记尺寸。
- **等**：尺寸档与密度只是换「等」。等变了，各部位按同一比例一起变，不逐个调值。
- **屋有大小，人无大小**：房屋可以分等，住在里面的人身高不变。控件、间距随等变化，**内容文字不随之缩放**。字号由阅读需要决定，不由容器决定。用户「值字号不随框变」的裁决由此成立。

**判据**：每个几何值都能写成「n 分」或「材 ± n 分」，并说明 n 由哪条关系决定。真正自由的值只有材、分与少数比例；**基础层的质量看自由值的数量，不看标注是否诚实。**

**可行性核对**：取材 = 20px（正文 14px 的行高）、分 = 材 ÷ 5 = 4px，现行五档控件外高 24/28/32/36/40 恰为 6/7/8/9/10 分；标记 20px 为 1 材，字段间隔 8px 为 2 分。现有取值大多已落在这套分格上，第二步要补的是每个 n 的关系依据，不需要推翻重来。

### 4.2 疏密：计白当黑

**出处**：包世臣《艺舟双楫》述邓石如：「字画疏处可以走马，密处不使透风，常计白以当黑，奇趣乃出。」笪重光《画筌》：「虚实相生，无画处皆成妙境。」《老子》第十一章：「凿户牖以为室，当其无，有室之用。」

**内核**：空白与笔墨同样经过设计，并且疏与密要拉开，不能平均。空本身是用处。

**界面上的法**：

- 间距是表达关系的第一手段：同一组内紧，组与组之间松，章节之间更松。**能用间距分组的，不用线和卡片。**
- 间距只有少数几级，相邻两级的差距要大到一眼可辨；平均分布的间距等于没有分组。
- 空态、工作区、输入区的空是功能，不是剩余。

**判据**：

- 组内间距 < 组间间距 < 章节间距，相邻两级的比例不低于约定值（第二步确定）。
- 同一关系在全库只有一个间距值。
- 去掉所有边框与底色后，分组仍然读得出来。

### 4.3 墨分五色：色

**出处**：张彦远《历代名画记》：「运墨而五色具，谓之得意。」后世概括为「墨分五色」（焦、浓、重、淡、清）。谢赫六法：「随类赋彩」。

**内核**：只用一种墨，靠浓淡就能分出远近、主次与质感；彩色依物类而施，不随意添加。

**界面上的法**：

- 界面的层级由**一条中性墨阶**承担：文字、线、承载面都从这一阶取值，阶数有限（约五级加纸白），各级之间的差可以辨认。墨阶以外不另造灰。
- **彩色随类**：只用来表达有语义类别的事实，即危险、警示、成功、信息与数据系列。不用彩色做装饰或区分无语义的东西。
- **朱只一点**：品牌可以有一种强调色，用法像画上的一方印：位置少、面积小、意义明确。强调色缺省时就是墨。
- 用户「配色保持墨色」的裁决由此成立。

**判据**：

- **灰度检验**：把界面转成灰度，层级与状态仍然可读；状态不只靠色相表达。
- 同一视图中，没有语义类别的彩色数量为零。
- 中性取值都能对应到墨阶中的某一级。

### 4.4 骨法用笔：线

**出处**：谢赫六法「骨法用笔」。

**内核**：线是结构，不是装饰；每一笔都有它要承担的东西。

**界面上的法**：

- **线只承担面承担不了的边界**：底色与承载面相同、需要划出范围时才用线，填充已经划出范围就不再加线。用户「同底色才留边框」的裁决由此成立。
- 线宽统一，强调靠墨色而不靠粗细。焦点、错误、选中只让已有的线**变浓**，不加粗，也不在外面另加一圈。用户「只加黑不加粗」「控件外不出现一圈」的裁决由此成立。
- 一个范围只用一种边界机制，线、底色与阴影不叠加表达同一件事。

**判据**：

- 每一条线都能回答：去掉它，哪个范围就读不出来了？答不出来的线删除。
- 状态变化前后，元素的几何尺寸不变。

### 4.5 应物象形：形

**出处**：谢赫六法「应物象形」。

**内核**：形随物的性质而定。

**界面上的法**：

- **方以载事**：可操作、可编辑的范围（控件、面板、输入区）用方整轮廓，转角略缓。
- **圆以标点**：只表达一个点或一个身份的东西（状态点、头像、开关抓手所处的位置）可以用圆。
- **内外同心**：同一轮廓等距内缩时，内角 = 外角 − 内缩。
- 状态改变形中已有的属性（浓淡、填充、位置），不新增形。

**判据**：每一处圆形都对应一个点或身份；嵌套轮廓同心。

### 4.6 经营位置：章法与行气

**出处**：谢赫六法「经营位置」；书法「章法」「行气」，指行与行之间气脉贯通、字与字之间相互顾盼。

**内核**：先安排位置，再施笔墨。主次首先由位置确立。

**界面上的法**：

- 主次先由位置与留白建立，然后才用尺寸、墨色与填充。一个视图的「君」（§3）只有一个，它在位置上就应当是第一眼。
- **同行同气**：同一行里的控件同高、文字同基线，左右边缘落在少数几条对齐线上。尺寸裁决中「md 按钮与输入同高」「轨道外高等于控件外高」由此成立。
- 文字长度、语言或放大比例变化后，章法仍然成立。

**判据**：

- 同行元素的外高与基线一致。
- 一个区块中的对齐线可以数出来，并且数量少。
- 去掉所有填充色后，仍然认得出哪一项是君。

### 4.7 素：表面

**出处**：宋代审美所尚「平淡天真」（米芾评董源）；宋瓷以釉色与器形取胜，不靠纹饰。

**内核**：质量来自比例与材质本身，不来自附加的装饰。

**界面上的法**：

- 不用装饰性的渐变、纹理与高光。
- 阴影只表达真实的浮起，例如浮层盖在内容之上；同一平面上的东西不加阴影。
- 正常状态不额外铺灰底；灰底是一级墨色，必须有它要表达的东西。用户「正常态不用灰底」的裁决由此成立。

**判据**：删去检验（现行 `design.md`）用于每一处装饰性表面，删除后无损的表面一律去掉。

### 4.8 气韵生动：动与节奏

**出处**：谢赫六法「气韵生动」。

**内核**：画面的各部分贯通成一个整体，有呼吸与节奏，而不是零件的堆积。

**界面上的法**：

- **动不离位**：动效从变化发生的地方开始，说明从哪里来、到哪里去。不做与位置无关的装饰动效。
- 状态之间的过渡连续，可以中断；业务结果不依赖动画结束。
- 重复出现的间隔与节拍保持一致，比如同类列表的行距、同类过渡的时长，让整体读起来是一体的。

**判据**：关闭动效后，状态与任务完全成立；同类变化使用同一时长与曲线。

### 4.9 材有美：尊重媒介

**出处**：《考工记》「材有美」。

**内核**：顺着材料的性质做，不与它对抗。

**界面上的法**：

- 屏幕的材是像素、系统字体、输入方式与平台行为。几何落在整像素上；默认使用系统字体，因为中西文字面是成对设计的；保留平台的原生行为与可访问能力。
- 中文排版尊重中文的材性：标点、中西文混排间距、长词换行，用真实文字检查。

**判据**：在常见缩放比例下，几何值不出现半像素；中英混排的文字只出现一套 x 高度与灰度。

## 5. 度：合宜

| 方法 | 出处 | 决定什么 |
|---|---|---|
| 时中 | 《中庸》「君子而时中」 | 默认值随情境变化，不取中间值，也不在所有情境使用同一强度（即现行「随境取度」） |
| 因借 | 《园冶》「巧于因借」 | 组件从所在环境继承密度、明暗、方向与语言，不让调用方逐个配置 |
| 体宜 | 《园冶》「精在体宜」 | 表达的强度与对象的分量相称：保护措施与风险相称，强调与重要性相称 |
| 过犹不及 | 《论语·先进》 | 每个表达参数都有上下界，例如对比、圆角、密度与强调数量；超出任何一侧都算失度 |

## 6. 判据汇总

现行的删去、分工、变化、来源、归属与证据检验全部保留。新增的检验如下：

| 检验 | 来源 | 可观察的结果 |
|---|---|---|
| 灰度检验 | 墨分五色 | 转成灰度后，层级与状态可读 |
| 疏密检验 | 计白当黑 | 去掉线与底色，分组仍可读；间距级差达到约定比例 |
| 骨法检验 | 骨法用笔 | 每一条线都承担一个面承担不了的边界 |
| 行气检验 | 经营位置 | 同行元素同高、同基线；对齐线少 |
| 君位检验 | 君臣佐使 | 去掉填充色后，仍认得出唯一的君 |
| 分格检验 | 以材为祖 | 每个几何值都能写成材与分，并给出系数的关系依据 |
| 物勒工名 | 《礼记·月令》「物勒工名，以考其诚」 | 每个值都记录来源：锚点、派生（附关系）或裁决（附日期）；不能指名来源的值不能进入基础层 |

## 7. 不取

- 传统纹样、云纹、回纹、窗棂等图案作为装饰。
- 仿古字体、书法字体用于界面文字。
- 印章、卷轴、宣纸肌理作为界面元素。
- 用五行、方位附会配色。
- 竖排，除非内容本身是竖排。
- 用文化说明代替可用性证据。现行 `design.md` 中「不能通过补一段文化解释使它合格」继续有效。
