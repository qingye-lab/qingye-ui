# Qingye UI 4.1.0

4.1.0 adds standard consumer compositions and fixes confirmation cleanup across React Activity and StrictMode lifecycle reconnection. The existing advanced table, pagination parts, Combobox parts and snapshot-confirmation entries remain available.

GitHub distribution is produced by the `v4.1.0` Release workflow. npm publication is separate; this document does not establish either remote result.

## Added

- `DataTablePattern`: column/data configuration with an internal TanStack instance, client or server sorting/pagination, stable IDs, page-scoped select-all, retained cross-page selection and independent active records. Sorting and page reset are delivered in one state update. Server mode does not re-sort or slice server results.
- `PaginationPattern`: one-based `{ page, pageSize }` state, bounded page windows, page-size selection and totals. Changing page size resets the page atomically; shrinking totals and last-page deletion clamp the page. Zero results show no current page. Unknown totals require explicit `hasNextPage`.
- `ConfirmProvider` / `useConfirm()`: an awaited boolean decision. Cancellation, abort, owner/provider teardown and lifecycle deactivation decline it; concurrent calls return false. Business submission, busy state and failures stay with the application. Use `ConfirmAction` for object/version snapshots and renewed review.
- `AsyncContent`: distinguishes request state from usable content. Background refresh and refresh failure retain content identity, drafts and focus. Loading feedback is outside the busy content subtree.
- `ComboboxSelect`: a flat single-selection composition with explicit labels, clear, read-only/disabled, empty and loading states. The remote example guards stale responses independently from transport cancellation.
- `/examples/records`: a list/detail reference using public components, one vertical scroll owner, horizontal table overflow, stable record drafts and density switching. Its complete implementation is distributed with Workspace documentation.

## Fixed

- Confirmation no longer retains an uncloseable dialog after a provider inside React 19.2 Activity is hidden and restored. Layout lifecycle reconciliation removes obsolete views while preserving newly issued requests. Hook availability is restored before caller layout effects; StrictMode replay remains usable.
- Configured table updates preserve actual cell/control identities and keyboard focus. Sorting labels stay on one line while long active-row names can wrap.
- Public `hooks/*` entries make individual hooks importable without loading the aggregate table/chart export graph.
- Input adjunct corners derive from the current field radius and actual inset; autofill uses the field surface.

## Contracts and visual changes

Selection IDs may outlive the currently loaded server rows; they do not imply selection of every server result. Applications still own permissions, data validity, requests, query races and execution results. New pagination messages are available through both built-in locales; custom complete locale objects must supply those message keys or extend a built-in locale.

This release adds a workspace reference page and keeps sortable column labels on one line. It does not change global theme tokens. Input adjunct geometry and autofill follow the current field roles. Rebuild generated or precompiled styles after upgrading.

## Distribution and verification

The package contains 95 component modules. Current Chinese/English AI resources are under `ai/v4.1.0/`; historical `ai/v4.0.0/` is retained in the repository and excluded from the new tarball. UI versioning is independent of `@qingye/tooling` 0.5.0.

The lifecycle repair has fail-before/pass-after regression coverage, including Activity provider/owner deactivation, StrictMode layout-effect replay, and a fresh confirmation during reactivation. Release checks run type, test, built-browser, package and installed-consumer gates from the tagged commit. See [the workflow](../../.github/workflows/release.yml) and [implementation evidence](../implementation/2026-10-20-consumer-compositions.md).

Real Chinese IME, screen-reader speech, physical-touch devices and native contrast modes remain outside the automated acceptance evidence.
