# Qingye UI 2.0.0

`packages/ui/package.json` is set to 2.0.0 and the release is cut by the `v2.0.0` tag. The GitHub Release exists once the [Release workflow](../../.github/workflows/release.yml) succeeds for that tag; npm publication is a separate manual step and is not established by this document.

2.0.0 follows one rule decided on 2026-10-10: **a component does one job.** A warning, a result or a guess belongs to the component whose job it is — AlertDialog and ConfirmAction for consequences, Toast, Alert and Tooltip for results, Empty for a chart with nothing to draw. The dispositions are recorded item by item in the [foundation document](../decisions/2026-10-03-foundation.md) under 「2026-10-10 功能纯粹」. It is a breaking update from 1.0.0; for the migration from 0.4.x read the [1.0.0 notes](./v1.0.0.md) first.

The current source contains 90 component modules.

## Breaking API changes

| Area | 1.0.0 | 2.0.0 and migration |
| --- | --- | --- |
| Button | `state`: `idle`, `waiting`, `in-progress`, `unknown`, `failed`. A danger action required `ButtonProtection` or a linked description. | Boolean `loading`. `ButtonProtection` and the danger requirement are removed; `tone="danger"` is a tone only. Replace `state="waiting"` / `"in-progress"` with `loading`. Show an unknown or failed result with Toast, Alert or Tooltip; put a consequence and its confirmation in AlertDialog or ConfirmAction. |
| ConfirmAction | `state` | Boolean `loading`. |
| Input | `clearable`, `clearLabel`, `onClear`, `visibilityToggle`, `visible`, `defaultVisible`, `onVisibleChange`, `showLabel`; a leading icon and Escape-to-clear for `type="search"`. | Input is the bare field. Use `SearchInput` for search with clearing and `PasswordInput` for show/hide, or compose `InputGroup` + `Input` + `InputGroupButton`. |
| Toast | `loadingTimeout`; a loading toast turned into an unknown result when overdue. | Removed. A loading toast stays loading until the caller updates it. Locale keys `toastResultUnknown` and `toastResultUnknownDescription` are removed. |
| Chart, ScatterChart, Heatmap | Chart-wide `state` and `children` for non-data states. | Removed. Render `Empty` in the chart's place when there is nothing to draw. Per-value `unknown` / `not-applicable` and the equivalent data table are unchanged. |
| TooltipTrigger | Wrapped its content in a default button. | `render` is required; the trigger is the element the caller supplies. |
| TabsPanel | `keepMounted` defaulted to `true`. | Defaults to `"visited"`: a panel mounts on first arrival and stays mounted. Pass `keepMounted` where every panel must exist up front (measuring, stacking, server-rendered links). |

## Added

- `SearchInput` and `PasswordInput`, composed from InputGroup, Input and the new `InputGroupButton`.
- Combobox `multiple`, with `ComboboxChips`, `ComboboxChip` and `ComboboxValue`.
- `TableContainer` `framed`; pass `false` when the table sits on an existing surface such as a Card.
- `Skeleton` (added after 1.0.0).
- `--qy-sidebar-current`, the surface role of the current sidebar item.

## Visual changes

- Button no longer renders a wrapper element; the busy mark sits inside the button. Selectors that targeted the wrapper need review.
- The current `SidebarLink` carries a one-pixel ink line besides its fill: on the item's own edge, or on the guide line inside a sub-level. The line's width and inset are presets, not derived values.
- Adjunct buttons inside Combobox, Autocomplete and the date pickers take an explicit width from the control's fill height.
- Input no longer draws a search icon for `type="search"`.
- Charts no longer draw a frame for a non-data state.

Check light and dark themes in the consuming application's real states. Mobile layouts are not part of the verified scope.

## Distribution

Generated guides and AI resources for this version are under `ai/v2.0.0/` (with `en/`); `ai/v1.0.0/` keeps the content published with 1.0.0. Registry templates reference `@qingye_lab/ui@2.0.0`. `@qingye/tooling` stays at 0.5.0 and the private Studio at 0.4.0.
