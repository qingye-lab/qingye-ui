# Qingye UI 5.1.0

5.1.0 answers the first consumer report on 5.0.0 and the review that followed. The narrow-screen Sidebar drawer stops weighing on the first chunk, page shells gain a transition key, layout primitives cover justified rows and grids, sticky table headers follow the page scroll, and time values carry milliseconds. Two adjustments to contracts introduced in 5.0.0 can require code changes; read **Adjusted 5.0.0 contracts** before upgrading.

## Adjusted 5.0.0 contracts

- **Sidebar drawer handle:** `Sidebar drawerHandle` and `SidebarDrawerTrigger handle` take a `SidebarDrawerHandle` created by `createSidebarDrawerHandle()` (exported from the main entry and `@qingye_lab/ui/components/sidebar`), not a Base UI `DrawerCreateHandle()`. Inside `Workspace` nothing changes: the shell still provides the handle. `SidebarDrawerTriggerProps` are now `ButtonProps` plus `handle`; props that only Base UI's drawer trigger understood are no longer accepted.
- **TimeField seconds:** with `granularity="minute"`, editing a value that carries seconds (or milliseconds) keeps them, as native `input[type=time]` does. Previously the seconds were dropped on the first edit. Clearing every segment still clears the whole value. Applications that relied on the truncation should normalise the value themselves.

## Added

- `Sidebar`: the narrow-screen drawer host loads on demand when the viewport turns narrow, so Base UI's drawer code is no longer in the first chunk. A press before the host arrives opens it once it mounts; a failed load closes the drawer and retries on the next press. Above 40rem the sidebar stays in place; collapsing to a rail at intermediate widths stays the application's choice through `collapsed` / `defaultCollapsed`.
- `WorkspaceContent transitionKey`: when it changes, the content scrolls to the top (or to the hash anchor when the new content contains it) and replays its entrance.
- Layout: `Stack` and `Inline` take `justify`; `Grid` lays out equal columns, either a fixed count (`columns`) or fluid by `minItemWidth`. New gap role `pair` (one fen, 4px) for a name and its description or a value and its unit.
- `DataTable stickyHeaderOffset` and `TableHeader stickyOffset`: clear a fixed application bar.
- `DateTimePicker` and `TimeField` accept `HH:mm:ss.SSS` and compare `min` / `max` to the millisecond; `34.5` and `34.500` are equal. More than three fraction digits throw.

## Fixed and clarified

- A sticky DataTable header now sticks to the page or the `Workspace` scroll area while the table fits horizontally (its container clips instead of scrolling). A table that overflows horizontally still scrolls, and its header sticks inside its own container.
- An overflowing horizontal `Tabs` list fades only the end that still hides tabs (`data-overflow-start` / `data-overflow-end`, measured on scroll and resize, RTL aware) and no longer chains its scroll to the page.
- Under coarse pointers, Tabs and NavigationMenu items and Menu and Command items grow to `--qy-touch-target` instead of relying on enlarged hit layers that could cover neighbouring items.

## Compatibility notes

Everything added is opt-in. Current Chinese/English AI resources are under `ai/v5.1.0/`; the `ai/v5.0.0/` snapshot stays in Git as released and is excluded from this tarball.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. A versioned build or tarball does not establish npm publication.

```sh
pnpm add @qingye_lab/ui@5.1.0 --registry=https://registry.npmjs.org
```
