# Qingye UI 4.0.0

`packages/ui/package.json` is set to 4.0.0 and the release is cut by the `v4.0.0` tag. The GitHub Release exists once the [Release workflow](../../.github/workflows/release.yml) succeeds for that tag; npm publication is a separate manual step and is not established by this document.

4.0.0 carries the consumer requests confirmed on 2026-10-13 (application shell, ordered level marks, frameless charts, whole-row entries), the system-role token cleanup, the move of Prose typesetting into a stylesheet, and the documentation site redesign. Read the [3.0.0 notes](./v3.0.0.md) first when upgrading from 2.0.0.

4.0.0 contains 93 component modules.

## Breaking changes

| Area | 3.0.0 | 4.0.0 and migration |
| --- | --- | --- |
| CSS tokens | `--qy-wash-dan`, `--qy-duration-slow` and `--qy-ease-spring` were published but no component read them. | Removed. A project that referenced them defines them itself with the 3.0.0 values: `--qy-wash-dan: calc(var(--qy-ink-dan) / 2)`, `--qy-duration-slow: 320ms`, `--qy-ease-spring: cubic-bezier(0.34, 1.3, 0.64, 1)`. |
| `chart` exports | `MARK` (8) and `SURFACE_GAP` (2) were exported as numbers. | Removed. Chart geometry derives from `--qy-fen` and `--qy-line-width`; read it with `useChartGeometry()`. |

## Added

- `Workspace` application shell: `Workspace`, `WorkspaceSurface`, `WorkspaceHeader`, `WorkspaceHeaderPortal`, `WorkspaceTitle`, `WorkspaceSummary`, `WorkspaceActions`, `WorkspaceContent`. A routed page sends its title, summary and actions to the header through `WorkspaceHeaderPortal`; `WorkspaceContent` is the only scroll container and joins the tab order only when it overflows.
- `SeverityMark`: an ordered level drawn as filled cells (`level`, `max` 2–5, `tone`, required `label`, `name="visible" | "hidden"`), named as one image.
- Chart, Heatmap and ScatterChart: `framed={false}` for a chart inside a section or card; the figure can be named by `aria-labelledby` or `aria-label`, and `ChartHeader`'s title is optional. `chartName`, `chartBaseClassName`, `chartPaperClassName`, `ChartFigureProps` and `useChartGeometry` are exported.
- A missing series, row or point label now throws a readable error naming the item instead of a `TypeError`.
- `Item` rendered as a link or button gets whole-row hover and press feedback, with the text kept on the column edge.
- `SidebarHeader`, `SidebarTitle` and `SidebarFooter`; `popupOffset()` reads `--qy-popup-offset` for floating positioners.
- System-role tokens (line width, half fen, disabled opacity, field surface, selected surface, popup offset, hint padding, prose measure and others) replace values that were repeated as literals. Default computed values are unchanged unless listed under visual changes.
- `@qingye_lab/ui/prose.css`: Prose typesetting rules, imported by `styles.css`. It uses `@apply` and is valid only through `styles.css`.

## Fixed

- Breadcrumb's folded menu no longer repeats the key `.0`.
- OtpField's selected characters use the selected surface instead of the press surface.

## Visual changes

- Selected and current surfaces are one 4% ink wash (`--qy-surface-selected`), equal to hover; press is 8%. The Sidebar current item is that fill without the former line; its siblings use the muted foreground and the current item the full foreground. The fill alone is below 3:1 against its neighbours; the text ink is the second cue.
- Popover, Tooltip and HoverCard open 4px from the trigger. Solid and danger buttons are one step lighter when pressed. Toast has the raised shadow.
- The narrow breakpoint is 40rem everywhere; panel padding between 640 and 767px returns to the desktop value. Hint surfaces share one padding.
- Prose headings are 32/24/20 (were 28/22/18); its task-list checkbox uses the field surface.
- Chips use the neutral soft surface.

Check light and dark themes in the consuming application's real states. Mobile layouts are not part of the verified scope.
