# Qingye UI 5.3.0

5.3.0 closes the component gaps reported by a consuming project on 2026-11-01. It adds `RelativeTime`, `useCursorPagination`, `SidebarButton` and `SkeletonControl`; gives `Text` a tone, `Stat` an `xl` size, `BulkActionBar` custom counts, `DataTablePattern` a selection scope and line charts a range band; and replaces the browser's empty date segments with a text hint. Existing props keep their meaning. Read **Visual baseline changes** before comparing screenshots.

## Added

- **RelativeTime**: renders `<time dateTime>` with relative text, gives screen readers the absolute time and shows it in a Tooltip.
- **useCursorPagination**: remembers visited cursors for server paging by cursor, so previous pages can be revisited.
- **SidebarButton**: `SidebarLink`'s look on a `<button type="button">` for actions in the sidebar; it never sets `aria-current`.
- **SkeletonControl**: a placeholder at the height of a fill control that follows the touch target.
- `Text` `tone="default" | "muted"`; `Stat` `size="xl"` (display-lg, 40/48).
- `BulkActionBar` `formatCount` and `summary`; `DataTablePattern` selection scope `"page" | "filtered"` (client mode only).
- `onRowActivate` and `activeRow.onActivate` receive the triggering event.
- Line series in `Chart` accept `range: { min, max }`, drawn as a band; the equivalent table gains min/max columns.
- `Input` of type date, time, datetime-local, month or week renders `placeholder` as a muted hint while the field is empty, unfocused and holds no partial entry. Date pickers pass a locale default.
- New locale keys: `chartRange`, `chartRangeMin`, `chartRangeMax`, `relativeTimeAbsolute`. Locales that spread the shipped `zhCN` / `enUS` objects get them automatically.

## Changed

- `WorkspaceContent` is positioned (`relative`).
- A truncated table column holding a single link truncates the link itself; the Tooltip shows the full text.
- `data-motion="stagger"` numbers children by position (up to 8); an explicit `--qy-index` still wins.
- Segmented date and time digits use tabular numerals.
- A single-step `Tour` no longer shows `1 / 1` or a Previous button that does nothing.

## Fixed

- `InputGroup` adjacency padding also applies to the date hint.
- `Prose` `<details>`: the summary gap applies only when open, so top and bottom spacing match.

## Visual baseline changes

- `TableContainer` fades by default: the edge that still has content fades.
- `DescriptionList` stacked layout: the single-column subgrid drops its column gap.
- `Progress` / `Meter` indicators transition their width and `Proportion` segments their share (`--qy-duration-base`; none on mount, none under reduced motion).
- `Card` rendered as a link or button layers its hover and active wash over the surface instead of replacing it; no shadow.
- Empty date and time inputs show a text hint instead of browser segments; closed `Prose` details are 8px shorter; single-step `Tour` loses its progress line and Previous button.

## Behaviour changes

- A custom **complete** `UILocale` adds the new keys listed above.
- Tests that queried the native empty segments of date inputs, or the progress line of a single-step `Tour`, need updating.

## Compatibility notes

No public API is removed. Current Chinese/English AI resources are under `ai/v5.3.0/`; the `ai/v5.2.0/` snapshot stays in Git as released and is excluded from this tarball.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. From 5.3.0 the release workflow publishes the verified tarball to npm through Trusted Publishing and attaches it to the GitHub release.

```sh
pnpm add @qingye_lab/ui@5.3.0 --registry=https://registry.npmjs.org
```
