# Qingye UI 5.0.0

5.0.0 closes the gaps found by the 2026-10-29 source review and the 2026-10-30 consumer report. It adds selection, input and layout components that administration interfaces needed, completes table, sidebar and form states, and removes contracts that could not state what decided them. Several removals and new runtime checks are breaking; read **Breaking changes** before upgrading.

## Breaking changes

- **Spacing tokens:** `--qy-space-5`, `--qy-space-10`, `--qy-space-12` and `--qy-space-16` are removed. No component consumed them. Replace them with the nearest remaining tier or with `calc(var(--qy-fen) * N)` when the value is a deliberate local measure.
- **Subpath:** `@qingye_lab/ui/components/motion-provider` is removed. The component is `InputModalityProvider` (`@qingye_lab/ui/components/input-modality-provider`); `MotionProvider` remains an alias exported from the main entry and from the new subpath.
- **Sidebar landmark:** the `Sidebar` root renders `div` instead of `aside`. Primary navigation is not complementary content; the landmark comes from the named `nav` inside. Use `render={<aside aria-label="…" />}` when the sidebar really is complementary content.
- **Motion selectors:** `motion.css` attaches entry, exit and progress motion to stable `.qy-*` classes instead of `[data-slot]` selectors. Changing `data-slot` no longer drops motion; consumer CSS that overrode motion through `[data-slot="…"]` must target the component or its class.
- **New runtime errors** (each names the missing contract):
  - `ButtonGroup`, `Tree` and `VirtualList` require `aria-label` or `aria-labelledby`.
  - `CornerMark` requires a non-empty `label` in every environment (previously development only) and accepts `neutral` or the four shared tones; other `tone` values throw.
  - `confirm()` requires a non-empty `confirmLabel`.
  - `DataTable` with `onRowActivate` requires one row-header column (`meta.rowHeader: true`, or `rowHeader: true` in `DataTablePattern`); pinned columns must be a contiguous leading run.
  - `SidebarSub` cannot be nested in another `SidebarSub`; the third level belongs in the page (design guide NG13).
  - `Sidebar drawer` and `SidebarDrawerTrigger` require a `Workspace` ancestor or a shared handle.
  - Invalid `CodeBlock maxLines`, `DescriptionList columns` and `BulkActionBar extent` values throw.

## Added

- `ColorPicker`: swatches are a named radio group; the trigger is named by its label.
- `Resizable`: panels with keyboard-adjustable separators.
- `TimeField`, `Cascader` (asynchronous columns), `TreeSelect` and `Command`.
- `FileTrigger`: button-triggered file selection that returns accepted files and rejected files with reasons. Transfer remains a composition demo, not a component.
- `DataTable`: sticky header, pinned leading and trailing columns, fixed and flexible columns together (overflow scrolls inside the table), row names from the row-header cell, per-row selection names, select-all naming its scope (this page or all filtered results), separate empty-value display, focusable truncated cells with full text in a Tooltip, roving tabindex, visible busy and error states.
- `Sidebar`: named `nav`, `--qy-sidebar-width`, and a narrow-screen drawer (`drawer` with `SidebarDrawerTrigger`) sharing one navigation tree. `Workspace` includes a skip link to the main content.
- Forms: `Select` `loading`, `error` and empty list; `Field` required and validating states; `Switch` `pending` and `readOnly`; `SearchInput` `loading`; clearable `DateTimePicker` and `DateRangePicker`; date typing rejects out-of-range values; unified read-only notes for value controls.
- `DescriptionList` `columns`, `CodeBlock` `maxLines` (a named, focusable scroll region), `Collapsible` `indicator={false}`, `Alert` category icons and screen-reader category names (`icon={false}` to remove), `Menu` danger items.
- `@qingye_lab/ui/hooks/use-copy-to-clipboard` subpath; copying falls back when the Clipboard API is unavailable (for example over http).

## Fixed and clarified

`ConfirmAction` cannot be dismissed while its request is pending; toasts with actions do not auto-dismiss. Wide tables no longer widen the page. Chart, Scatter and Heatmap data tables declare numeric columns through `numeric`; chart legend and heatmap scale keys read shared geometry, and remaining fixed measures are marked as presets in source. Dialog, AlertDialog and Popover titles wrap with `wrap-anywhere`; the wrapping rule is in `STANDARDS.md` section 7. The indeterminate progress bar centres its travel under reduced motion, including RTL. `AlertDialogClose` defaults to the localized “Back” name; `LocaleSwitch` options carry `lang`; Breadcrumb separators follow RTL.

## Visual changes

- Feedback ladder: hover 4%, selected and pressed 8% ink, current list items `font-medium`. `--qy-surface-selected` moves from the wash step to the 8% ink step.
- `--qy-border-strong` becomes 66% ink instead of equalling `--qy-border-input`.
- Narrow screens use `--qy-text-label-mobile-size`, so field labels no longer read smaller than their descriptions.
- `Select` sizes its trigger by all options; pagination page size reads “10 / page” (accessible name unchanged); `PendingValue` `numeric` defaults to off; `Prose` is unframed by default; the heatmap scale key matches legend swatch height and radius.
- Rebuild Tailwind output or use the refreshed compiled `ui.css`.

## Compatibility notes

The new components and table, sidebar and form capabilities are opt-in. Fill controls follow `data-density` and do not gain `size`. `picker-trigger` depends on an internal `@base-ui/react` module; that dependency stays pinned to an exact version and must be retested with every Base UI upgrade. Custom complete locale objects must provide the new message keys or extend a built-in locale. Current Chinese/English AI resources are under `ai/v5.0.0/`; older version directories remain in Git and are excluded from this tarball.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. Local runs that could not execute (missing browsers) are recorded as not run, not as passing. A versioned build or tarball does not establish npm publication.

```sh
pnpm add @qingye_lab/ui@5.0.0 --registry=https://registry.npmjs.org
```
