# Qingye UI 5.6.0

5.6.0 adds `ScrollArea` edge fades and scrollbar visibility, a visible title for `CommandDialog`, an unframed `CodeBlock` and a narrower observation scope for `Tour`. No public API is removed. Several visual baselines change (styled scrollbars hide at rest, Confirm's default cancel label), and five unused locale keys are deprecated; see Upgrading.

## Added

- `ScrollAreaViewport` `fade`: the clipped end of an overflowing viewport fades out, following the primitive's `data-overflow-*` state.
- `ScrollAreaScrollbar` `visibility`: `"auto"` (default) hides the scrollbar at rest and shows it while hovering or scrolling; `"always"` keeps it visible whenever there is overflow.
- `CommandDialog` `title`, `description`, `popupProps` and `onOpenChangeComplete`. With `title`, the dialog renders a visible header and takes its name from that title; `aria-label` / `aria-labelledby` are then ignored, so the screen-reader name matches what is on screen. Without `title`, one of them is still required. `popupProps` cannot override the dialog's name or `data-slot`.
- `CodeBlock` `framed` (default `true`): pass `false` to drop the outer line, surface and radius when the block sits inside an existing container.
- `Tour` `container`: the DOM scope watched for late anchors; defaults to `document.body`.

## Behaviour changes

- Styled scrollbars are 2 fen wide and float over the content; `ScrollAreaContent` reserves the same width at its end and bottom so the last column and row are not covered. The thumb uses the muted ink at rest and the body ink on hover or drag, keeping 3:1 against the surface.
- `confirm()` without `cancelLabel` labels the cancel button 返回 / Back instead of 取消 / Cancel.
- Numeric `TableCell` no longer wraps; a narrow table scrolls horizontally inside its container.
- `Drawer` side panels strip the physical left/right radius and border of the edge they attach to, so RTL pages no longer keep the line on the wrong side.
- `TimeField` segments grow to the small control size on coarse pointers; `SkipLink` meets the touch target.
- `SearchInput` shows the shared `BusyMark` while loading.
- Long `Composer` suggestion labels and descriptions wrap instead of overflowing.

## Fixed

- `DataTablePattern` caches its column definitions and passes live state to cells through context, so cells keep their focus and never read state from an interrupted render.
- `ColorPicker` derives its surface from the controlled value without setting state during render.
- `Toc` no longer rebinds its scroll listeners when the caller passes a new but identical inline `items` array.

## Deprecated

- `UILocaleMessages` keys `inputClear`, `expand`, `collapse`, `lightTheme` and `darkTheme` are no longer read by any component. They stay in 5.x for type compatibility and will be removed in 6.0.

## Upgrading

- Pages that relied on always-visible styled scrollbars should pass `visibility="always"`.
- Code or tests that expect 取消 / Cancel as Confirm's default cancel label must use 返回 / Back, or pass `cancelLabel`.
- `CommandDialog` callers that pass both `title` and `aria-label` now get the title as the name.
- Visual baselines change for ScrollArea, Confirm, numeric table cells, Drawer side panels in RTL, coarse-pointer TimeField and SearchInput loading.
