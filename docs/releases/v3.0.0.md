# Qingye UI 3.0.0

`packages/ui/package.json` is set to 3.0.0 and the release is cut by the `v3.0.0` tag. The GitHub Release exists once the [Release workflow](../../.github/workflows/release.yml) succeeds for that tag; npm publication is a separate manual step and is not established by this document.

3.0.0 carries the component adaptations from the 2026-10-12 consumer issue list and the benchmark against mature libraries. The plan is [2026-10-12-component-optimization.md](../plans/2026-10-12-component-optimization.md), with evidence under [2026-10-12-benchmark/](../plans/2026-10-12-benchmark/). Read the [2.0.0 notes](./v2.0.0.md) first when upgrading from 1.0.0.

The current source contains 91 component modules.

## Breaking changes

| Area | 2.0.0 | 3.0.0 and migration |
| --- | --- | --- |
| `useUILocale()` | Returned `UILocale`. | Returns `ResolvedUILocale` (`UILocale & { dir }`). Code that passes the result where an exact `UILocale` is expected, or compares the whole object, needs review. |
| DateRangePicker | One display input. `inputProps` went to it. | Two native date inputs share one draft with the calendar. `inputProps` applies to the start input and the new `endInputProps` to the end input. Typing a complete, ordered range requests the change at once; an incomplete, reversed, out-of-bounds, wrong-length or disabled-day range is not submitted and is reported through `onInvalid`. |
| FileUpload | Rejection reasons were type, size and count. | `FileUploadRejection` and the `fileError` locale reason add `"directory"` and `"custom"` (from `validate`). Exhaustive switches over the reason need the new cases. |
| CopyButton | Always named by the locale's "copy". | When the button shows text, its accessible name is that text. An icon-only button still uses the locale string. |
| Heatmap | Cell names without level names. | Each cell's name is row + column + value, plus the level name when `levels` is given. |
| Package `ai/*` | Shipped `ai/v0.4.0/`, `ai/v1.0.0/` and `ai/v2.0.0/`. | Ships only `ai/v3.0.0/`. Older versions stay on the website and in the repository. |

## Added

- Writing direction: `UILocaleProvider` `dir`, `useUIDirection()` and `getLocaleDirection(code)`; Base UI's `DirectionProvider` is wrapped. Sidebar rail popups open on the inline end.
- Date family: Calendar formats through `Intl`, takes the locale's week start and uses native selects for month and year. DatePicker and DateTimePicker keep a half-typed entry and accept `min`, `max` and `defaultValue`. DateRangePicker adds `presets`, `onInvalid` and `endInputProps`.
- Input family: OtpField `normalizeValue`, IME composition and paste handling; TagInput `splitOn`, `max`, `addOnBlur`, `validate` and required semantics; FileUpload `validate`, paste and folder rejection; PasswordInput warns in development when `autoComplete` is missing; `focusFirstInvalid()` from `form`.
- Combobox and Autocomplete: `Group`, `GroupLabel`, `Separator`, `Collection` and `Status` (result count announcements).
- Breadcrumb `maxItems` folds middle items into a menu. Tree typeahead. Accordion and Collapsible pass `hiddenUntilFound`. Page and empty-state titles wrap balanced.
- `Section` and the `Tone` type. Chart reference bands, value domains, step lines, share stacks, value labels, donut totals and ranges; Sparkline bands; Meter and Heatmap levels; Progress segments.
- Forced colors (`@media (forced-colors: active)`) and high contrast (`tokens/contrast.css`, `prefers-contrast: more`).
- Package: `default` export conditions and declaration maps.

## Fixed

- Read-only Select no longer opens under Base UI 1.9.
- Radio and SegmentedControl items inside a Field no longer share the Field's control id.
- A scrollable Table container is focusable and named; a non-scrollable one is not a tab stop.
- Toast uses dynamic viewport units.

## Visual changes

- The selected item of SegmentedControl, ToggleGroup and Toggle, and the current Pagination page, use a soft fill with full-ink text instead of a solid fill.
- Chart and status graphic colors were adjusted.
- A read-only FileUpload hides the remove button, and its read-only note no longer overlaps the chooser label.
- New appearance under forced colors and high contrast.

Check light and dark themes in the consuming application's real states. Mobile layouts are not part of the verified scope.

## Dependencies

`@base-ui/react` 1.7.0 → 1.9.0; `@daypicker/react` 10.0.1 → 10.0.2. Peer requirements are unchanged.
