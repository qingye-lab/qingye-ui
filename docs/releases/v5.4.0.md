# Qingye UI 5.4.0

5.4.0 lets `DataTable` columns say how they relate to each other instead of fixing pixel widths, repairs charts on negative values and long names, and stops date pickers and asynchronous trees from misreporting state. The default container line also deepens, which changes most visual baselines. No public API is removed.

## Added

- `DataTable` `columnDef.meta.grow`: a column takes a share of the remaining width. It must be a finite positive number. `minSize` and `maxSize` are the limits; a column that reaches one freezes there and the rest goes back to the other growing columns. A `size` on the same column acts as its floor. A column the user has resized leaves the distribution. It cannot be combined with `fit`.
- `DataTable` `columnDef.meta.fit`: a column is as wide as its header and rendered cells plus the cell inset, which also suits action columns. `maxSize` limits the cell content, never the column name. A virtualized table measures the first screen and locks the result.
- In the fixed layout, a text column without `size` now takes part in the distribution, and a marker column takes the marker's size plus the cell inset.

## Fixed

- `Chart` horizontal bars: the category axis stops at the longest name and caps at a third of the plot, truncating longer names instead of clipping them. Axis text is measured, so short names stay whole.
- `Chart`: the category axis keys on the row `id`, so rows sharing a name keep their own hover readout, and `formatValue` receives the hovered row.
- `ScatterChart`: axis formatters returning a node fall back to the default format instead of printing `[object Object]`, and the last x tick is no longer clipped.
- `DatePicker` and `DateTimePicker`: clicking the selected date again keeps the value. `DatePicker` closes the calendar and reports nothing; `DateTimePicker` keeps the draft and Apply stays available.
- `Tree` and `Cascader` with lazy children: a parent with an enabled unloaded descendant shows mixed at most, never fully checked. Toggling looks at the loaded enabled leaves, so such a parent can be cleared. A `Cascader` value inside an unloaded branch shows that branch and its ancestors as mixed, and clearing a parent removes those paths too. Clicking a parent with only unloaded descendants expands it, and a `Tree` parent like this is no longer dimmed. Disabled unloaded branches stay out of all of this.

## Visual baseline changes

- `--qy-border` deepens from 8% to 12% of ink (about 1.32:1 in light, 1.43:1 in dark), including table separators and chart grids. Every component that draws the container line changes.
- Light `--qy-danger-graphic` moves from `#7d161b` to `#8e1d22`.
- `Heatmap`: the lowest step takes a pale wash instead of nothing, and its legend key has a line.
- `Section`: a chart title inside a section drops to `text-body-strong`.
- `Chart` horizontal bars: the category axis width follows the names, so the plot area changes.
- `DataTable` in the fixed layout: columns without `size` and marker columns change width as described under Added.

## Behaviour changes

- `Chart` types `bar-horizontal`, `bar-stacked` and `area-stacked` and the continuous `Heatmap` scale throw a `RangeError` naming the negative value and its row. These forms only grow one way from the baseline, so their previous drawing was wrong. Use `bar` for signed values, or `levels` on `Heatmap`. Unknown values are not negative and do not throw.
- A click on the selected day no longer calls `onValueChange` with `undefined`. Use the clear button to clear.
- `Tree` and `Cascader`: tests that asserted a fully checked parent above unloaded descendants need updating.

## Compatibility notes

No public API is removed. Current Chinese/English AI resources are under `ai/v5.4.0/`; the `ai/v5.3.0/` snapshot stays in Git as released and is excluded from this tarball.

Known limit: on a horizontal bar chart, a name made of very wide Latin capitals can still pass the left edge after truncation, because the width is estimated.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. The release workflow publishes the verified tarball to npm through Trusted Publishing and attaches it to the GitHub Release.

```sh
pnpm add @qingye_lab/ui@5.4.0 --registry=https://registry.npmjs.org
```
