# Qingye UI v0.4.0

本版将 v0.3.0 之后的设计体系、组件修补、任务示例与项目工具正式打包发布。包含 `@qingye/ui` 和独立开发工具 `@qingye/tooling`，两者版本均为 0.4.0；通过 GitHub Release tarball 安装。

## 更新

- 全部 88 个组件补全具体的使用、组合、状态归属、响应式与主题修改指导；45 个组件实现及复制 Hook 完成修补。官网使用公共组件，首页采用简短介绍与真实组件预览，提供六种完整任务示例。
- 修复字段继承禁用、输入名称优先级、文件选择去重与原生表单值、日期约束、复制在途状态、树焦点恢复、折叠面板草稿、嵌套键盘操作、缺测图表与代码复制等行为。
- 修复辅助文字、占位和菜单高亮快捷键的对比度，以及长内容、窄屏和短视口下的浮层与触摸目标。
- 新增 `@qingye/tooling` CLI，支持读取实际安装版本、查询组件、显式初始化、主题 diff/apply、AST 诊断与影响查询。Theme Studio 可在仓库内运行，通过两份独立预览管理主题与工作状态；它不是本次附件中的独立安装包。
- 包内提供同源 `design.md`、schema 2 catalog、`ai/v0.4.0/` 组件与任务资料、AI Skill 及 registry 模板；官网提供可复制到消费项目的 `AGENTS.md` / `design.md` 接入片段。

## 升级注意

本版包含可见布局和行为变化，升级后应检查项目覆盖样式与相关交互：

- DataTable 批量动作进入正常文档流，会增加一行；刷新保留搜索与已有数据。长错误、长标签和任务动作允许换行。
- ComboboxChip 新增标签包装元素；依赖直接子元素的 CSS 需要复核。
- Pagination 禁用的自定义路由 render 使用无目的地的原生占位链接，启用时仍使用原路由组件；依赖禁用态子组件生命周期的代码需要调整。
- 粗指针 OTP 每格至少 44px，窄容器内部滚动；纵向 ToggleGroup 真正纵排。移动 Sidebar 增加标题与关闭入口，弹层按可用视口避让或滚动。
- 占位、辅助文字和危险状态颜色，以及 Accordion / Collapsible / Tabs 的展开退出动画有可见变化。

品牌、明暗、密度仍是独立维度。Tailwind 源样式与预编译 `ui.css` 仍只选一种。工具包不是 UI 运行时依赖，现有项目无须为了组件升级安装工具包。

主题源使用 `ui.theme.json`，生成 CSS 为派生文件；旧手写 CSS 默认只读。Studio 要求目标 UI 的版本、catalog 与源码指纹匹配，不支持用新源码预览任意旧包。

## 安装或升级

```bash
gh release download v0.4.0 --repo qingye-lab/qingye-ui --pattern 'qingye-ui-*.tgz' --output qingye-ui.tgz --clobber
pnpm add ./qingye-ui.tgz
```

需要 CLI 时另外安装：

```bash
gh release download v0.4.0 --repo qingye-lab/qingye-ui --pattern 'qingye-tooling-*.tgz' --output qingye-tooling.tgz --clobber
pnpm add -D ./qingye-tooling.tgz
```

提交下载的 tarball、`package.json` 与 lock 文件以固定实际依赖。原有 v0.3.0 Release 保留；需要回退时恢复项目之前的 tarball、依赖与 lock 文件。

## 验证范围

发布工作流要求类型检查、单元测试、事实台账、库/官网/Studio 构建、88 组件 × 明暗 × 桌面/手机浏览器审计、任务与主题场景、四种实际安装 UI 消费项目及实际安装 CLI 验证。只有通过全部检查才会创建 Release。

真实 IME、物理触屏、读屏和人工审美验收不由上述自动检查证明；任务示例中的本地业务状态也不证明后端权限、持久化或幂等。
