# Qingye UI 5.2.0

5.2.0 rebuilds the pager that `PaginationPattern` and `DataTablePattern` render. Props are unchanged; the layout, the controls it shows and one locale key are not. Read **Behaviour changes** before upgrading if your tests or custom locale depend on the old pager.

## Changed

- **One row.** A quiet range summary (`21–40 of 95`) leads the row; the page row and the page-size select sit at its end. On narrow screens the summary and page size share the first line and the page row takes the second, justified to both edges.
- **Icon page buttons.** Previous and next are icon buttons named from the locale (`上一页` / `下一页`, `Previous page` / `Next page`) and mirror under RTL. The trailing icon's glyph aligns with the row edge.
- **Constant page window.** The window always has `2 × siblings + 5` slots: seven on wide screens, five on narrow ones. Page buttons are square up to two digits, and an ellipsis takes one slot, so the row no longer shifts while paging.
- **Only controls that change the result.** One page leaves only the summary; the page-size select appears only when the total exceeds the smallest option; zero results read `0 results` with no buttons. With an unknown total (`totalCount={null}`), the summary shows the page number instead of "total unknown", and page 1 without a next page renders nothing.

`DataTablePattern` reuses `PaginationPattern` and follows all of the above.

## Behaviour changes

- Tests that looked for the previous/next buttons, a page-size combobox or the old summary text on a single page, on zero results or on a cursor first page without a next page need updating: those controls are now absent, and the summary text changed.
- Previous/next are found by their accessible names, not by visible text.
- A custom **complete** `UILocale` adds `paginationRange(start, end, totalCount)`. Locales that spread the shipped `zhCN` / `enUS` objects get it automatically. `paginationSummary` is deprecated and goes in the next major release.

## Compatibility notes

The primitive parts (`Pagination`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, …) keep their text defaults and contracts. Current Chinese/English AI resources are under `ai/v5.2.0/`, where `components/pagination.md` and `components/data-table.md` carry the migration notes; the `ai/v5.1.0/` snapshot stays in Git as released and is excluded from this tarball.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. A versioned build or tarball does not establish npm publication.

```sh
pnpm add @qingye_lab/ui@5.2.0 --registry=https://registry.npmjs.org
```
