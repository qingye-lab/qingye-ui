# Qingye UI 5.2.0

5.2.0 closes the component gap inventory recorded on 2026-11-01. It adds Composer, Transfer, Tour, Rating, Chip, AvatarGroup, ImagePreview, Result, SkipLink, TimeRangeField and DateTimeRangePicker; gives Calendar and the date pickers week, month, quarter and year granularity; lets Tabs and NavigationMenu use the track appearance; and rebuilds the pager that `PaginationPattern` and `DataTablePattern` render. Existing props keep their meaning. Read **Behaviour changes** before upgrading if your tests or a custom complete locale depend on the old pager.

## Added

- **Composer** (`Composer`, `ComposerInput`, `ComposerToolbar`, `ComposerSubmit`): a message editor whose value is an array of segments. `@` and `/` triggers open an asynchronous candidate popup; a choice inserts an atomic token or runs an action. Store the segments, not the text: text is restored into tokens only at word starts.
- **Transfer**: move items between two lists, with announcements and hidden form fields that submit the selected keys in value order.
- **Tour**: a non-modal step-by-step guide with an optional spotlight; anchors are re-resolved when DOM nodes appear or disappear while it is open.
- **Rating**, **Chip** (a removable or toggleable label, distinct from `Badge`), **AvatarGroup** (overlap, `+N` with the full name list), **ImagePreview** (thumbnails, set navigation, zoom, focus return), **Result** (an outcome receipt with tone, mark, title, description and actions) and **SkipLink** (a bypass link that moves focus; `Workspace` uses it).
- **TimeRangeField** and **DateTimeRangePicker**.
- **Date granularity**: `Calendar`, `DatePicker` and `DateRangePicker` take `granularity` (`"day"` by default, or `"week"`, `"month"`, `"quarter"`, `"year"`). Values stay `Date`: a single value is the period start; a range runs from the first period start to the last day of the last period. Week rules come from the locale. Non-day pickers use locale-formatted text inputs (ISO also parsed) and submit an ISO hidden field under `name`. Non-day granularities support single and range selection only; `mode="multiple"` with them throws.
- **Track appearance beyond SegmentedControl**: `Tabs` and `NavigationMenu` take `appearance?: "line" | "track"` (default `"line"`). In the track appearance an outer wrapper draws the frame, so overflow fades only the tabs.
- **ButtonGroup** `attached` merges adjacent borders; `ButtonGroupText` and `ButtonGroupSeparator` are new.
- **InputGroup** accepts `InputGroupTextarea`, `InputGroupNumberField` and `InputGroupSelectTrigger` members and reads focus, hover, invalid, disabled and read-only state from them. `InputGroupAddon` takes `align` (`inline-start`, `inline-end`, `block-start`, `block-end`); `InputGroupText` is new; `loading` marks the group busy and announces it. `Autocomplete` gains `loading`.
- **Select** `multiple` (no search; repeated form entries; the trigger lists the first two names and then "and N more"). `NumberField`, `Textarea` and `SelectTrigger` take `unstyled`. `NumberFieldScrubArea` is new.
- **Cascader** `multiple`, **TreeSelect** `searchable`, **Tree** `loadChildren`, `query` and drag-to-reorder (`draggable`, `onMove`, `canDrop`) with a keyboard equivalent.
- **OtpField** `groups`, single-character `placeholder` and `mask`; **ScrollArea** `fade` on either or both axes, RTL aware; **Drawer** `inset` in all four directions; `MenuSwitchItem` and `ContextMenuSwitchItem`; **CornerMark** logical placement and `hostShape`.
- New locale keys: `paginationRange`, `composerSubmit`, `dateInvalid`, `treeNoMatch` and the strings of the date granularities and new components. Locales that spread the shipped `zhCN` / `enUS` objects get them automatically.

## Changed

- **Pager in one row.** A quiet range summary (`21–40 of 95`) leads the row; the page row and the page-size select sit at its end. On narrow screens the summary and page size share the first line and the page row takes the second, justified to both edges.
- **Icon page buttons.** Previous and next are icon buttons named from the locale (`上一页` / `下一页`, `Previous page` / `Next page`) and mirror under RTL.
- **Constant page window.** The window always has `2 × siblings + 5` slots: seven on wide screens, five on narrow ones. Page buttons are square up to two digits, and an ellipsis takes one slot, so the row no longer shifts while paging.
- **Only controls that change the result.** One page leaves only the summary; the page-size select appears only when the total exceeds the smallest option; zero results read `0 results` with no buttons. With an unknown total (`totalCount={null}`), the summary shows the page number, and page 1 without a next page renders nothing.
- Switch and `MenuSwitchItem` share one geometry, as do Checkbox and the menu check marker; the ButtonGroup text segment follows Button's sizes.

## Fixed

- `InputGroup` adjacency styles were never generated by Tailwind; they now apply, and aligned addons are judged by position.
- `DatePicker` reports `dateInvalid` for unparsable period text; `DateRangePicker` reports `unrecognized`, and period ranges honour the calendar's min/max day span and `excludeDisabled`.
- `ScrollArea` fade stops before the native scrollbar gutter.
- `CornerMark` no longer shifts inward under RTL.
- The production build no longer fails on a vendor chunk initialisation order (`Cannot access 'lt' before initialization`).

## Behaviour changes

- Tests that looked for the previous/next buttons, a page-size combobox or the old summary text on a single page, on zero results or on a cursor first page without a next page need updating: those controls are now absent, and the summary text changed.
- Previous/next are found by their accessible names, not by visible text.
- A custom **complete** `UILocale` adds the new keys listed above. `paginationSummary` is deprecated and goes in the next major release.
- Visual baselines change for Pagination, the DataTablePattern pager, the Tabs track and ScrollArea fade masks.

## Compatibility notes

The primitive pagination parts (`Pagination`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, …) keep their text defaults and contracts. Current Chinese/English AI resources are under `ai/v5.2.0/`, where `components/pagination.md` and `components/data-table.md` carry the migration notes; the `ai/v5.1.0/` snapshot stays in Git as released and is excluded from this tarball.

## Verification and distribution

Release gates run in CI: workspace tests, type/API/fact checks, builds, built-preview browser audits and isolated tarball installations. A versioned build or tarball does not establish npm publication.

```sh
pnpm add @qingye_lab/ui@5.2.0 --registry=https://registry.npmjs.org
```
