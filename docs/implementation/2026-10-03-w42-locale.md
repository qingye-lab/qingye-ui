本任务实现语言、路由、Provider 与元数据机制，没有交付翻译内容。依据计划 W4.1–W4.3；W4.1 已定方法译名保持原样。本次起点 HEAD 为 `275d730`，工作区已有大量并行改动，全部按当前文件增量接线，未重置或覆盖其他任务的工作。

**机制验证与要求的四项总门禁均已通过。** 最新 UI 原样全量命令为 61 个文件、472 项测试通过；早期并行修改中的失败保留下方历史记录，不算作当前结果。

## 契约与设计决定

- URL 是语言的唯一权威：无前缀为 `zh`，`/en` 为 `en`；不使用 localStorage、浏览器语言推断或运行期 i18n 库。
- `apps/docs/src/lib/paths.ts` 独占语言前缀、页面 URL 构造、内容身份、访问身份及语言切换 URL。原 `/docs/...` 地址保留；`/components/...` 是同一组件内容的短别名，两种语言都可直接访问。
- 内容身份由 `routeIdentity()` 去除语言前缀并归一化组件别名；访问身份包含语言；滚动键再包含 history entry。导航/搜索不会把中文地址带入英文树。
- `ComponentMeta` 和 `DemoMeta` 共同继承 `LocalizedMeta`，具备可选 `titleEn` / `descriptionEn`。`localizedMeta(meta, locale)` 逐字段选择，缺哪个英文值就保留哪个中文值；demo 的中文 description 仍可缺省。原对象不会被改写。
- 导航指南和总览也支持同样的并列字段，`NAV_LABELS` 为类别/外壳标签提供同样的可选合同，现阶段不填英文。文档正文继续作为页面内容，未通过字符串注入进行翻译。
- `main.tsx` 挂载动态 `UILocaleProvider`，复用现有 `zhCN` / `enUS`。库侧本任务只将 `UILocale.code` 改为 `string`；没有新增键或改写键值，也没有编辑 `en-US.ts`。工作区中库侧其他键的新增来自并行任务，予以保留。
- `<html lang>` 先提交为 `zh-CN` / `en-US`，随后挂载消费者；切换语言重挂载消费树，以刷新 DataTable 缓存的 document collator。**这会重置 demo 的局部 React 状态**；页面、query、hash、返回上下文和滚动位置保留。ThemeProvider / MotionProvider 保持在该边界之外。
- 新增的面包屑使用公共 Breadcrumb 组合。所有文字翻译缺省时仍显示现有中文内容。
