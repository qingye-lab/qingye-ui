## 保留的边界

- 前几次未采集独立任务时间；后续墙钟时间含排队、调度和 root 接收通知延迟，不是有效修改耗时。平台没有逐次完整 token/tool 统计与可强制一致的 token 上限，因此不比较工时或提效倍数。
- 全部 tools 数为 null；observedHarnessToolCalls 仅统计可信 typecheck/docs wrapper，不冒充完整工具数。humanCorrections=0 指没有人工修补模型 work，判定器修正另记。
- 文件边界是提示与固定输出审计，不是 OS 沙箱；未经完整 transcript 审计的外部读写仍为 null。
- t02 是 AST/DOM selector 与有限 CSS 变量求值，其他任务为 jsdom/RTL + 注入 API；没有真实后端、浏览器、读屏、IME 或视觉效果结论。
- 固定目标为产品 reduced-motion 修补之前的源码快照；资料/组件在两组一致，但结果不代表最终全部源码的测量。

## 判定器修正与原始结果

初期合法公共子路径未被解析、批量任务中未公开的确认要求/范围错误、合法嵌套文本与标题别名、附文件名的取消可访问名称曾造成误判。依据公开 exports 和任务合同统一修正；全部首次结果和中间配置失败保留在各 run/result-history。未给模型二次修改机会，也未移除取消确认、未知保留、请求范围、旧响应或错误状态断言。具体记录见 [协议](ai-eval-protocol.md)。

## 产品判断

新资料已提供同源事实与明确修改入口，真实 CLI 查询/AST 诊断另有安装包验证；这属于已交付能力。现有 AI 试验没有测出它相对旧资料的错误率优势。公开网站不得使用本次结果宣称“更快”“效率提升”或保证 Agent 不出错。
