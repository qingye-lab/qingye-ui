# P1：四个探针与基础层发现

2026-10-03。实现对象：Button、Input、Card、Popover。依据 foundation §1–§18、四份族判据、component-layering、design.md、STANDARDS.md。本文记录实现与实际验证，不修改判据。

## 结果与边界

四个组件已在原路径重建。Button/Input/Popover 为 Primitive；Card 为 Pattern。类型、库测试、库构建、官网类型与官网构建通过。浏览器探针 240 项通过；构建后四页 × 明暗 × 桌面/移动 16 组审计无问题。

这些通过结果不表示基础层已经完整：下文的缺口仍需裁决。尤其浮层族「焦点必须回到触发者」未区分用户主动 Tab 离开或点击另一个可聚焦控件；按无条件字面检查，这两个关闭路径不满足该条，不能归入 PASS。

开工 HEAD 为 `275d730`。工作区已有大量未提交改动；保留原有工作，仅迁移新 API 的直接消费者与生成物。任务前 747 个源码/测试/文档/样式文件已保存快照。对比快照，218 个既有文件变化，17 个文件删除：两份被合并的输入源码、对应文档与示例，以及被新情境替代的 Card/Popover 示例。没有删除测试文件。没有创建或取得 upstream，也没有把 coss-source.json 当作实现依据。原服务 PID 59950、父 PID 59927、端口 5180 保留。

## Button

| decision | which foundation section forces it | the trade-off you took |
|---|---|---|
| `state` 只接收 idle / waiting / in-progress / unknown / failed；不自行请求、计时或推断完成 | §9；动作族决定 1 | 调用方必须持有对象与可靠结果；组件只呈现事实 |
| 名称与 DOM 控件保持稳定；等待/进行中仍可 Tab 到达，但保护鼠标、键盘、菜单组合的激活入口 | §9、§15；任务的焦点要求 | 状态描述位于独立 description/live region；不以原生 disabled 表达等待 |
| `variant=solid/quiet` 与 `tone=neutral/danger` 独立 | §7、§10；动作族 §五 | 删除旧外观枚举；颜色不能授予权限 |
| size 为 xs/sm/md/lg/xl，shape 为 label/icon | §1、§2、§8 | 从 F1 尺寸/文字档取值；图标形态具有同档宽度，文字形态可因长标签增高 |
| 无边框时消费 padding 档；低对比承载面显式补边界并换 bordered 档 | §1、§5 | 不读取 DOM 猜测父表面；消费端承担真实组合对比检查 |
| 危险动作必须处于 `ButtonProtection` 的非空可见后果结构中，并以 aria-describedby 关联 | §18；动作族决定 3、§六倾向 A | 保护是组合，不塞入 Button 的业务配置；裸 danger 或空后果显式抛错 |
| 按下反馈、焦点与粗指针命中继续消费集中角色 | §11、§12、§15 | 不以阴影、高光或更强填充冒充风险与授权 |

组合的实际形式：

```tsx
<ButtonProtection consequence="仓库 3 号设备（版本 7）及其历史记录会被永久删除。">
  <Button tone="danger" state={deviceState} onClick={removeDevice}>删除设备</Button>
  <Button variant="quiet" onClick={keepDevice}>保留设备</Button>
</ButtonProtection>
```

`ButtonProtection` 是本次试点的最小共处结构，不是已经实现完整确认、审批或服务器版本校验的 ConfirmAction。应用必须给出真实对象/版本/变更；React 上下文与必填文字无法证明这些事实，也无法阻止消费端用 CSS 隐藏说明或把子内容 portal 到另一处。库没有声称它能证明授权或不可逆操作安全。

删除：loading 布尔；default/secondary/ghost/outline/link/destructive/destructive-outline 变体；default 与 icon-* 等混合尺寸名；旧 Spinner 依赖、按钮自身默认边框/高光/阴影/图标间距。前几项由动作族裁决直接要求；后几项未具备当前角色依据。未知态禁止重复触发的实现候选单列在缺口 G7，不作为 §9 唯一强制的结论。

## Input

| decision | which foundation section forces it | the trade-off you took |

| 保留 `""` 与 `0` 的原生区别；未知、不适用由字段组合明确表达 | §17；表单族决定 1–3 | 不增加 unknown / N/A 值哨兵；没有值的事实不伪装成空输入 |
| 搜索、密码通过 type 表达同一个 Input 的形态 | §9、§18；表单族 §九、选择器族 Input 判据 | 删除两份独立组件与文档入口；搜索结果、快捷键与远程状态属于调用方组合 |
| 清空走真实 input 事件链；IME、取消的 Escape、只读/禁用不清草稿 | §9、§11、§15 | 首次 Escape 清当前字段，空值后交还外层关闭链；不提交表单 |

| className/style/render/ref/原生事件属于真实 input，controlClassName 属于共同编辑边界 | §18；STANDARDS 结构/透传 | 消费者需显式选择作用部位；InputGroup 放弃内层边界并承担共同外高 |

删除：SearchInput/PasswordInput 源码、公开导出、独立页面及当前版本生成入口；旧默认 size 名与旧文字档；默认「搜索」字段名与 placeholder；快捷键显示、加载 Spinner 等领域/组合配置。保留原有搜索与密码行为测试文件，改测 Input 形态与调用方组合。

## 实测几何与对比

探针加载真实 React 源码和构建后的 `dist/ui.css`，没有使用官网视觉覆盖。每项在 1280px 鼠标、390px 鼠标、390px 粗指针 × light/dark 串行运行。

| 档 | 桌面 Button 外高 / 字号 | 窄屏 Button 外高 / 字号 | Button 水平 padding | Input 实际水平 padding | 视觉留白 ÷ 档名义外高 |
|---|---|---|---|---|---|
| xs | 24 / 12px | 28 / 14px | 10px | 9px + 边框 1px | 41.67% |
| sm | 28 / 13px | 32 / 14px | 12px | 11px + 边框 1px | 42.86% |
| md | 32 / 14px | 36 / 15px | 14px | 13px + 边框 1px | 43.75% |
| lg | 36 / 14px | 40 / 15px | 16px | 15px + 边框 1px | 44.44% |
| xl | 40 / 16px | 44 / 17px | 16px | 15px + 边框 1px | 40.00% |

- 鼠标下 Input 外高与上述 Button 外高一致；粗指针下五档 Input 实际外高均为 44px。共同边界 InputGroup 为桌面 32px、窄屏鼠标 36px、窄屏粗指针 44px。
- Button 图标形态在 flex 与 grid 两种承载下保持同档正方形；InputGroup 的附属文字动作不被输入挤成多行。
- 把 spacing 的基础值调为 8px，五档 Button 外高及 padding 不变。把内容 body 字号调为 30px，控件字号不变。将桌面与窄屏 control-md 字号均改为 20px，computed 字号变为 20px，padding 仍为 14px。
- 因此本次不会声称「padding 随字号变化」：最终 §1 明确要求它由名义外高决定。任务早稿的该表述与最终依据不同。
- Card computed padding 默认 0px。嵌套探针外半径 12px、实际 inset 9px（padding 8px + border 1px）、内半径 3px，六组均满足 `12 − 9 = 3`；子 Button 仍保留自己的 8px 控件半径。
- Popover computed 半径 12px、raised 表面、外层 overflow visible、非 aria-modal；键盘关闭控件 ring 为 2px + offset 1px，距滚动边界约 15.68–16px，未裁切。
- Input 文字对比浅/深约 19.80:1 / 15.09:1，输入边界约 4.00:1 / 4.25:1；solid Button 文字约 14.50:1 / 13.88:1。同底色测试填充对比为 1:1，显式边界为约 14.50:1 / 13.88:1，computed padding=13px，与边框合为 14px 视觉留白。这里只证明这些实际组合。

## foundation gaps：不能冒充已定规则

以下引文保持原文。涉及实现候选的条目不列入上方「基础层强制」决定。

| # | 原文与定位 | 发现 / 当前处理 |
|---|---|---|
| G1 | §1：「实测五档都落在外高的 40–44%。」 | lg=16/36=44.44%，超过字面 44%。实现遵从同节表格；硬上限 50% 满足，不能为了区间描述把 lg padding 改小 |
| G2 | §1 xl：「**被上限卡住**：按比例应为 17.6px，但大字档需要更多文字区」 | 同节上限为外高×50%=20px，17.6px 没被此上限卡住。16px 仍作为已落地预设使用，理由需改清楚 |
| G3 | §4：「**嵌套同心**：内层 = 外层 − 内边距，或减 0.5px；内高光伪元素比宿主小 1px。这不是「也用 8px」。」 | 任意减 0.5px 不保证同心；CSS padding 未含边框也不等于实际 inset。本次按实际边界偏移 9px 换算，不发明另一份固定半径 |
| G4 | §8：「**窄屏比桌面大 1px 是预设**」 | 同节 xs 表为 12→14px，实际是 +2px；实现遵从表和 F1，不把 xs 改成 13px |
| G5 | §9：「状态围绕**同一个对象**连续发生，因此状态不能存在控件上。」 | 同节下一段允许指针/焦点/展开由控件自持；应限定为对象/持久化事实，不应概括所有状态 |
| G6 | §9：「\| 选中、无效、当前项 \| 控件自持，可由应用受控 \|」 | 与本任务及表单族「值不符合规则（必填、格式）」「应用/浏览器校验」的归属容易冲突。Input 只呈现应用/Field 的 invalid，不从内容推断 |
| G7 | §9：「超时 ≠ 未执行 ≠ 失败」 | 规定事实区别，未规定 unknown 时重复动作是否禁用、何时可以安全重试。当前探针采取 unknown 禁止重复激活的候选策略，调用方提供独立核实入口；这项需裁决，不能声称由 §9 唯一推出。失败也不自动发起重试 |
| G8 | §3：「**规则：组件引用角色，不引用阶梯。**」 | 缺 Button 图形↔标签↔状态、后果说明↔动作的内部关系间距角色。本次不新造 token，也不借 action-gap 代理图形间距；仅给实际相邻动作使用 action-gap，状态用自然文字分隔 |
| G9 | §5 的填充低对比条件；动作族 §五：「由基础层 §5 的条件决定」 | 未定义消费端声明父表面/必要边界的公共组合入口。当前靠显式 class/style 与 bordered 档；实测示范成功，不证明任何父表面都能自动补边界 |
| G10 | §18：「\| **继承** \| 密度、方向、语言由容器传递；单位自己不声明 \|」 | 默认 Portal 的 DOM 容器是 body，局部继承会改变。提供已挂载 container 可保留上下文；defaultOpen 加未挂载 ref 的策略未定义，不能宣称自动满足局部继承 |
