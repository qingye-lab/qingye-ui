# F1 动效所有权（§12）

依据 `docs/decisions/2026-10-03-foundation.md` §12；本项集中浮层出现、消失与浮层内切换的表现，不改原语的打开、关闭、焦点、嵌套和拖拽状态机。

## 文档未定项与采用的解释

- §12 未重新规定各浮层的起止数值与差异。保留既有 `.98` 预设和 Dialog 窄屏贴底的 `1rem`、Sheet 的 `2rem`、导航内容的 `1.5rem` 位移，集中迁移而不重设视觉。
- 小浮层使用原有 fast 进入 / press 退出；Dialog、AlertDialog、Command、Sheet、Navigation Popup 使用原有 base 进入 / fast 退出。Navigation Content 的退出采用 fast，以满足 §12 的退出比进入快。
- ContextMenu 与 Menu/ContextMenu 子菜单原来未被全局 Select/Menu 选择器覆盖。本项将它们接入同一小浮层预设，解释为 §12 的同类所有权统一；这是可观察的新增入退场表现。
- Drawer 原有退出为 `swipe-strength × 400ms`；以 `swipe-strength × --qy-duration-drawer × 8/9` 保留当前 400ms（strength=1），只留下一个集中时长入口；实时 swiping 时 backdrop 仍即时。
- Popover/Tooltip/Navigation 的既有 width/height 内容切换过渡保留；Drawer 既有底向 margin/padding/snap-point 过渡保留。本项不借统一所有权重写它们的内容切换或拖拽几何。
- Layering 文档写未来删除 Sheet/Command/PreviewCard，但当前仍是实际导出的消费实现。F1 保留这些文件，并让它们遵守同一所有权规则。
