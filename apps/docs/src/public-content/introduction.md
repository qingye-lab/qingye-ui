# Qingye UI：公开介绍稿

**让文化成为设计的方法**

Qingye UI 关注的是一个具体问题：怎样让数字界面更清楚地承载人的目的。

我们从中国传统思想、造物与艺术中寻找方法，但不把传统理解成一种固定皮肤。颜色、纹样和字体可以表达文化，却不是文化进入设计的唯一方式。我们更关心：文化能否参与一次命名、一组操作、一段空间和一次状态变化的判断。

我们的立场是：**器用为本，关系为法，合宜为度。**

器用为本，是先理解人要完成什么。阅读、表达和比较是目的，暂停、拒绝和改变决定，也同样是正常的需要。

关系为法，是不孤立地看一个按钮是否漂亮。我们同时看它和内容、辅助说明、保护措施以及前后状态的关系。

合宜为度，是不把“克制”理解成什么都淡，不把“留白”理解成什么都空。需要比较的数据可以很密，重要风险可以很醒目；关键是表达与情境相称。

围绕这个立场，我们形成六个方法。

**名实相符：**名称说清行动与结果。“保存草稿”和“发布”不能因为放在同一个位置，就都叫“确定”。

**相成相制：**一组部件不只分主次，还要考虑怎样互相帮助、限制意外、保持衔接。保护使用者的操作，也可以是当前最重要的操作。

**布白有用：**空白不仅用于分隔，也留给内容、表达和判断。高密度可以有秩序，空白起点也需要清楚入口。

**随境取度：**让显著程度、空间和介入与任务相称，不为了自适应打断已经发生的操作。

**展开有据：**需要时深入，同时保留必要上下文。逐步了解与直接抵达，应当能够共存。

**进退相承：**让改变有来处、有后续。失败后不无端丢掉输入，返回后不迫使人重新寻找位置；顺畅不只是向前，也包括可以停下。

设想一次资料编辑：从列表进入详情，明确对象，保留对照；修改之后看清保存或放弃的含义；遇到失败，能在原处修正；完成以后，回到能继续工作的地方。

这个过程不需要任何传统图案，却可以体现完整的文化方法。它影响的不是一张界面截图，而是人怎样理解和使用工具。

我们希望最终的体验能够静而有回应、疏而有联系、有序而不僵化、协调而有区别、含蓄而入口可寻、克制而足以承接意外。

**Qingye UI：从器用出发，在关系中建立秩序，为使用留下余地。**
