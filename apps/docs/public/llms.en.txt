## Components
- [Accordion](/en/docs/components/accordion.md): Reveal content from each item's named trigger.
- [Alert](/en/docs/components/alert.md): Static local information, with announcements only when requested.
- [AlertDialog](/en/docs/components/alert-dialog.md): Block the work surface for an explicit decision about the current object.
- [Autocomplete](/en/docs/components/autocomplete.md): Edit free text with optional suggestions.
- [Avatar](/en/docs/components/avatar.md): An image with one named identity and a fallback.
- [Badge](/en/docs/components/badge.md): A short marker that keeps its content name without inferring state.
- [Breadcrumb](/en/docs/components/breadcrumb.md): Parent links and an explicit current location.
- [BulkActionBar](/en/docs/components/bulk-action-bar.md): Shared actions with explicit targets, versions and scope.
- [Button](/en/docs/components/button.md): Trigger a named action with a clear object and consequence. The caller owns its state.
- [ButtonGroup](/en/docs/components/button-group.md): Give actions in one scope a shared name and spacing.
- [Calendar](/en/docs/components/calendar.md): Navigate a local calendar and select a day, multiple dates, or a range.
- [Card](/en/docs/components/card.md): Bound an independently identifiable object.
- [Chart](/en/docs/components/chart.md): Nine task-chosen forms—line, bar, area, area-stacked, area-share, bar-horizontal, bar-stacked, bar-share and donut—with a same-source plot, named axes and an on-demand data table.
- [Checkbox](/en/docs/components/checkbox.md): Choose an independent yes/no value or multiple items in a set.
- [CheckboxGroup](/en/docs/components/checkbox-group.md): Connect checkboxes to one collection and shared scope.
- [CodeBlock](/en/docs/components/code-block.md): Literal text with actual copy results.
- [Collapsible](/en/docs/components/collapsible.md): Reveal additional content for the same object.
- [Combobox](/en/docs/components/combobox.md): Filter candidates and confirm one value or a set, with query text separate from selection.
- [ConfirmAction](/en/docs/components/confirm-action.md): Confirm a specific object, version, and change; review again when content changes.
- [ContextMenu](/en/docs/components/context-menu.md): A context-menu enhancement for commands on the current object.
- [Copy button](/en/docs/components/copy-button.md): Copy supplied text and reflect the clipboard write result.
- [CornerMark](/en/docs/components/corner-mark.md): A count or presence dot anchored to a host's corner, never part of the host's own content.
- [DataTable](/en/docs/components/data-table.md): Comparison, sorting and scoped selection for a real caller-owned collection.
- [DatePicker](/en/docs/components/date-picker.md): Edit one local date or choose it from a calendar.
- [DateRangePicker](/en/docs/components/date-range-picker.md): Type or pick start and end dates; only a complete, ordered range is a confirmed value.
- [DateTimePicker](/en/docs/components/date-time-picker.md): Edit complete local wall-clock date/time, or apply calendar and time drafts.
- [DescriptionList](/en/docs/components/description-list.md): Native relationships between names and values.
- [Dialog](/en/docs/components/dialog.md): Take over the work surface for an edit or decision, then return.
- [Drawer](/en/docs/components/drawer.md): Enter an edge-aligned work surface and return to its entry point.
- [Empty](/en/docs/components/empty.md): Distinguish zero results, unknown and not applicable.
- [Field](/en/docs/components/field.md): Connect one value's name, control, description, and caller-supplied errors.
- [Fieldset](/en/docs/components/fieldset.md): Give related fields a shared name and disabled scope.
- [FileUpload](/en/docs/components/file-upload.md): Choose or drop local files, retaining accepted files and real rejection reasons.
- [FilterBar](/en/docs/components/filter-bar.md): Shows draft conditions separately from applied facts.
- [Form](/en/docs/components/form.md): A native field submission scope and reset context.
- [Heatmap](/en/docs/components/heatmap.md): A quantity over two categorical dimensions, such as sync activity by weekday and hour; a single-hue sequential scale (the first series color, light to full) or application-declared levels, readable cell by cell from the keyboard, with an on-demand data table.
- [HoverCard](/en/docs/components/hover-card.md): Reveal the same supplemental content on hover and keyboard focus.
- [Input](/en/docs/components/input.md): Enter one text value.
- [InputGroup](/en/docs/components/input-group.md): Give an input and its markers, units or actions one editing boundary.
- [Item](/en/docs/components/item.md): Content, navigation and related actions.
- [Kbd](/en/docs/components/kbd.md): A native keyboard key display.
- [Label](/en/docs/components/label.md): Name one control with a native label.
- [Layout](/en/docs/components/layout.md): Arrange content vertically or side by side using field, action, panel and section spacing roles.
- [Link](/en/docs/components/link.md): A text entry that goes to an address; every text link in the library shares this one treatment.
- [Locale switch](/en/docs/components/locale-switch.md): Request an application locale change and show the current Provider value.
- [Menu](/en/docs/components/menu.md): Temporary commands and choices related to the current task.
- [Meter](/en/docs/components/meter.md): A real measurement over a valid range.
- [MotionProvider](/en/docs/components/motion-provider.md): Record input modality at the application root and skip transitions for keyboard input.
- [NativeSelect](/en/docs/components/native-select.md): Keep the platform picker, native options and form values.
- [NavigationMenu](/en/docs/components/navigation-menu.md): Real links, expandable navigation groups, and in-panel group names with descriptions.
- [NumberField](/en/docs/components/number-field.md): Edit an optional number and adjust it by a declared step.
- [OtpField](/en/docs/components/otp-field.md): Present a fixed-length text value in segments.
- [PageHeader](/en/docs/components/page-header.md): Co-locate a page name, context and related actions.
- [Pagination](/en/docs/components/pagination.md): Page position, real actions and explicit unknown totals.
- [PasswordInput](/en/docs/components/password-input.md): Enter a password and switch to plain text to check it.
- [PendingValue](/en/docs/components/pending-value.md): An unresolved write result with its original value.
- [Popover](/en/docs/components/popover.md): A trigger-bound non-modal popup for local actions and supplementary information.
- [Progress](/en/docs/components/progress.md): Confirmed task completion or an explicit indeterminate state.
- [Proportion](/en/docs/components/proportion.md): Which parts make up a whole and how much each takes.
- [Prose](/en/docs/components/prose.md): Typesets already-rendered Markdown or rich text as an independent reading paper; headings, lists, quotes, code and tables read existing text tiers and ink roles.
- [RadioGroup](/en/docs/components/radio-group.md): Choose one value from a small set of visible options.
- [ScatterChart](/en/docs/components/scatter-chart.md): The relationship between two numeric quantities; an all-pairs form with one to three series, a same-source scatter plot, named axes and an on-demand data table.
- [Scroll area](/en/docs/components/scroll-area.md): Native scrolling within a bounded viewport.
- [SearchInput](/en/docs/components/search-input.md): Enter a search term and clear it in one step.
- [Section](/en/docs/components/section.md): A page block without a border, named by its title; the title and its actions share one row.
- [SegmentedControl](/en/docs/components/segmented-control.md): Enter one value from a small set of visible segments.
- [Select](/en/docs/components/select.md): Choose one value from a collapsible set of options.
- [Separator](/en/docs/components/separator.md): Express a boundary between content groups as a semantic separator or decorative line.
- [Sidebar](/en/docs/components/sidebar.md): Persistent navigation, an icon rail when collapsed, and an expandable sub-level.
- [Skeleton](/en/docs/components/skeleton.md): Hold the place and row count content will take until it arrives.
- [Slider](/en/docs/components/slider.md): Enter a number or an ordered range within explicit bounds.
- [Sparkline](/en/docs/components/sparkline.md): A small line set in a line of text, showing how a reading has recently changed.
- [Stat](/en/docs/components/stat.md): Values, units and explanations supplied independently.
- [StatusDot](/en/docs/components/status-dot.md): A state graphic and its visible name.
- [Steps](/en/docs/components/steps.md): An ordered process with application-owned progress.
- [Switch](/en/docs/components/switch.md): Immediately change the on/off state of a current setting.
- [Table](/en/docs/components/table.md): Native two-dimensional relationships with complete comparison columns.
- [Tabs](/en/docs/components/tabs.md): Different views of one object with panel drafts retained.
- [TagInput](/en/docs/components/tag-input.md): Confirm a string collection while keeping its unconfirmed draft.
- [Textarea](/en/docs/components/textarea.md): Edit multiline notes and messages.
- [ThemeProvider](/en/docs/components/theme-provider.md): Remember the user's choice of light, dark, or system mode for the whole document. ThemeProvider follows system preference changes and applies the resolved mode to <html>. Mount it once at the app root and use useTheme to read or change the mode.
- [Timeline](/en/docs/components/timeline.md): Preserve input order and actual times.
- [Toast](/en/docs/components/toast.md): Report recoverable, non-critical facts while the current work continues.
- [Toc](/en/docs/components/toc.md): A vertical in-page table of contents for moving between sections; the current location deepens its own segment of an existing thin line instead of adding a new shape.
- [Toggle](/en/docs/components/toggle.md): A two-state toggle that holds its pressed fact until toggled again, with a stable name.
- [ToggleGroup](/en/docs/components/toggle-group.md): A shared single or multiple set of toggles whose pressed fact persists.
- [Toolbar](/en/docs/components/toolbar.md): Actual groups, arrow-key focus and operable actions.
- [Tooltip](/en/docs/components/tooltip.md): Read shortcuts, formats and brief context on hover or focus.
- [Tree](/en/docs/components/tree.md): Hierarchy, expansion, focus, independent single selection, and an optional cascading checkable mode for stable nodes.
- [Typography](/en/docs/components/typography.md): Headings, body copy, supporting text and numbers use the existing text steps. Semantics and visual size are independent.
- [Virtual list](/en/docs/components/virtual-list.md): An accessible window over a fixed-height collection with stable item identity.
